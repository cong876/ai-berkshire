## 4. 各维度分析摘要

### 4.1 商业模式 & 护城河（段永平视角）★★★★（持平）

1. **9-25 Copilot 定价拆分是本轮最大结构变化。** 「日常 AI」留在 $30 席位里，列价没动；Cowork / Code / Autopilot 和前沿模型改按 Copilot Credits 计费（$0.01/credit，预购最多 8 折，叠加在席位之上，企业租户默认关闭）。上轮「Copilot 可能是 Office 最后一次加价」被部分推翻：微软没涨列价，换成了叠加计量表。新税种能不能收上来，要看后几季数字。
2. **Copilot 席位 / ARR / attach 本轮零新披露。** Hood 9-09 高盛会议没给新数，最新仍是 7-29 的「>3,000 万」；按 4.5 亿商业席位估算 attach 约 6.7%（估计）。
3. **M365 涨价落地**：7-01 起 E3 $36→$39、E5 $57→$60，新推 E7 $99/人/月。办公税的定价权仍在。
4. **Maia 300（10-12）**：公司预期每兆瓦 token 比「领先 GPU 系统」多 40%，2027 年起多 GW 部署，只自用不外租，无第三方基准。成本路线变清楚，但不是收入。
5. **OpenAI 资产侧与风险侧同时放大。** 年化收入约 $500 亿（净额口径，FT 10-08）、Q3 +77%；正以 $1.4 万亿估值融资，微软 25–27% 股权隐含约占市值 9%（推算）；同时据报 2026–2030 烧钱 $2,780 亿，与其对 Azure 承诺约 $2,810 亿同量级。现行条款仍是 4-27 修订版：非独家、多云、分成封顶、AGI 条款删除。
6. **模型层多元化坐实**：产品内同时内置 GPT-5.6 与 Claude Sonnet 5，GitHub 加入 Gemini 和 Grok。护城河在 harness（身份、数据、分发），不在模型。

> 段永平：「不懂不做。」第一层办公税懂，第二层云水电看得见，第三层 Copilot Credits 刚开始计费，OpenAI 的 $2,780 亿烧钱和 $1.4 万亿估值——还是不懂。

### 4.2 财务 & 估值（巴菲特视角）★★（降一星）

1. **+12.95% 全部是倍数扩张。** 两轮之间没有新季度、没有新指引。OpenAI 股权重估（Forge 二级约 $8,940 亿 × 27%）只解释市值增量的 2.5%；按 $1.2 万亿 IPO 传闻算也只解释 20%（估计）。
2. **9-02 分部重述是唯一财务披露。** 三分部改成 Agents and Infra / Devices and Consumer；Azure 首次披露绝对额 FY26 $1,019 亿（+40.4%）；Agents and Infra 利润率逐季下行 53.1% → 49.3%。10-28 起增速口径断档，必须新口径对新口径。
3. **贵不贵取决于尺子。** GAAP PE 30.3x 约等于十年中位；P/FCF 60.2x 高于过去五个财年末任何一年；业主盈余宽松口径（OCF − D&A − SBC）收益率 3.27%，最严口径 0.74%。两把尺子都低于 5.2% 的国债。
4. **资产变重**：PP&E/收入从 FY17 的 25% 升到 FY26 的 94%，折旧 +56%；增量资本回报从 FY23→25 的 30.0% 降到 FY24→26 的 20.9%（估计）。
5. **资本配置从返还转向再投资**：股息增速 10.7% → 9.6% → 7.7%，无新回购授权（$600 亿计划剩 $406 亿）；FY26 股东回报 $487 亿占经济 FCF 的 115%。
6. **FY27 EPS 噪音更大**：数据中心折旧年限 15 → 25 年抬高 EPS（金额未披露）；Anthropic 已提交招股书、IPO 目标传闻 >$2 万亿，浮盈不在 Q1 指引里。
7. **三情景（参数同上轮，EPS $16.93，3 年）**：乐观 **$834.5**（+53.6%）/ 中性 **$495.7**（−8.8%）/ 悲观 **$270.9**（−50.2%）。反推：3 年后回到 22x 需可持续 EPS 年增 13.4%；回到十年中位 30x 只需 2.1%。

> 巴菲特：「股市短期是投票机，长期是称重机。」8-20 到 10-13，称重机上一克没变。

### 4.3 行业 & 竞争（芒格视角）★★★★（持平，下行风险上升）

1. **Anthropic 成为头号增量对手，算力几乎不在 Azure。** 7 月底年化收入超 $650 亿（NYT 9-18 报「超 $1,000 亿」，两者冲突，取低值）。泄露的 S-1 草案算力承诺合计 $5,180 亿：Broadcom $1,612 亿、Google $1,111 亿、Amazon $1,100 亿、**微软 $314 亿（6.1%）**。
2. **各家 backlog 万亿级、中游现金流普遍为负。** 微软 RPO $6,780 亿、Oracle $6,640 亿（约一半与 OpenAI 相关，估计）、Google $5,140 亿、AWS 约 $4,960 亿（转引）。Oracle FCF 约 −$50 亿且季内增发 $200 亿；AWS 过去 12 个月 FCF −$76 亿；CoreWeave 季度利息 $6.4 亿高于经营利润。四家口径不可比，只看方向。
3. **自研芯片全面落地**：Maia 300 自用；OpenAI 自研芯片 2027 年量产；Amazon 8-K 写明 OpenAI 和 Anthropic 都有多 GW 的 Trainium 承诺。
4. **NVIDIA 买家结构在变**：Q2 FY27 数据中心 $890 亿，超大规模云 $490 亿；AI 原生云 + 企业 + 主权客户 $400 亿、同比 +138%，增长更快。
5. **开发者工具格局重排**：Cursor 被 SpaceX 以 $600 亿收购（转引）；GitHub Copilot 5,000 万用户；Codex 占 OpenAI 企业客户输出 token 的 64%。
6. **微软尚未开始的租赁承诺** $3,291 亿（上季 $1,966 亿，+67%，DCD 单源，需 10-K 附注核实）。
7. **什么会杀死微软**（3 年概率，观点）：OpenAI 集中度反噬 25%；过度建设 + 固定承诺锁死 25%；Agent 绕开 Office 席位税 20%；Google–Anthropic–Amazon 轴心 20%；监管拆捆绑 15%。**最可能的组合死法**：OpenAI 融资收紧削减 Azure 消耗，而已签租约无法同步收缩。

> 芒格：「反过来想，总是反过来想。」四家云都在囤万亿 backlog，谁的客户最集中、租约最长、现金流最先转负，谁先出事。

### 4.4 风险 & 管理层（李录视角）★★★（持平）

1. **宏观独立核实属实**：9-16 FOMC 12:0 加息 25bp 至 3.75–4.00%，2023 年以来首次；十年期美债 9-25 升至 5.23%，10-14 约 5.22%。微软 TTM 盈利收益率 3.30% 低于国债约 1.9 个百分点。
2. **管理层 7 项可检验承诺全兑现**：dock-to-live 缩短 50% 以上、Maia 300 发布、Xbox 重组完成约四分之三。扣分：Hood 仍无 capex 的 ROIC 数字门槛（9-09 首次表示「ROIC 合理时愿意用债」）；8-31 一次 M365 认证故障。
3. **杠杆转到表外**：微软两个财年未自己发债，由房东代为借钱。QTS 为微软乔治亚项目发的 $39 亿债预期投资级却付约 7% 收益率，相当于单 B 垃圾债定价（Bloomberg 8-17/18）。
4. **OpenAI 信用链压力测试**：FT 10-08 报 OpenAI 年化净收入约 $500 亿低于流传的 $680–700 亿，微软当日 −1.35%，Oracle −5.5%，市场认为微软在这条链上风险最低。双方互相降级为可替换供应商：OpenAI Dots Agent 进 Teams；微软用 MAI 模型替换部分功能并发布 Maia 300。
5. **监管三线合围**：欧盟 DMA 最早 11 月把 Azure 列为守门人；英国 CMA 2027-02 前决定；FTC 6 月扩大调查、无起诉。三者可逆，不构成永久性资本损失来源。
6. **内部人交易无异常**：Nadella 9-01 卖出 86,525 股约 $4,339 万，等于净归属股 80%，与 10b5-1 计划吻合，每年 9 月例行；仍持 918,227 股。Hood 9-14 卖 8,834 股。
7. **永久性资本损失概率（观点）**：10 年名义亏损约 12–20%（业务永久受损 5–8%、$543 买入的价格型损失 10–15%）；亏超 50% 约 3–5%。

> 李录：「投资最重要的是避免永久性资本损失。」生意没变坏，管理层没犯错，价格吃掉了一部分安全边际，利率又压薄了一层。

## 5. 投资论点（Bull vs Bear）

### 🟢 看多逻辑

1. **办公税定价权仍在**：7-01 涨价落地，E7 $99 新档，Copilot Credits 叠加计费——同一批席位可以收第三次钱。
2. **Azure 绝对额首次可审计**：FY26 $1,019 亿、+40.4%，Q1 指引 +44–45%（恒定汇率，9-02 8-K 机械调整后口径），RPO $6,780 亿为四家最大。
3. **执行力有证据**：7 项承诺全兑现，dock-to-live 缩短 >50%，Maia 300 给出 2027 年多 GW 自用推理路线。
4. **OpenAI 股权是看涨期权**：$1.4 万亿估值融资中，25–27% 股权隐含约占市值 9%；Anthropic IPO 传闻 >$2 万亿，微软另持少数股权。
5. **GAAP PE 30.3x 等于十年中位**：按利润倍数看，微软没有比自己的历史贵。
6. **在 OpenAI 信用链上风险最低**：10-08 压力测试日跌幅只有 Oracle 的四分之一；多云、分成封顶条款已写进合同。
7. **监管三线都可逆**：DMA/CMA/FTC 都是行为救济，不拆公司。

### 🔴 看空逻辑

1. **分子零变化、倍数 +13%**：可持续 PE 32.1x、P/FCF 60x 五年最高、FCF yield 1.66% 对 5.2% 国债。同参数三情景中性已 −8.8%。
2. **Copilot 仍无 ARR / attach**：渗透率估计约 6.7%，Credits 默认关闭；「3,000 万席位」已连续三个季度没有美元跟进。
3. **Anthropic 94% 算力给了别人**：增长最快的模型公司把 $5,180 亿承诺中的 $314 亿留给 Azure。
4. **租约表外化 + 杠杆由房东承担**：尚未起租租约 $3,291 亿（单源）、QTS 项目债 7% 收益率；经济 FCF $424 亿已低于股东回报 $487 亿。
5. **增量资本回报下行**：FY23→25 30.0% → FY24→26 20.9%（估计）；Agents and Infra 利润率逐季下行 53.1% → 49.3%。
6. **OpenAI 两头放大**：烧钱 $2,780 亿 ≈ 对 Azure 承诺 $2,810 亿；RPO 约 45% 绑定 OpenAI（Forrester 估计）。融资一旦收紧，租约收不回来。
7. **利率新高 + 资本返还放缓**：股息增速连续三年放缓、无新回购授权，正是估值最需要现金支撑的时候。

## 7. 最终投资建议

### 7.1 定性判断

| 维度 | 判断 | 评级 |
|------|------|:----:|
| 生意质量 | 一流办公税 + 正在变重的云军备，收费结构在变好 | **A-**（不变） |
| 管理层 | 执行力有证据；AGI 开支仍缺回收年数 | **A-**（不变） |
| 估值 | 可持续 32x、P/FCF 60x，同参数中性 −8.8% | **C**（上轮 C+） |
| 时机 | 利率新高 + 财报前两周 + 分部口径断档 | **C**（上轮 C+） |

### 7.2 分层操作建议

价格锚：现价 **$543.45**；工具三情景 **$834.5 / $495.7 / $270.9**。可持续 EPS $16.93 对应：22x ≈ **$372**，26x ≈ **$440**（财务组回到 ★★★ 的条件之一），28.4x（上轮倍数）≈ **$481**。

| 投资者类型 | 建议 | 参考价格区间 | 说明 |
|-----------|------|-------------|------|
| **激进型** | 已有仓**持有不加**；新开仓等 10-28 | 回踩 **$440–480**（26–28x）再加；$440 以下是财务组升星线 | 赌的是 Copilot Credits 真能收上来 + Azure 新口径 ≥42%，不是 OpenAI 估值 |
| **稳健型** | **观望** | 等待其一：(1) 10-28 经营利润增速 ≥15% 且 FCF 同比转正；(2) 可持续 PE 压回 **26x 以下（约 $440）**；(3) 首次披露 Copilot ARR/attach | 两轮之间没有任何新证据支持在更高价格买同一份 10-K |
| **保守型** | **回避新开仓** | 除非靠近悲观带 **$270–330**，或经济 FCF yield 回到 3% 以上 | 李录框架下，60x 现金买一项自己停不了火的 GPU 重置，而无风险利率是 5.2% |

以上是研究区间，不是预测。10-28 的 capex 指引、Azure 新口径增速、RPO ex-OpenAI、Copilot 席位数、折旧年限变更金额都会改写倍数。上轮若按「$481 不加满」持有，本轮 +13% 是**估值扩张而非基本面跳跃**，不宜把涨幅理解成论文被验证。

### 7.3 关键催化剂

**加仓 / 论点转正**
1. 10-28：Azure 新口径 ≥44%、经营利润增速 ≥15%、单季 FCF 同比转正
2. 首次披露 Copilot ARR 或 attach，且显著高于 6–7% 回推；Credits 收入单列
3. 10-K 附注核实尚未起租租约远低于 $3,291 亿，或 FY27 capex 指引不再加速
4. Anthropic 对 Azure 的承诺比例提升，或 RPO ex-OpenAI 增速 ≥30%
5. 恢复回购授权；股息增速止跌

**减仓 / 回避**
1. Azure 新口径 <42%，同时 Cloud 毛利率继续下滑、capex 再上调
2. 商业席位增速 ≤4%——Agent 架空席位的早期信号
3. RPO 环比增量又主要来自 OpenAI；OpenAI 融资遇阻、削减 Azure 消耗
4. 欧盟 DMA 终裁附带具体许可或互操作义务
5. 十年期美债站稳 5.5% 以上而 FCF yield 仍低于 2%

### 7.4 10-28 财报必查清单（8 个数）

Copilot 付费席位 ｜ ARR / attach ｜ Credits 收入 ｜ M365 商业云增速 ｜ Azure vs +44–45% 指引（新口径） ｜ Agents and Infra 毛利率 ｜ RPO 及 OpenAI 占比 ｜ 现金 capex + 新签融资租赁

## 8. 总结

微软这 54 天做对了三件事：把 Copilot 从「席位加价」改成「席位 + 计量表」，把 Azure 从口头口径改成 $1,019 亿的可审计数字，把推理成本路线交给自家 Maia 300。这三件事都让生意更好懂、更可验证，所以四个大师视角里三个维持原星。

但同一份 10-K 卖贵了 13%，而无风险利率从 4.3% 升到 5.2%。可持续 PE 32x、P/FCF 60x、FCF yield 1.66%——按利润倍数微软只是回到自己的十年中位，按现金倍数它比过去五年任何时候都贵。巴菲特视角降一星，综合分从 3.5 到 3.25。

反面也要摆出来：法律风险不大、管理层没犯错、OpenAI 股权是一张不小的期权、GAAP PE 并不离谱。如果 10-28 交出 Azure ≥44% + FCF 转正 + Copilot ARR，这份报告的估值判断会被打脸，财务组已明说届时回到 ★★★。在那之前，**好生意、贵价格、财报前两周——观望**。

**综合评分：3.25 / 5。立场：观望（维持），参考价带下移至 $440–480 加仓线。** 建议 10-28 财报后 1 周内复审。
