**A级研究声明**

资料多 ≠ 确定性高。微软是全球被定价最充分的公司之一，默认输出极易写成「云+Office 双轮、AI 加速」。本底稿的工作不是证明微软「很好」，而是检验三件事：

1. **Copilot 3000 万席位是不是把 Office 从「订阅税」改成「被 ChatGPT 抽走意图」之前的最后一次加价？** 席位 ≠ 净增量 ARR。
2. **Azure +43% 有多少是产能释放 / 合同 mix / GitHub Copilot 计价变更，而不是可持续需求？** 「客户需求超过供给」是护城河还是 capex 无底洞的借口？
3. **这门生意对用户还有没有定价权，还是只对 CIO 预算有锁定？** Windows/Office 转换成本 vs 云支出可被 AWS/Google/自建替代。

## 1. 生意本质：不是「AI 公司」，是三层税

段永平问的第一句永远是：这门生意到底卖什么、向谁收钱。

微软今天收三层税，税率和可替代性完全不同：

| 层 | 收税对象 | 收费方式 | FY2026 量级 | 可替代性 |
|----|----------|----------|-------------|----------|
| **第一层：知识工作税** | CIO / 采购，不是点击 Copilot 的员工 | M365 席位 + E5/E7 升级 + Copilot 附加 | M365 商业产品+云 **$1020 亿** | 极低（身份、邮件、文件、合规缠在一起） |
| **第二层：算力税** | CIO / 开发者 / 前沿实验室 | Azure 消费 + 预留 + 承诺 | Azure 口头超 **$1000 亿**；Server+云 **$1294 亿** | 中高（AWS 仍更大，新 AI 负载可多云） |
| **第三层：开发者工作流税** | 工程师个人习惯 + 企业 DevOps | GitHub 席位 + 从 2026-06 起的用量计价 | 含在「Azure and other」里，**公司不拆** | 中（代码托管有网络效应；模型层可换） |

外加：LinkedIn 对招聘预算收税（$198 亿）、搜索对广告主收税（$152 亿）、Xbox 对玩家收税（$218 亿，在掉）、Windows OEM 对 PC 厂商收税（Windows+Devices $171 亿，Q4 −7%）。

**观点：** 市场把这三层打包叫「AI 转型」。事实结构是——第一层是近乎年费的安装基础，第二层正在变成资本密集的公用事业，第三层把「按席位卖插件」改成「按 token 卖用量」。AI 不是第四层护城河，是第二、三层的新计价单位。

**反面：** Nadella 自己在电话会把目标说成「每个企业建自己的学习闭环，不要把核心 IP 外包」。如果成真，微软卖的是 **harness（缰绳：身份、合规、Agent 365、Graph）** 而不是模型。那第一层税会更宽。问题是 harness 的定价权取决于员工是不是每天打开 Copilot，而不是 CIO 有没有签字。

本维评分 **生意本质清晰度：★★★★**（旧生意五星清楚，新计价单位故意不透明）。

## 2. 飞轮：旧飞轮还在转，新飞轮的轴承是 capex

### 2.1 旧飞轮（能看懂）

```
Windows 预装 → Active Directory / Entra 身份
    → Office 文件/邮件/日历进 Graph
        → Teams 把沟通锁进同一租户
            → 安全/合规（Purview、Defender）变成「已经买了」
                → CIO 续约，ARPU 靠 E3→E5→E7 爬坡
```

这条链 20 年了。FY2026 商业 M365 付费席位仍 +6%，ARPU 靠 Copilot、E5、E7。这是飞轮，不是故事。

### 2.2 新飞轮（公司在讲、数字对不上）

```
Copilot 席位 → 用量上升 → Azure token 消费
    → 需要更多 GPU → capex
        → 「需求超过供给」→ 可以涨价 / 排期
            → RPO 膨胀 → 再 capex
```

电话会硬数据：

- Copilot 工作负载吞吐自财年初 **4 倍**；
- Foundry「年化 1 万亿 token」客户数 **同比 4 倍**；
- Q4 又上线 **1 GW** 产能，两年内产能大约翻倍；
- Maia 200「比最新一代硬件每美元性能高 30%」，同时服务 OpenAI 和 MAI。

**反面检验：** 如果飞轮成立，FCF 不应在收入 +18%、经营利润 +21% 的年份往下走。事实是 FY2026 FCF **$670 亿 vs 上年 $716 亿**。飞轮的「转」目前表现为资产负债表上的 PP&E，不是股东口袋里的现金。Hood 的辩护是短寿命资产可随需求减速而减速——这是**观点**，不是已验证的历史。上一次「需求永远超过供给」的叙事（2021–2022 云）以消化产能和增速回落结束。

本维评分 **飞轮：★★★★**（旧飞轮五星，新飞轮三星，综合四星）。

## 3. 护城河逐项打分（禁止把「AI」写成一种护城河）

### 3.1 品牌  ★★★★

**事实：** Windows / Office / Azure / GitHub / LinkedIn 是全球级品牌。搜索（Bing/Copilot）和 Xbox 不是。Q4 Xbox 内容与服务 **−10%**，Windows OEM 与设备 **−7%**——品牌没有阻止消费端下滑。

**观点：** Copilot 的品牌不是「用户爱用的助手」，是「CIO 买得安全的那一款」。Microsoft 自己的对比页强调 Graph、Purview、Entra，不强调模型谁更聪明。这是合规品牌，不是消费品牌。

**反面：** 苹果的品牌溢价由用户支付；微软的品牌溢价由采购委员会支付。用户在浏览器里打开 ChatGPT，并不觉得自己「离开了微软」。品牌护城河对 CIO 宽、对终端用户窄。给四星不是五星，因为五星要求用户愿意为牌子多付钱。

### 3.2 转换成本  ★★★★★（身份/Office 地产） / ★★★（Azure IaaS） / ★★（Copilot 本身）

必须拆开，否则「微软转换成本极高」是正确的废话。

| 资产 | 转换成本 | 证据 |
|------|----------|------|
| Entra / AD + Exchange + SharePoint + Teams | **极高** | 十年邮件、权限、合规审计、混合身份。没有公开的大规模「整个企业迁出 M365」案例能在一年内完成 |
| Office 文件格式 + 宏 + Power Platform | **高** | Google Workspace 啃了教育/创业，没啃掉财富 500 的核心地产 |
| Azure 已有企业负载（AD 集成、混合云） | **中高** | 混合云是 10-K 自己写的差异化；但新 AI 训练/推理负载从第一天就可以多云 |
| Azure 新 AI 负载 | **中低** | Synergy 2026 Q2：AWS 28%、微软 20%、Google 15%。微软份额同比**持平** 20%，Google +2pct。AI 增量没有自动变成 Azure 份额 |
| Copilot 插件 | **低到中** | 席位可停；ChatGPT Enterprise 用连接器进 M365；Nadella 自己说「harness 与模型分离、模型可换」——这是在教客户：Copilot 不是锁 |

**观点：** 五星转换成本在第一层税，不在 Copilot，更不在 GPU 租赁。把 Azure 的转换成本写成和 Office 一样宽，是把两种生意当成一种。

### 3.3 网络效应  ★★★

| 产品 | 有没有网络效应 | 说明 |
|------|----------------|------|
| GitHub | **有** | 2.25 亿用户、Fortune 500 超 90%、1/3 的 PR 有 agent 参与（电话会）。开发者工具是真网络效应 |
| LinkedIn | **有** | 招聘双边市场，$198 亿，+11% |
| Teams | **弱网络效应** | 公司内部有，跨公司弱；Zoom/Slack 仍在 |
| Office | **几乎没有** | 你用 Word 不取决于邻居用不用；这是标准+文件锁，不是网络 |
| Azure | **没有** | 云是规模经济，不是网络效应。客户变多不会让下一个客户的 Azure 更好用，只会让排队更长 |
| Copilot | **没有** | 你的 Copilot 不会因为别人也买了而变得更准。数据在租户里，不在公共网络里 |

**反面：** 把「安装基础」说成网络效应，是卖方最爱的概念偷换。安装基础是转换成本。GitHub 才是网络效应。Azure 是规模。不要混。

### 3.4 规模  ★★★★

**事实：** 10-K 自己写云业务的三个规模经济：更低单位计算成本、需求汇聚提高利用率、多租户摊低运维。FY2026 Microsoft Cloud **$2144 亿**，毛利率电话会 **65%**（好于预期、同比下降）。Q4 又加 1 GW。这是真规模。

**反面：** 规模正在变成**入场券**。日历 2026 capex 底层预期不变、只是租赁科目搬家；Q1 FY2027 capex >$500 亿。AWS、Google、Oracle、一串 neocloud（Synergy 点名 CoreWeave、OpenAI 自己、Crusoe、Nebius）在同一赛道烧。当所有人的 capex 都是「需求超过供给」，规模优势的增量回报下降。Hood 说短寿命资产可减速——这也意味着规模壁垒的折旧年限只有两三年（GPU），不是数据中心的 25 年。

给四星不是五星：规模极大，但可复制的资本开支正在把「规模」从护城河改成军备竞赛。

### 3.5 技术  ★★★

**事实，不是段子：**

- 微软**不是**前沿模型的第一名。10-K：AI 产品与超大规模、新兴对手、开源竞争；战略伙伴「许多在某些产品上与我们竞争」。
- 电话会：模型目录 **1.1 万+**（OpenAI、Anthropic、Mistral、xAI、自研 MAI）。Nadella 的架构原话：「把 harness 和模型分开……任何模型在任何时候都可替换。」
- 自研：Maia 200、Cobalt、MAI-Code / MAI-Voice / MAI-Image。Dynamics 用 MAI-Voice-2-Flash 降 GPU 成本 89%，PowerPoint 用 MAI-Image-2.5 降 84%——这是**应用层效率**，不是模型领先。
- GitHub Copilot 上 MAI-Code-1-Flash：更高代码接受率、中位 token 用量 −10%。

**观点：** 技术护城河在「把模型接到企业身份和数据上的工程」，不在模型本身。Nadella 公开把模型降级为「输入」，等于承认模型不是护城河。这是诚实，也是弱点：如果工程可被复制（Google 有 Workspace+Gemini，Amazon 有 Bedrock），技术壁垒只剩执行速度。

**反面：** 有人会说「多模型目录本身就是技术护城河」。目录是采购关系，不是技术。开源权重和 API 让目录的差异化衰减。

**禁止：** 把「AI」单独列为一类护城河。AI 是产品功能，可能强化转换成本或强化规模，本身不是河。

### 3.6 OpenAI 关系：资产还是反护城河（必须单独写）

**事实（10-K + 两季电话会）：**

| 项目 | 数字 / 条款 | 来源 |
|------|-------------|------|
| 合伙起点 | 2019；**2025-10 和 2026-04** 两次延期 | FY2026 10-K |
| 股权 | 约 **25%**（as-converted），权益法 | 10-K Note |
| 已出资 / 承诺 | 已投 **$119 亿** / 承诺 **$130 亿** | 10-K |
| FY2026 来自 OpenAI 的收入（含分成） | **$241 亿** | 10-K 关联方披露 |
| 占公司总收入 | **7.3%**（$241 亿 / $3318 亿） | 手算 |
| 2026-06-30 应收 OpenAI | **$60 亿** | 10-K |
| FY2026 Q2 商业 RPO | $6250 亿，约 **45% 来自 OpenAI** ≈ **$2810 亿** | Q2 电话会（Hood 原话） |
| FY2026 Q4 商业 RPO | **$6780 亿 +84%**；**剔 OpenAI 后 +25%**；环比增量「全部来自非前沿模型公司」 | Q4 电话会 |
| 若 OpenAI 承诺环比大致不变 | OpenAI 约占 Q4 RPO **~41%**（$2810 亿 / $6780 亿） | **估计**，公司 Q4 未重述 45% |
| IP | 「持有 OpenAI IP（含模型与基础设施）用于集成」+ 继续收分成 | 10-K |
| 治理 | 2025-10 OpenAI 重组为公益公司并 recap；微软确认**比例所有权下降**，记稀释利得 | 10-K |
| 投资损益 | FY2026 净利得 **$49.6 亿**（Q4 +$4.8 亿）；FY2025 净亏损 $36.2 亿 | EX-99.1 |
| 客户集中 | 「除美国外，无单一客户或国家占收入 >10%」 | 10-K ——所以 OpenAI 7.3% 刚好不必点名，但关联方必须披露 |

Microsoft Cloud 全年「近 90% 来自前沿模型公司以外」——电话会。10% × $2144 亿 ≈ **$214 亿**，与 OpenAI $241 亿量级吻合（分成可能有一部分不进 Cloud 口径）。

**资产侧：** $241 亿已确认收入；超 $1000 亿 Azure 里有一块是这家实验室的训练/推理；IP 使用权仍在；分成条款仍在。没有 OpenAI，Azure 过 $1000 亿的时间表会更晚。

**反护城河侧：**

1. **RPO 集中。** +84% 的海报数字，剔 OpenAI 只剩 +25%。+25% 仍然很好，但和海报不是同一件事。持续时长加权平均 **2.3 年**，未来 12 个月只确认约 30%——长单把风险推到后面。
2. **客户即对手。** ChatGPT Enterprise 与 Copilot 在 2026 年是 Gartner 专题对标的一对（2026-07-09 文档 8114797）。10-K 自己写：伙伴「许多在某些产品上与我们竞争」。
3. **模型可被开源/多模型替代。** Nadella 电话会第一问就在回答这个：开源+自训、harness 与模型分离。公司战略与「OpenAI 独家」在逻辑上互斥。
4. **治理看不懂。** 公益公司、recap、25% as-converted、HLBV 核算、稀释利得进「其他收益」。董事会权利、产能优先权、如果 OpenAI 把训练搬到自建/Oracle/CoreWeave 会发生什么——**10-K 用风险因素覆盖，没有可验证的硬约束披露。** 按段氏纪律：**看不懂，不假装懂。**
5. **应收 $60 亿。** 不是小数字。关联方信用与结算条款，外界看不到。

**观点：** 这是一张**不对称期权**：上行是分成+Azure 消费+IP；下行是最大客户变成最大竞争对手、且 RPO 的四成系在一个对手身上。把它写成「战略护城河」是偷懒。更准确的标签是：**高相关性的大客户 + 正在贬值的独家叙事。**

OpenAI 关系单独评分：**资产 ★★★ / 反护城河风险 ★★★★**（不作综合星，避免平均掉关键风险）。

## 4. 必须回答的反面三问

### 4.1 Copilot 3000 万席位：最后一次加价，还是新税种的开始？

**公司披露了什么（事实）：**

| 时点 | 付费 Copilot 席位 | 来源 |
|------|-------------------|------|
| FY2026 Q2（2026-01） | **1500 万**（首次给出数字） | Q2 电话会 |
| FY2026 Q3（2026-04） | **超过 2000 万** | Q3 电话会（CNBC / CIO Dive 复述） |
| FY2026 Q4（2026-06） | **超过 3000 万**；净增席位环比**翻倍以上** | Nadella + Hood，Q4 电话会 |
| >5 万席位客户数 | 同比 **超 7 倍** | 电话会 |
| 「把 Copilot 铺到过半信息工作者」的企业客户 | 环比 **近 +75%** | 电话会 |
| 大单样例 | NHS England **50.5 万**；KPMG **>27.6 万**；HSBC **20 万**；EY 上 E7 **40 万** | 电话会（样例，非统计） |
| 商业 M365 付费席位 | **+6%** YoY；增量主要在 SMB 和一线工人（更低 ARPU） | Hood |
| 商业 M365 云收入 | 报表 +14%；剔除上年「期内确认」2 个点后 **+16%** | 新闻稿 |
| 公司对 Copilot 的 ARR / attach / 净保留 / 折扣 | **未披露** | — |

**公司没有披露、因此不能假装知道的：**

- Copilot 净增 ARR（美元）
- attach rate（Copilot 席位 / 商业 M365 席位）
- 净美元保留、logo 流失、席位流失
- 实际 ASP（目录价 $30/用户/月 vs 企业折扣）
- 已购席位的周活 / 日活（Nadella 说「使用强度已与 Outlook/Teams 相当」——没有给出百分比分母）
- E7 把 Copilot 打进套餐后，多少「Copilot 席位」只是 SKU 升级而非净增附加

**分母只能估计：** 公司 Q2 说商业 M365「超过 **4.5 亿**」席位（450 million；Directions on Microsoft / Office 365 IT Pros 转述电话会）。Q4 席位 +6% YoY，若以 4.5 亿为起点外推，分母约 **4.50–4.77 亿**。3000 万 / 4.5 亿 ≈ **6.7%**；/ 4.64 亿（第三方把半年增长对半计入）≈ **6.5%**。**这是估计，不是披露。** 公司拒给 attach。

**目录价毛估：** 3000 万 × $30 × 12 = **$108 亿 ARR**。企业折扣 40–60% 在行业里常见（卖方估计，非公司数字）→ 可能 **$50–70 亿**。相对 Microsoft Cloud $2144 亿，这是 2–5% 的附件，不是新引擎。相对 M365 商业 $1020 亿，是高个位数——有意义，但撑不起「AI 重估」的叙事。

**「最后一次加价」的证据链：**

1. 商业席位量只 +6%，还是低 ARPU 的 SMB/一线在拉；收入 +14–16% 靠 ARPU。ARPU 的三个钉子是 Copilot、E5、E7。钉子钉在同一块木头上。
2. 2026-07 商业套餐目录价上调（E3 等 +$3/用户/月量级，行业媒体；**独立 Copilot SKU 据称大体不动**）。消费端 M365 云 +24%「还是 ARPU」；FY2027 Q1 指引消费云回落到「teen 中段」，因为** laps 去年涨价**。涨价是可验证的、也是可 laps 的。
3. Nadella：**从 per-seat 走向 per-seat-plus-consumption**。这句话的反面读法：纯席位税碰到了天花板，必须用用量再榨一层。正面读法：TAM 变大。两种读法目前都缺用量美元。
4. 意图层：ChatGPT 是员工自己打开的盒子；Copilot 是 IT 配发的盒子。Gartner 2026-07 把两者写成「伙伴但企业策略日益竞争」。多家实施商的 2026 框架是「两个都买」——意味着 Copilot **没有**把意图独占，只是占了「在 Word 里改文档」这一格。
5. Copilot Chat 已塞进 M365 不另收费（公司与行业报道）。免费层是防守界面，不是加价。

**反面论据（必须并列）：**

- 净增席位一个季度从 ~2000 万到 >3000 万，不是「滞销清库存」的形状。
- 使用潜伏期「从月降到天」、使用强度对齐 Outlook/Teams——如果属实，货架席位（shelfware）的旧指控在弱化。**未给审计数字，置信度：中。**
- E7 + Agent 365 把 Copilot 焊进 SecOps/FinOps。焊得越深，越不像「可撤的插件」。
- 1500 万 → 3000 万只花了两个季度。按这个斜率 attach 从 3.3% 到 6.5%，离「饱和加价」还远。**斜率能否维持是未知数。**

**本问结论（观点）：** 3000 万是**真实的部署加速**，不是虚假席位；但它**不是**净增 ARR 的硬证据，更不是「Office 税升级成功」的硬证据。在公司拒绝披露 attach 和净保留之前，把席位当收入是分析纪律的失败。最危险的假设是：这些席位会按 $30 续、且不会被 ChatGPT 连接器掏空「空白页意图」。

本问评分：**席位增长可信 ★★★★ / 变现质量不可知 ★★**。

### 4.2 Azure +43%：产能释放，还是需求政权？

**公司自己把超预期拆成三块（Hood 准备稿，原话结构）：**

1. **CPU/GPU 机群效率**提升，多挤出的产能「当季立刻变现」——因为需求仍超过供给；
2. **流程改进**让新产能更早交付（码头到上线时间，最大区域近 −50%，Nadella）；
3. **GitHub Copilot** 在 2026-06 改成按用量计价后，消费「强于预期」。

另外：YoY 增速「会因**产能时点**和**合同 mix** 而季季波动」——Hood 每个季度都提醒，Q4 又说了一遍。Q1 FY2027 指引 Azure 恒币约 **+45%**，上半年继续加速。

**因此 +43% 里有多少是「可持续需求」？公司没有给百分点拆分。** 能确定的只有：管理层把「打赢指引」归因于供给侧和一次计价变更，而不是「需求突然上台阶」。需求「超过供给」已经讲了多个季度，是背景，不是本季增量解释。

**「需求超过供给」的双重身份：**

| 当作护城河 | 当作 capex 借口 |
|------------|-----------------|
| 稀缺产能 → 现货价、承诺价有支撑；Hood 提到现货市场定价 | 不扩容就丢份额；扩容就把 FCF 吃掉 |
| RPO $6780 亿，剔 OpenAI 仍 +25% | 其中仍有 ~40% 量级绑在一个前沿实验室（Q2 硬数 45%，Q4 未更新） |
| 短寿命资产 2/3，需求若降温可减速采购 GPU | GPU 两年一折旧，减速采购 = 承认增速叙事结束 |
| Cloud 毛利率 65%，好于指引 | 同比仍在掉：结构转向 Azure + 提前建 AI 基础设施 + 产品用量上升 |

**份额事实（日历 2026 Q2，Synergy，与微软财季错位一个季度，仍是最新独立份额）：** AWS **28%**（同比 −2pct）、微软 **20%**（同比持平）、Google **15%**（同比 +2pct）。全球云基础设施支出 +43%——与 Azure +43% **同一量级**。观点：微软在一个整体加速的市场里**保住第二**，没有在吃 AWS 的午餐；正在吃份额的是 Google。把 Azure +43% 读成「赢了云战争」与份额数据冲突。

**GitHub 计价变更是一次性 mix：** 「Azure and other」含 GitHub。用量计价让原来锁在席位里的消费爆出来，+60% QoQ 的「Copilot 收入」（电话会放在 GitHub 段）会抬高本季 Azure 增速，**不会**按同一斜率再抬四个季度。公司未量化贡献了几个点。

**capex 无底洞？不完全是，但方向是重资产化。**

- Q4 FCF $196 亿，同比 **−23%**（CNBC 口径与 EX-99.1 手算一致：CFO $554 亿 − PP&E $358 亿）。
- 全年 FCF 仍 **$670 亿**，只是利润率从 25.4% 压到 20.2%。
- Hood：FY2027 仍 FCF 为正；经营利润率全年只掉不到 1 个点。
- 会计小动作：使用寿命 15→25 年，更多租赁改经营租赁，capex 指引从市场盛传的 ~$1900 亿「降」到 ~$1750 亿。**投资没减，科目换了。** 把 $1750 亿读成「微软在砍 capex」是阅读障碍。

**本问结论（观点）：** +43% 是**真需求背景下的供给释放季**，叠加一次 GitHub 计价变更。可持续需求大概在「高 30%–低 40%」区间——这是推测，公司没给。把它外推成「Azure 进入 45%+ 永续」会被产能时点和 OpenAI 合同到期打脸。需求超过供给**既是**短期定价权**也是**被迫投资；两者同时为真，不是二选一。

本问评分：**需求真实性 ★★★★ / 增速可外推性 ★★★ / 资本循环 ★★★**。

### 4.3 定价权在用户，还是只在 CIO？

先分清三个付钱的人：

| 付钱的人 | 产品 | FY2026 / Q4 信号 | 定价权 |
|----------|------|-------------------|--------|
| **终端用户 / 家庭** | M365 消费订阅、Xbox、Search | 消费云 +24%（ARPU）；Xbox Q4 −10%；Search ex-TAC +10% | 消费订阅还有；游戏在丢；搜索是广告不是用户付费 |
| **PC 买家（经由 OEM）** | Windows OEM | Q4 **−7%**；全年「略降」 | **弱**。Windows 10 支持已结束后的消化期 + PC 周期，用户不直接给微软开支票 |
| **CIO / 采购** | M365 商业、Azure、E5/E7、GitHub Enterprise | 席位 +6%、ARPU 升、Azure 排队 | **强**，但这是预算锁定，不是爱 |

**用户侧的裂缝：**

- 知识工作者的「空白页意图」（写、问、想）正在流向 ChatGPT / Gemini。Copilot 赢的是「在已打开的 Word/Excel/Outlook 里改」。这是**场景锁**，不是**意图锁**。
- 微软自己把 Copilot Chat 做成 M365 标配、不另收费——说明在用户意愿付费这一层，公司选择了防守而不是收费。
- Windows OEM −7%、Xbox −10%：对**不经过 CIO** 的用户，微软本季在退。MPC 分部收入 Q4 −4%，经营利润 $27.5 亿 vs 上年 $31.9 亿。

**CIO 侧的锁：**

- 身份、合规、审计（Purview 已审计超 500 亿次 Copilot 交互，同比 +360%）是采购理由，不是用户理由。
- E7 = Copilot + E5 + Entra + Agent 365。Hood：上线两个月，「数百家企业、数百万席位」。这是把 AI 卖进**治理预算**，不是卖进员工的心。
- Azure：CIO 可以、而且正在多云。10-K：Azure 竞争来自云厂商和开源；AI 负载尤其如此。转换成本保护的是旧负载，不是新训练集群。

**段永平会怎么问：** 「涨价了用户会不会跑？」Office 涨价，员工无处可跑，因为邮箱还在。Copilot 涨价或打折，员工可以开 ChatGPT。Azure 涨价，新项目可以去 AWS/Google/自建。所以：**定价权对 CIO 的存量地产是真的，对用户的增量意图和对云的增量负载不是同一等级。**

**反面：** 企业软件从来都是卖给 CIO 的。要求微软有苹果式的用户热爱，是错的能力圈。M365 消费 +24% 证明至少有一群人自己掏钱。GitHub 2.25 亿用户是自下而上的。不是「只有 CIO」。但**增量 AI 定价**目前明确是自上而下。

本问评分：**对 CIO 存量 ★★★★★ / 对用户意图 ★★★ / 对可迁移云负载 ★★★**。综合定价权 **★★★★**（被第一层税拉高，被第三问的裂缝扣掉一星）。

## 5. 用户价值：为谁创造了不可替代的东西？

段永平：「用户导向而非利润导向。」微软的「用户」一直是分裂的。

| 角色 | 独特价值 | 不可替代？ | 2026 年的变化 |
|------|----------|------------|---------------|
| 知识工作者 | 文件、邮件、会议在一个身份下 | 套件内不可替代；**AI 助手可替代** | Copilot 若不如 ChatGPT 好用，员工会「双开」 |
| IT / 安全 | 一套身份走完设备、云、AI 审计 | 高 | Agent 365、Purview 让 IT 更离不开 |
| 开发者 | GitHub + VS + Azure | GitHub 高；Azure 中 | 用量计价后，价值与账单同时上升 |
| 游戏玩家 | 主机+Game Pass | 低 | 收入在掉，减值在发生 |
| 广告用户 | 搜索结果 | 低 | Copilot 入口在抢 Bing 的问句，效果不明 |

**观点：** 2026 年微软把资源从「让员工更爽」转向「让 IT 能管住 token」。E7 的卖点是 FinOps/SecOps，不是更好的写作体验。这是合理的企业软件进化，也是对段氏「用户导向」的偏离。利润可以继续来自 CIO；长期风险是员工的工作习惯迁到别的盒子，CIO 最后只能买一个空壳席位。

**反面：** NHS「人均每天省 43 分钟」这类案例如果可规模化，用户价值就是真的。目前是精选案例，不是抽样。

本维评分 **用户价值：★★★★**（对组织五星，对个人三星）。

## 6. 业务矩阵与协同

```
                    ┌─ Entra 身份 ─────────────────┐
                    │                              │
 Windows ─── M365 ──┼── Graph / 文件 / 会议 ── Copilot / E7
                    │                              │
                    └─ Purview / Defender ─────────┘
                              │
                         Azure 消费（token + 常规 IaaS）
                              │
              GitHub ── 开发者 ── Foundry 多模型
                              │
                         OpenAI / Anthropic 既是供应也是客户
```

**真协同（有数字）：**

- M365 Copilot 用量上升 → Hood 承认 PBP **毛利率因 Copilot 用量微降**，同时 IC 吃到 GPU 消费。协同是「左口袋的毛利换右口袋的收入」，不是免费午餐。
- GitHub Copilot 改用量计价，直接记入 Azure and other，拉动 +43%。协同是会计上的，也是产品上的。
- 安全：500 亿次 Copilot 交互进 Purview。AI 把安全从「另卖的产品」变成「AI 要能卖出去的前提」。

**假协同 / 负协同：**

- Xbox、Windows OEM 与云几乎无协同。Activision 收购后的内容与服务 Q4 −10%，电话会承认减值。这是资本配置问题，交给风险/管理层那一维，这里只记：消费矩阵在拖。
- OpenAI 既贡献 $241 亿收入，又在企业助手市场抢 Copilot。协同与竞争写在同一张合同里。
- Anthropic：Q4 投资收益 $32 亿，Foundry 上架 Claude。对客户是多模型；对 OpenAI 关系是对冲；对报表是一次性收益。三件事不要并成「AI 生态飞轮」。

**简单到能看懂的矩阵：** 办公（高利润、中增长）+ 云（中利润、高增长、高 capex）+ 其他（LinkedIn 稳、搜索稳、Xbox/Windows 弱）。FY2026 收入结构：PBP 42% / IC 42% / MPC 16%。利润结构更斜：PBP 经营利润 $839 亿（54% 的经营利润）对 IC $570 亿。**利润还在第一层税，增长叙事在第二层税。**

本维评分 **业务矩阵：★★★★**。

## 7. 段永平「好生意」标准

| 标准 | 判定 | 说明 |
|------|------|------|
| **简单，能看懂吗？** | **一半能，一半不能** | 能看懂：向企业收身份+办公年费，利润率 60%。看不懂：token 单位经济（每席位 GPU 成本、Azure AI 毛利、承诺合同的实际消耗曲线）、OpenAI 治理（25% as-converted、分成、产能优先、公益公司董事会）。**不假装懂。** |
| **差异化？** | **有，但是分层的** | 差异化在 Graph+身份+合规，不在模型，不在 GPU。模型层微软自己都说可替换。 |
| **对谁有定价权？** | **对 CIO 的存量地产有；对用户意图和可迁移负载弱** | 见第 4.3 问。消费端 Windows/Xbox 正在给负分。 |
| **可持续竞争优势？** | **第一层是；第二层是军备；第三层未证实** | Office 税能再收十年的概率高于 Azure 41% 增速能再维持三年的概率。 |
| **轻资产？** | **正在变重** | PP&E $3131 亿，一年 +53%；FCF 利润率 20%。还不是航空公司，已经不是 2019 年的微软。 |
| **用户导向？** | **组织导向** | E7、Agent 365、Purview 是给 IT 的。Copilot Super App 是在追用户，尚未用独立留存数据证明。 |
| **不为清单** | **部分踩线** | 「不盲目多元化」：游戏收购的回报本季看起来差。「不轻易收购」历史记录混杂。云 capex 不是收购，但是同一类「为了增长把模式改重」。 |

**段氏一句话（观点，不是事实）：** 这是一门**曾经极简的好生意**，正在被自己改成「好生意 + 一门看不太懂的资本密集生意」。看懂的那部分（办公税）质量仍高；看不懂的那部分（token 与 OpenAI）体量已经大到不能当期权忽略——OpenAI 相关收入已占公司 7%，RPO 曾占 45%。

**反面：** 2011 年的微软也被说「太复杂、Windows 已死」。Nadella 把复杂做成了云。这次也可能再做成。区别是：上次是把软件改成订阅，**更轻**；这次是把订阅改成电厂，**更重**。方向相反。

本维评分 **段氏好生意：★★★★**（第一层五星，整体被资本密度和「看不懂」扣到四星。达不到五星：五星是「简单、轻、对用户有定价权」——苹果 2016、茅台。微软 2026 不是）。

## 9. 给 team-lead 的 5 条最重要发现

1. **利润还在第一层税，海报数字在第二层税。** FY2026 经营利润 $1552 亿的 54% 来自 PBP（办公/LinkedIn/Dynamics），不是 Azure。Azure 全年口头超 $1000 亿、+41%；Microsoft Cloud $2144 亿、毛利率 65% 但在掉。把公司当成「AI 云」会看错谁在付账单。
2. **3000 万 Copilot 席位没有配套的 ARR / attach / 净保留。** 相对约 **4.5 亿+** 商业席位，attach 估计约 **6–7%**（第三方分母，公司未披露）。目录价毛估 $108 亿 ARR，折扣后可能腰斩。席位环比翻倍是真的；「Office 税升级成功」尚未被美元验证。公司同时把模式改成 seat+consumption，等于承认纯席位加价不是终点。
3. **Azure +43% 被管理层归因于供给释放 + GitHub 计价变更，不是需求上台阶。** 需求超过供给是多季背景。Synergy 日历 Q2：微软云基础设施份额 **20% 同比持平**，Google 在抢。全球云市场也是 +43%——微软在水涨船高，不是在独食。
4. **OpenAI 是资产也是反护城河。** FY2026 关联收入 **$241 亿**（7.3%）、应收 $60 亿；Q2 RPO 的 **45%（~$2810 亿）** 来自 OpenAI，Q4 总 RPO $6780 亿剔 OpenAI 仅 +25%。10-K：约 25% as-converted、IP 使用权、分成；同时承认伙伴是竞争对手。治理与 token 单位经济：**看不懂，不假装懂。**
5. **轻资产好生意正在被改写成电厂。** Q4 capex+融资租赁约 $410 亿（+69%），FY FCF $670 亿（−6.5%），PP&E $3131 亿（+53%）。经营利润率仍在扩（46.8%），所以不是崩，是**资本循环变差**。FY2027 Q1 capex >$500 亿；$1750 亿日历 capex 是科目重分类，不是减支。

### 最可能被打脸的假设

**假设：** 「CIO 锁定 + Copilot 使用强度对齐 Outlook，会把 6% attach 在 2–3 年内做成高双位数，且 Azure 在产能释放后仍能维持 40% 左右增速，同时 FCF 利润率止跌。」

打脸路径（任一即可）：

- Copilot 席位继续涨但 ASP/用量不涨（货架席位回流，或 E7 只是把 $30 附加塞进套餐折扣）；
- 员工意图继续迁到 ChatGPT，CIO 开始砍未使用席位；
- OpenAI 训练/推理迁走或分成条款重谈，$241 亿关联收入和 RPO 的四成同时松动；
- GPU 供给缓解后「需求超过供给」消失，Azure 增速回落到与份额（20%）匹配的市场增速之下，capex 却因长单无法立刻降。

**反面：** 若 E7+Agent 365 真把 token 治理焊进 IT 操作系统，attach 和用量会比席位数字更快变成收入——那是本底稿最该承认可能错的方向。

## 10. 本维总结

微软 2026 年 8 月的生意，拆开看仍是一门**对 CIO 收税的好生意**：身份、办公、合规的转换成本没有消失，PBP 经营利润率 60%，公司仍在用美元利润而不是故事支付分红回购。被市场定价的那部分——Copilot 席位、Azure +43%、RPO +84%——经不起同样的纪律：席位没有 ARR，增速含供给和计价噪音，RPO 含一个既是客户又是对手的实验室。

段永平框架下的刺：这门生意**还看得懂的一半**（办公税）质量足够；**看不懂的一半**（token 经济、OpenAI 治理、GPU 资本回报）已经重到不能用「长期期权」四个字打发。不因为看不懂就宣布它是坏生意——那是另一种装懂。

本维综合：**★★★★**。不给仓位建议。不构成投资建议。
