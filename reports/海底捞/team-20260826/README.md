## 核心结论

- **综合评分：2.75 / 5**（上轮 2026-08-21 为 3.0 / 5）
- **一句话**：同店从 −9.9% 收窄到 −1.34%，是两年来最好的经营信号；但归母 +0.47% 是折旧红利与非经常项恶化互相抵消的结果，真实经营利润零增长，增量 147% 来自公司拒绝披露利润率的低毛利业务。**经营在止血，护城河在退，估值反而变贵。**
- **建议**：**持有收息，不加仓，不减仓**。稳健型加仓条件为价格 ≤ HK$10 或同店连续两期转正。
- **单一最大变量**：9 月中期报告里的**现金流量表**——三期业绩公告均无此表，巴菲特框架最核心的利润质量检验本期整体缺席。

## 本轮最有价值的四处分歧裁决

1. **25.62 亿短债是加杠杆还是再融资** → 两位分析师各对一半：全期看有息负债只净增 1.34 亿（债务置换），但利息倒推显示这笔钱 6 月才提、只存续 6–23 天，紧邻 18.16 亿末期股息。
2. **翻台 3.8→3.9 是回升还是假象** → 结构效应。同店翻台 3.9→3.9 持平，倒算客流仍 −3.11%。
3. **定价权在流失还是同业最强** → 绝对口径在退（vs 2019 单桌日产出 −25.1%），相对口径最强（−0.92% 是同业最小跌幅）。两者都对。
4. **二线 −8.04% 是需求塌陷还是关店口径** → 门店 −6.45% × 单店 −1.70%；二线单店跌幅其实好于三线（−2.25%）。
