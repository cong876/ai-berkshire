# 海底捞（6862.HK）投资研究索引

## 最新结论（2026.08.26 · 2026H1 中报口径）

- **综合评分：2.75 / 5**
- **一句话**：同店从 −9.9% 收窄到 **−1.34%**，是两年来最好的经营信号；但归母净利 **+0.47%** 是折旧红利（2.48 亿，资产折完的机械结果）与非经常项恶化互相抵消后的"持平"，真实经营利润**零增长**，增量 147% 来自公司**拒绝披露利润率**的低毛利业务。经营在止血，护城河（定价权）在退，估值反而从 13.24x 涨到 **14.05x**。
- **建议**：**持有收息，不加仓，不减仓**。稳健型加仓条件：价格 ≤ HK$10（≈11.8x PE）或同店连续两期转正。
- **单一最大变量**：9 月**中期报告**里的现金流量表——三期业绩公告均无此表，股息可持续性无法确认。

### 2026-09-09 · 投资论文追踪（长期维护）📌
[海底捞-thesis.md](海底捞-thesis.md) — 论文回溯重建 + 第一次追踪检查

> **健康度 1/10**（机械与严重程度加权两种算法同分）。8 条核心假设：🟢 成立 2（同店、净现金）｜🟡 弱化 4（翻台率、**股息支付能力**、第二曲线、估值）｜🔴 **受损 2**（**股息水平 −19.60%**、**管理层利益一致**）｜⚫ 破裂 0。红线 **#8 创始人家族大规模非计划性减持已触发**。
> **股息一节已修订**：「股息不可持续」的判断**已撤回**——FY2025 股息/OCF 由 79.5% **改善**至 73.0%（覆盖 **1.37x**），支付能力充裕；股息/FCF 虽由 95.8% 恶化至 103.5%（覆盖 0.97x），但缺口仅 1.41 亿 vs 净现金 84.55 亿，且差额全部来自 CAPEX **+28.8%**（重新开店 + 改造 200+ 家门店，属扩张性投资）。**受损的是股息水平（收益率下行），不是支付能力（本金风险）。**
> **⚠️ 论文的原始缺口**：8/26 建仓时，报告对"合理的价格"打的就是 ❌（14.05x、现价高于 DCF 中位 18.5%）。**这是一个用股息率替代价格安全边际的论文**——而全年每股股息 FY2024 **0.898** → FY2025 **0.722**（**−19.60%**），打击的正是它最脆弱的那根支柱。
> **结论**：论文**受损**，非破裂；核心生意逻辑（同店修复、净现金）仍成立，今日下跌已交叉验证为股东名册事件。具体动作交回投资者。
