# 海底捞（6862.HK）投资研究索引

## 最新结论（2026.08.26 · 2026H1 中报口径）

- **综合评分：2.75 / 5**
- **一句话**：同店从 −9.9% 收窄到 **−1.34%**，是两年来最好的经营信号；但归母净利 **+0.47%** 是折旧红利（2.48 亿，资产折完的机械结果）与非经常项恶化互相抵消后的"持平"，真实经营利润**零增长**，增量 147% 来自公司**拒绝披露利润率**的低毛利业务。经营在止血，护城河（定价权）在退，估值反而从 13.24x 涨到 **14.05x**。
- **建议**：**持有收息，不加仓，不减仓**。稳健型加仓条件：价格 ≤ HK$10（≈11.8x PE）或同店连续两期转正。
- **单一最大变量**：9 月**中期报告**里的现金流量表——三期业绩公告均无此表，股息可持续性无法确认。
