## 2. 盈利能力分析

### 2.1 毛利率结构性拆解：为何总毛利率降 23.6pct，而云端毛利率转正到 24.6%？

这是本份中报最重要、也最容易被误读的一组数字。**两者同时为真，因为它们回答的是不同的问题。**

**公告原文分部毛利表（RMB 千元）**

| 分部 | 2026H1 毛利 | 2026H1 毛利率 | 2025H1 毛利 | 2025H1 毛利率 | 毛利率变动 |
|---|---:|---:|---:|---:|---:|
| 云端部署 | 202,871 | **24.6%** | (116) | **-0.4%** | **+25.0pct** ✅ |
| 本地化部署 | 48,740 | **37.9%** | 95,540 | **59.1%** | **-21.2pct** ❌ |
| **总计** | **251,611** | **26.4%** | 95,424 | **50.0%** | **-23.6pct** ❌ |

**FY2025 全年对照（年度业绩公告）**：云端部署毛利率由 FY2024 的 3.3% 升至 FY2025 的 18.9%；本地化部署由 66.0% 降至 48.8%；综合毛利率 41.0%。

### 拆解：这是一次纯粹的"结构性摊薄（mix shift）"

用最简单的算术还原（**验算见第 7 章工具输出**）：

**若收入结构不变**（云端 15.2% / 本地化 84.8%），用 2026H1 的分部毛利率：
- 加权毛利率 = 24.6% × 15.2% + 37.9% × 84.8% = **35.9%**

**实际收入结构**（云端 86.5% / 本地化 13.5%）：
- 加权毛利率 = 24.6% × 86.5% + 37.9% × 13.5% = **26.4%** ✅ 与报表一致

**结论（事实）**：23.6pct 的毛利率下滑可完整分解为两个独立成因：

| 成因 | 贡献 | 性质 |
|---|---|---|
| **① 结构摊薄**：高毛利的本地化业务占比从 84.8% 掉到 13.5%，让位给毛利率只有 24.6% 的云端业务 | 主因 | **中性/暂时**——若云端毛利率能爬坡，这一项会自我修复 |
| **② 本地化部署自身毛利率恶化**：59.1% → 37.9%，跌 21.2pct | 次因 | **负面/结构性**——高毛利业务本身也在失去定价权 |

### 云端毛利率从 -0.4% 到 24.6%：改善是真的，但要看基数

**公司给出的归因（公告原文 + 业绩会）**：
1. 单位 token 推理成本较年初下降约 **80%**（All-in-Infra 战略，国产芯片 10 万级规模化部署）
2. API 均价提高 **101%**（提价）
3. 调用规模扩大带来固定成本摊薄

**事实核验**：三个因素都是真实且可交叉验证的。**API 均价 +101% 而调用量仍暴增，是本份财报里唯一具有"定价权"含义的硬证据**——这一点在巴菲特框架下极其重要。

**但必须同时看到的反面**：

| 反面事实 | 数据 |
|---|---|
| 24.6% 的毛利率仍然**极低** | 对照：微软 Azure ~70%，AWS ~38%（含硬件），Adobe ~89%，甲骨文 ~70%。24.6% 更接近**代工/IDC 生意**的毛利率，而非软件生意 |
| 基数极低导致改善看起来很大 | 2025H1 云端收入仅 0.291 亿，毛利 -116 千元。**从 -0.4% 到 24.6% 的"转正"，起点是一个 2900 万元收入的实验性业务** |
| 本地化毛利率 21.2pct 的下滑是**同期发生**的 | 公司归因为"交付资源投入增加"与"产品结构变化"，但也可能反映本地化市场竞争加剧、议价能力下降。**数据不足以区分这两种解释** |
| 综合毛利率的修复**必须**靠云端毛利率继续大幅爬坡 | 因为云端已占 86.5%，本地化的分母权重只剩 13.5%，已无力拉动综合毛利率 |

**巴菲特点评**：
> "如果你必须每年重新证明自己的产品值这个价，那你就不是在做一门好生意。"

云端毛利率 24.6% 的背后是**每一次模型迭代都要重新采购/租赁算力、重新训练、重新竞价**。这与"一次投入、永续收租"的软件商业模式有本质区别。**这门生意目前的财务特征更像资本密集型的重资产服务业，而非轻资产软件。**

### 2.4 ROE / ROA：为什么这两个指标在这里**基本无意义**

**巴菲特最看重的指标 ROE，在智谱这里失效了。原因有三，必须说清楚：**

**原因一：分子为负，比率失去排序意义。**
ROE 为负时，亏损越大、权益越小，ROE 的负值反而越"大"（更接近 0 或更极端），无法用于横向比较。

**原因二：分母在报告期内发生结构性断裂。**

| 时点 | 归母权益（RMB 亿） |
|---|---:|
| 2024-12-31 | **-39.57** |
| 2025-12-31 | **-80.93** |
| **2026-06-30** | **+44.17** |

权益从 -80.93 亿跳到 +44.17 亿，**并非因为赚了 125 亿，而是因为 IPO 触发"向投资者发行的金融工具"（优先股，账面 100.73 亿元）由流动负债转入权益**（详见第 4 章）。**用"平均权益"作分母在数学上无意义。**

**原因三：即使勉强计算，结果也只是复述"亏损很大"这件已知的事。**

**仅作参考的 ROA（分母未受优先股转换影响，相对可算）**：
```
── ROA(年化) = 年化亏损/平均总资产 ; 总资产6/30=96.448亿, 2025末=48.539亿
  表达式: (0-20.71992*2)/((96.4483+48.5386)/2)*100
  结果:   -57.16
  精确值: -57.16356443237286
```
**年化 ROA = -57.2%**。含义：公司每持有 100 元资产，一年亏损 57 元。

**验算输出（工具口径 ROE，仅作数学演示，不构成分析结论）**：
```
============================================================
估值指标验算 (Valuation Verification)
============================================================
  当前股价: 822.5

  PE (TTM):  822.5 / -10.918 = -75.33x
  盈利收益率: -1.33%
  PB:        822.5 / 11.582 = 71.02x
  ROE:       -10.918 / 11.582 = -94.27%
  PS:        822.5 / 4.79 = 171.71x

  ✅ 以上指标均使用精确十进制计算, 无浮点误差
```

**明确声明**：上表中的 **PE -75.33x 与 ROE -94.27% 是数学结果，不是估值结论**。负 PE 不代表"便宜"，只代表"没有 E"。**本报告不使用 PE 作为任何估值判断的依据。**

**巴菲特点评**：
> "如果一家公司的 ROE 长期低于 15%，我基本不会有兴趣。"

智谱现阶段无 ROE 可言。**在巴菲特的评估框架里，这不是"分数低"，而是"不在考卷范围内"**——它属于风险投资的评估范式，而非价值投资的评估范式。这一点本身就是最重要的结论。

### 5.6 ⚠️ 关于 "ARR" 这个指标的严重警告

市场（包括中金、多家媒体）广泛引用"智谱 8 月 ARR 达 16 亿美元"。本报告必须对此提出**口径质疑**：

```

  结果:   107.29
── ARR ÷ 年化H1 IFRS收入 = 倍数
  结果:   5.62

  结果:   8.94

  结果:   1.59
── 隐含2个月内月收入放大倍数
  结果:   5.62
```

**事实**：
- 若 ARR = US$16 亿属实，折合 RMB 107.29 亿元
- 这意味着 8 月单月收入 ≈ **RMB 8.94 亿元**
- 而 2026H1 的月均 IFRS 收入仅 **RMB 1.59 亿元**
- **要求在 6/30 之后的 2 个月内，月收入放大 5.62 倍**

**这个数字要么是真实的爆发，要么是口径问题。三种可能（数据不足以判定，标注为推测）**：
1. **真实爆发**：Coding Agent 需求在 7–8 月出现指数级放量（公司称 Coding 调用量较年初 +23 倍、Token 调用量 +40 倍）
2. **口径差异**：ARR 可能采用"峰值月 × 12"或"合同金额"而非确认收入口径
3. **含未确认收入**：可能包含预售 token 包、企业年度合约 TCV 等尚未按 IFRS 确认的金额

**一致性检验（正面证据）**：中金将 2026 年收入预期上调至 RMB 60.7 亿元。若成立：

## 6. 安全边际：收入倍数反推法

### 6.1 为什么不能用 DCF

**三个硬性障碍**：

| 障碍 | 说明 |
|---|---|
| **① 自由现金流为负且不可预测** | 2026H1 FCF 估算 -27 至 -34 亿元。DCF 的第一个输入项就不存在 |
| **② 无法确定转正时点** | 公司未给出盈利指引。对照 Anthropic 自身预计到 2028 年才能实现正向现金流 |
| **③ 终值占比 100%+** | 若前 5–7 年现金流全为负，DCF 结果的 100% 以上来自终值，**等于把答案预设进假设里** |

**巴菲特点评**：
> "宁要模糊的正确，不要精确的错误。"

**一个只有终值、没有中间现金流的 DCF，是精确的错误。本报告拒绝使用。**

### 6.2 工具限制的实证（three-scenario 在亏损企业上失效）

```
  当前EPS:  -10.918
```

### 6.5 ⭐ 最关键的隐含假设：毛利率必须从 26.4% 涨到 55%+

**上述所有情景都建立在一个几乎无人讨论的假设上：终值净利率 12%–25%。**

**但这个假设与当前毛利率结构不相容：**

```
── 若终值净利率20%、期间费用率35% ⇒ 所需毛利率(税前近似)
  结果:   55.00
── 若终值净利率25%、期间费用率30% ⇒ 所需毛利率
  结果:   55.00
── 当前综合毛利率26.4% → 55% 需提升(pct)
  结果:   28.60
── 当前云端毛利率24.6% → 55% 需提升(pct)
  结果:   30.40
── 当前期间费用率(研发+销售+管理)/收入
  结果:   252.88
```

**推导（会计恒等式，非观点）**：

```
净利率 = 毛利率 − 期间费用率 − 税
```

| 若要达到 | 需要的期间费用率 | **⇒ 需要的毛利率** |
|---|---:|---:|
| 净利率 20% | 35%（Anthropic 式高研发） | **≥ 55%** |
| 净利率 25% | 30% | **≥ 55%** |
| 净利率 12% | 30% | **≥ 42%** |

**当前实际值**：
- 综合毛利率：**26.4%**
- 云端（占 86.5%）毛利率：**24.6%**
- 期间费用率：**252.9%**

**所以，今天的股价隐含了三个必须同时成立的假设：**

| # | 隐含假设 | 当前值 | 需要达到 | 差距 |
|---|---|---:|---:|---|
| **H1** | 收入放大 | RMB 19.08 亿（年化） | **RMB 730–1,277 亿** | **38–67 倍** |
| **H2** | 毛利率提升 | **26.4%** | **≥ 55%** | **+28.6pct** |
| **H3** | 期间费用率下降 | **252.9%** | **≤ 35%** | **−218pct** |

**H2 是最被忽视、也最难的一条。**

**支持 H2 的论据（正面）**：
- 单位 token 推理成本较年初已下降 **约 80%**（公司披露）
- API 均价提高 **101%**，且调用量仍暴增——**具备提价能力**
- 云端毛利率从 -0.4% → 24.6%，**方向正确且斜率陡峭**
- 国际对标：微软 Azure ~70%、Adobe ~89%，证明软件生意可以到 55%+
- 规模效应尚未释放：智谱云端收入基数仅 8.25 亿元，固定成本摊薄空间大

**反对 H2 的论据（反面）**：
- **推理成本下降的收益，正在被价格战吃掉**：行业整体在降价，智谱能提价 101% 是特例，未必可持续
- **模型迭代是永续资本开支**：每一代新模型都要重新训练、重新采购算力。这与"一次开发、永续销售"的软件模式有本质区别
- **12.44 亿元预付算力费**（占年化收入 65.2%）说明算力仍是硬约束和硬成本
- **本地化部署毛利率同期从 59.1% 掉到 37.9%**，说明公司在高毛利业务上正在**失去**而非获得定价权
- 与 MiniMax 对比：MiniMax FY2025 毛利率 25.4%，2026H1 反而降至 17.9%——**行业整体毛利率在往下走，不是往上走**

**本报告立场**：**H2（毛利率从 26.4% 到 55%+）是整个多头论述中最脆弱的一环，而市场几乎完全没有为它定价。**

### 7.2 毛利率 mix-shift 分解验算（原样嵌入）

```
  表达式: 24.6*0.152 + 37.9*0.848
  结果:   35.88
  精确值: 35.8784
  表达式: 24.6*0.865 + 37.9*0.135
  结果:   26.40
  精确值: 26.3955
```

**解读**：若收入结构维持 2025H1 水平，同样的分部毛利率将产出 **35.88%** 的综合毛利率；实际结构下产出 **26.40%**（与报表 26.4% 完全一致）。**⇒ 结构摊薄贡献了 9.48pct，分部毛利率自身变化贡献了余下 14.12pct。**

### 8.2 三个必须记住的数字

> **① 26.4%** —— 综合毛利率。今天的股价隐含它未来会变成 55%+。这是整个多头论述中最脆弱、也最少被讨论的一环。
>
> **② 12.44 亿** —— 预付计算服务费（RMB），半年增长 10.69 倍，占年化收入 65.2%。**这笔现金已经流出，但在利润表上看不见。**任何用"经调整净亏损 19.64 亿"估算烧钱速度的分析，都会系统性低估 60% 以上。
>
> **③ 3.09 倍** —— 智谱相对 MiniMax 的 P/S 溢价。两家年化收入只差 22%，年化经调整亏损几乎完全相同（-39.28 亿 vs -39.29 亿），研发只差 7%。**找不到基本面能解释这 3.09 倍。**

### 8.3 正面事实（不能忽视的另一面）

**必须诚实记录：这份中报里有真东西。**

1. **API 均价提高 101%，而调用量仍暴增** —— 这是本份财报中唯一具有"**定价权**"含义的硬证据。在一个普遍降价的行业里，能提价一倍还保住增长，是护城河的候选证据。
2. **销售费用绝对额下降 14.8%，管理费用下降 44.2%** —— 收入增长 400% 不是买来的。这在补贴横行的 AI 行业中罕见。
3. **人数增加 11.1%（883→981），总薪酬反而下降 3.5%** —— 组织效率在提升。
4. **人均创收从约 82 万元升至 194.5 万元（年化）** —— 提升 2.4 倍。
5. **云端毛利率从 -0.4% 转正到 24.6%** —— 方向正确，斜率陡峭，且单位 token 推理成本降 80% 是可归因的。
6. **经调整亏损只扩大 12.1%，而 MiniMax 扩大 111.2%** —— 在同样烧钱的两家公司里，智谱的**边际效率明显更好**。
7. **资产负债表干净** —— 无抵押、无资本承担、无或有负债，报表勾稽全部通过，第三方数据源完全对得上。
8. **配售后 2 年内无生存风险** —— Pro-forma 净现金 RMB 287.34 亿。

**如果剥离估值只看生意本身，这家公司在 2026H1 做对的事情比做错的多。**

### 8.4 反面事实

1. 毛利率两年半下滑 29.9pct，**且下滑在加速**
2. 剥离会计科目后，**真实经营亏损同比扩大 12.1%**
3. **两份业绩公告均无现金流量表** —— 对半年烧 30 亿的公司，这是重大披露缺失
4. 应收账款半年 **+158.2%**，账期约 **150 天**，6 个月以上占比升至 **17.0%**
5. **8 个月内三次融资**：IPO（HKD 50 亿）→ 6 个月烧掉 93% → 配售（HKD 313.75 亿）→ A 股 150 亿元计划
6. 银行贷款半年 **+222.7%**，且在手握 313 亿港元的同时仍在加杠杆
7. 净资产 44.17 亿中 **80.5% 来自优先股转普通股的会计重分类**，非经营积累
8. 7 月以 1,588 港元认购的机构，**两个月浮亏 48.2%** —— 专业投资者的定价也不可靠
9. 股价较 6 月高点 **-72.4%**，说明市场对该估值的共识极不稳定

### 8.5 明确的估值区间判断

**先说清楚这个判断的边界**：以下区间基于**已审阅的 IFRS 财务数据**。若公司/卖方口径的 ARR（US$16 亿）与 2026 年收入指引（RMB 60.7 亿）在 2027 年 3 月的年报中兑现，**下述区间应整体上移 2–3 倍**。这是本判断最大的不确定性，也是多空双方真正的分歧所在。

### 8.6 巴菲特视角的最终判断

**这家公司落在巴菲特的"太难"（Too Hard）篮子里，且理由不止一条：**

| 巴菲特标准 | 智谱现状 | 判定 |
|---|---|---|
| 我能理解这门生意吗？ | 商业模式在 6 个月内从"项目制"切换到"API 制"，仍在演化 | ❌ |
| 它有持久的竞争优势吗？ | API 提价 101% 是正面证据；但毛利率 26.4% 与本地化毛利率下滑 21.2pct 是反面证据 | ⚠️ 证据不足 |
| 管理层理性诚信吗？ | 费用控制优秀、披露合规；但业绩公告不披露现金流量表 | ⚠️ 部分保留 |
| 我能预测 10 年后吗？ | 大模型技术路线 12 个月都可能变一次 | ❌ |
| ROE ≥ 15%？ | 无 ROE 可言（权益为经营亏损后重分类而来） | ❌ |
| 有自由现金流吗？ | 半年 -27 至 -34 亿 | ❌ |
| 价格有安全边际吗？ | P/S 171.7x，乐观情景下年化回报 3.9% | ❌ |

> "我们只在能力圈内挥棒。投资最大的好处是，你不需要对每一个球都挥棒。"
> —— 沃伦·巴菲特

**明确结论（观点）**：

1. **智谱不是骗局，也不是泡沫公司** —— 它是一家收入正在真实爆发、效率正在真实提升、资产负债表干净的科技公司。**否定它的估值，不等于否定它的生意。**
2. **但在巴菲特的框架内，它不可投资** —— 不是因为它不好，而是因为**没有任何一个可靠的估值锚点**能支撑当前价格，且**即使最乐观的情景也不产生足够回报**。
3. **它属于风险投资的评估范式，不属于价值投资的评估范式。** 用 P/S 171.7x 买一家半年烧 30 亿、毛利率 26.4%、没有现金流量表的公司，这是 VC 的工作，不是价值投资者的工作。
4. **真正的观察点不是股价，是下一份财报里的三个数字**：
   - **综合毛利率**能否突破 35%（当前 26.4%）
   - **H2 收入**能否兑现 RMB 51 亿（H1 为 9.54 亿）
   - **现金流量表**是否披露，以及经营现金流的真实数字

**如果这三个数字兑现，本报告的估值区间需要整体上调 2–3 倍，届时应重新评估。如果不兑现，当前 822.5 港元仍有相当大的下行空间。**
