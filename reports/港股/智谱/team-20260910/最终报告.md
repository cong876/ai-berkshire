## 1. 一句话结论

智谱是中国最强的模型技术团队之一，但在 822.5 港元上它不是一门可投的生意——**毛利额 2.52 亿只覆盖研发 21.31 亿的 11.8%，护城河五维全部低于 ★3，而估值（P/S 171.7x）比同业 MiniMax 高 3.09 倍却拿不出任何基本面解释。四大师框架一致落在"回避/太难"，不是因为公司差，是因为价格与确定性严重错配。**

## 4. 各维度分析摘要

### 4.1 商业模式（段永平）★2

1. **收入正在单向流向没有护城河的一侧**：有转换成本、高毛利的企业级 **−54.6%**（毛利率 59.1%→约 38.1%）；零转换成本、薄毛利的 API **+2735.7%**（毛利率 −0.4%→24.6%）。
2. **"主动转型 vs 被迫放弃"的判据**：主动放弃的典型形态是"量缩+毛利率升"，智谱是**"量价齐跌"——失去议价能力的形态**。结论：方向主动，速度与形态被迫。
3. **护城河五维全部低于 ★3**：品牌★2 / 转换成本★1 / 网络效应★1 / 规模效应★2 / 技术壁垒★2。最锋利的反证是智谱自己的行为——**8 月把 GLM-5.3-Flash 伪装成匿名 `stealth/ox-alpha` 免费投放才拿到 OpenRouter 榜首。有品牌溢价就不需要匿名。**
4. **模型能力领先的实证半衰期：6–8 周**（2026 年 6–9 月四次可数的排序重排）。**任何以"当前模型领先"为基础的估值，有效期不应超过一个季度。**
5. **capex 真相**：3.9 亿元（+6.3 倍）的主体是收购北京红钻科技，其核心资产是**中关村软件园钻石大厦办公物业约 3.61 亿元，总部自用，与数据中心无关**。

### 4.2 财务与估值（巴菲特）★2（原始 1.8）

1. **数据来自一手报表**：经 HKEXnews 定位并解析中期业绩公告 PDF 原文，非媒体转引。资产负债表勾稽全部通过，与 etnet 每股净资产偏差 0.002%。
2. **发现 12.44 亿元的"利润表看不见的现金黑洞"**：附注 8"预付计算服务费"半年从 1.16 亿暴增至 **12.44 亿元（+10.69 倍）**，另有其他非流动资产增 7.14 亿。**现金已流出，但不进损益表、不进 capex。用经调整净亏损估算烧钱速度会系统性低估 60% 以上。**
3. **市场流传的"FY2025 经营现金流 −22.46 亿"是错的**——与 FY2024 的 −22.45 亿偏差仅 0.02%，是同一数字被错贴年份。**两份业绩公告均不含现金流量表（已逐字核验）。**
4. **毛利率 23.6pct 的下滑经算术分解**：结构摊薄贡献 9.48pct，**分部毛利率自身恶化贡献 14.12pct**。即"结构性下滑"只能解释 40%。
5. **安全边际**：`three-scenario` 工具在负 EPS 下失效（产出负股价 −4,579 港元），改用自建收入倍数模型。结果——**即使乐观情景（收入连续 5 年 CAGR 85%、终值 12x P/S），摊薄后每股年化回报仅 3.9%**；概率加权期望股价 **HKD 401.5**，较现价 **−51.2%**。
6. **把隐含假设显性化**：今天的股价要求三件事同时成立——收入放大 38–67 倍、**毛利率从 26.4% 升到 55%+**、期间费用率从 252.9% 降到 35%。**第二条是多头论述中最脆弱也最少被讨论的一环。**

### 4.3 行业与竞争（芒格）★2

1. **单位 Token 收入崩塌**：2025 年 1.58 元/百万 → 2026E **0.47 元/百万，−70.5%**。且**全社会 Token 中只有约 5%–11% 通过公有云 MaaS 收费**，其余不进任何模型公司的收入表。
2. **IDC 份额修正（2025 全年，公有云对外 MaaS 调用量）**：火山引擎 **49.5%**、阿里云约 28%、百度智能云约 **10%**（12 个月内从 17% 腰斩），前三约 87.5%；尾部回升至约 12.5%。**四家模型公司在调用量口径里连独立分项都没进。**
3. **模型层是产业链最差的一层——证据链完整**：MaaS 全市场 30.7 亿元**仅占中国 AI 云 567 亿元的 5.4%**；字节单年 capex 1,600 亿元是全市场 MaaS 收入的 **8.6 倍**；迁移成本 ≈ 改一行 base URL。
4. **五条赛道只占住一条**：编程/Agent ★4；roleplay ★1（**主动放弃了占开源 Token 52% 的最大池子**）；企业级私有化 ★2（主动撤退）；端侧 ★1；多模态/视频 ★1。
5. **稀缺性溢价有到期日**：月之暗面 9/2 已港交所保密递表（拟募 30 亿美元 @500 亿美元估值）；DeepSeek 二轮投前估值 5,000 亿元、目标 2027 挂牌；**面壁智能 8/11 已办 IPO 辅导备案**。**未来 12–18 个月新增 4–6 家标的。**
6. **被低估的对手：腾讯混元**——Hy3 在 OpenRouter 4.90T 排第 3，**高于 GLM-5.2 的 2.91T 第 5**，且**未被美方点名、不在实体清单上**。

### 4.4 风险与管理层（李录）★2（原始 2.5）

1. **2027-01-08 约 40% 老股解禁**——日期已确定，剩 4 个月。参照系商汤：流通盘不足 5% 时大额解禁，单日跌 46.77%。
2. **管理层自述用款计划隐含 runway 约 18 个月**：配售 314 亿"2027 年底前全部动用"，倒推月耗约 16 亿，是 2026H1 实际速度（约 7 亿/月）的 2.3 倍。
3. **十年后的四种形态**：中国的 Anthropic 40% / 国家级 AI 基础设施（活着但不赚钱）30% / 转型应用公司 20% / 被并购或消亡 10%。**只有 40% 的情形符合"十年后仍是好生意且仍由它赚"。**
4. **唯一不可恢复的风险是 R3（金融/证券层面制裁）**，概率 10–15%/2 年，但**不能用概率折现，只能用仓位上限控制**。
5. **澄清一个被误读的数字**：2025 年末股东权益 −81.11 亿是**上市前口径**（优先股按负债列账），不是资不抵债。
6. **公平记录**：被实体清单封锁后用 15 个月完成 GLM-5 全程昇腾训练；一半员工持股（451/938 人）；管理层从不承诺盈利时间表，且主动在中报里说"单点榜单领先很快会被追平"。

## 5. 投资论点：Bull vs Bear

### 🟢 看多逻辑

1. **收入增速全行业最快之一**：+399.7%，API 分部 +2735.7%；**2026H1 收入 9.54 亿元实际高于 DeepSeek 前 7 个月的 4.75 亿元**。
2. **单位经济性在真实改善**：云端毛利率 −0.4%→+24.6%（"卖一单亏一单"到"卖一单赚一点"的质变）；单位 token 推理成本 −80%。
3. **费用纪律是同业最好的**：销售费用绝对额 **−14.8%**、管理费用 **−44.2%**，人数 +11.1% 而总薪酬 −3.5%，人均创收 82 万→194.5 万。**收入增长 400% 不是买来的。** 经调整亏损只扩大 12.1%，而 MiniMax 扩大 111.2%。
4. **一次可验证的事前承诺兑现**：张鹏 2025 年 12 月招股期即公开"API 收入占比提到 50%"，2026H1 做到 86.5%。含金量高于任何事后叙事。
5. **全国产算力栈是唯一对手 12–24 个月难以复制的资产**，且在实体清单下是生存必需项而非加分项。
6. **编程/Agent 赛道卡位最好**：IDC **收入口径** 2025 年前五（火山、阿里云、百度、**智谱**、移动云）；GLM Coding Plan 调用量较年初 +23 倍；海外以 Claude 约 1/7 价格获 15 万付费开发者。
7. **弹药最厚 + 双通道**：pro-forma 流动性约 313 亿元，科创板 150 亿已过辅导验收（11 天完成）。

### 🔴 看空逻辑

1. **毛利额 2.52 亿 vs 研发 21.31 亿 = 1:8.5。即使毛利率做到 100%，也覆盖不了研发。** 这是本次研究唯一的记分牌。
2. **定价权是配给，不是权力**：6 个月内走完"涨 83% → 匿名免费 → 五折 → 夜间免费"的完整往返。张鹏自承"瓶颈在算力，不在客户"——**供给受限时提价是 rationing**。
3. **收入单向流向零护城河一侧**，且**最大客户群（字节/阿里/腾讯/百度/美团/快手）同时是最强潜在竞争对手**，采购发生在路由层——那里只有价格和跑分。
4. **估值无法用基本面解释**：较 MiniMax 溢价 3.09 倍而收入只差 22%、亏损相同；**即使最乐观情景年化回报 3.9%，低于无风险利率**。
5. **现金披露存在实质性空洞**：12.44 亿预付计算服务费 + 7.14 亿其他非流动资产 + 表外算力义务未披露 + **两份业绩公告均无现金流量表**。
6. **2027-01-08 约 40% 解禁**叠加管理层自述 18 个月 runway；小摩预计 2026–2027 还需再两轮融资。
7. **制裁阶梯已启动**：实体清单在列（2025-01-15）+ AA26-251A 具名（2026-09-08）且**六家中被指控时间窗口最新**；海外收入占比未披露，风险无法定价。
8. **稀缺性溢价 2027 年前失效**：4–6 家同类标的将陆续上市。

### 7.2 分层操作建议

| 类型 | 建议 | 价格区间 / 条件 |
|---|---|---|
| **激进型** | **观望**，不建议在此位置建仓 | 若坚持参与：仓位上限须极低（R3 制裁风险不可恢复，只能用仓位控制），且应等 ①2026 年报综合毛利率 ≥35% ②现金流量表首次披露 ③2027-01 解禁落地 三者至少兑现两项 |

### 7.3 关键催化剂

**加仓信号（需多条同时成立，单条不足）**
1. 2026 年报综合毛利率 **≥35%**（当前 26.4%）
2. **毛利/研发比改善至优于 1:6**（当前 1:8.5）——这是唯一的记分牌
3. **现金流量表首次披露**且经营现金流改善
4. 无促销季度的云端毛利率稳定在 **40%+**
5. **订阅收入单独披露**且占比超 30%
6. 企业级业务毛利率止跌回升（证明"主动收缩"而非"被迫退出"）
7. 科创板 150 亿落地；2027-01 解禁平稳消化

**减仓信号**
1. **金融/证券层面制裁**（SDN 或同类禁投清单）——立即、无条件
2. 模型发布间隔拉长；OpenRouter programming 榜位次连续 8 周下滑
3. 涨价后调用量下滑（定价权的唯一真实检验）
4. 南向资金连续 3 日以上净卖出
5. 跌破 800 港元（触发剩余牛证连环收回）
6. 2027 年底前出现融资窗口收紧迹象

## 8. 总结

**智谱不是骗局，也不是泡沫公司。否定它的估值，不等于否定它的生意。**

四位研究员独立得出的评分全部落在 ★2，但没有一位说它是坏公司。它的技术实力（GLM-5 全程昇腾训练、Flash 混合注意力架构、单任务成本 4.5 美分）、费用纪律（收入增 400% 而销售费用降 14.8%）、管理层克制（从不承诺盈利时间表）都是同业里数得着的。

问题出在别处：**它的收入正在从有护城河的一侧单向流向没有护城河的一侧，而它的估值是按"十年后的赢家"定价的，护城河宽度却只有六到八周。** 毛利额 2.52 亿覆盖研发 21.31 亿的 11.8%——这个缺口不能靠"慢慢改善"填上，需要收入呈数量级跃升，而单位 Token 收入正在以每年 70% 的速度崩塌。

在巴菲特的分类法里，这不属于"好"或"坏"，属于**"太难"**。在段永平的"不为清单"里，两条同时命中：看不懂的不做、生意模式不清晰的不做。**这不构成"看空"，构成"看不懂"。**

如果 12–18 个月后毛利/研发比、现金流量表、订阅占比三项同时改善，这份报告的结论应当重写。**在那之前，822.5 港元买的不是智谱的生意，是卖方对 2027 年的收入预测。**

## 9. 信息丰富度评级与 AI 研究局限性声明

### 9.1 数据充分度：**中等偏低**

| 维度 | 充分度 | 说明 |
|---|---|---|
| 损益表 | 高 | 一手 PDF 原文解析，勾稽通过 |
| 资产负债表 | 中高 | 一手数据，但 pro-forma 需推算 |
| **现金流量表** | **无** | **两份业绩公告均不含现金流量表，烧钱速度只能用四条路径估算** |
| 竞争份额 | 中 | 口径分裂（IDC/OpenRouter/Omdia 结论互相矛盾），已强制分离标注 |
| 管理层记录 | 低 | 上市仅 8 个月，作为上市公司高管的可观察窗口极短 |
| **海外收入占比** | **无** | **中报未披露，直接导致制裁风险无法定价——本次研究最大缺口** |

### 9.2 未解决的数据冲突（必须记录）

**自由流通盘口径冲突**：risk-assessor 称配售后自由流通盘约 **8%**（7 月为 3.9%）；而行情软件（腾讯/东财）口径的流通股为 **2.411 亿股（占总股本 51.8%）**。

两者相差 6 倍以上。若真实自由流通盘仅约 8%（≈3,725 万股），则港股通持股 2,710 万股将占自由流通盘的 73%——数学上高度可疑。**合理推测是行情软件的"流通股"= 全部 H 股（含已转换但仍受锁定的内资股），而非真正可交易的自由流通量。**

**影响范围**：换手率、南向持股占比、卖空占成交比 三项指标的分母全部受影响。**本报告涉及这三项的数值请按存疑处理，待中报附注或 CCASS 数据核实后修订。**

### 9.3 团队内部分歧与 team-lead 裁决

**分歧点：API 均价上涨算不算定价权？**
- financial-analyst：2026H1 API 均价提高 101% 而调用量仍暴增，称其为"唯一具定价权含义的硬证据"
- business-analyst：这是供给受限下的配给（rationing），不是定价权；判据是"单向棘轮"检验失败

**team-lead 裁决：两者可调和，但结论偏向 business-analyst。**
H1 的均价上涨是事实，financial-analyst 的记录正确；但 business-analyst 提供了两条更强的证据——①张鹏本人自承"瓶颈在算力，不在客户"②公司在 Q3 用"匿名免费 → 五折 → 夜间免费"把涨幅系统性还了回去。**决定性的是毛利率：涨价 83% 叠加降本 80%，云端毛利率理论上应 ≈89%，实际只有 24.6%——说明实际成交价远低于挂牌价。真有定价权，钱应该落在毛利率上。它没有。**

### 9.4 AI 研究局限性

1. **锚定风险**：四个 Agent 共享了同一份 team-lead 数据包。虽然三位都对数据包提出了修正（IDC 份额窗口、IPO 募资净额、capex 归因），但共享起点会降低结论的独立性。**四人同为 ★2 的收敛需要打一定折扣。**
2. **资料多 ≠ 确定性高**：智谱的公开资料并不少，但**全部是短周期资料**。AI 能输出的置信度不等于投资的真实确定性——确定性来自商业模式本身，而这门生意的模式今天尚未成型。
3. **未做的事**：未取得中报附注全文（资本承诺、租赁负债、分部地区收入）、未取得 CCASS 经纪商持仓、未访谈任何一手信源。
4. **本报告为研究框架输出，不构成投资建议。** 作者非持牌投资顾问。任何投资决策应基于读者自身的独立判断与专业意见。
