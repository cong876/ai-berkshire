### 1.3 单位经济性：毛利率的完整时间序列

| 口径 | FY2024 | 2025H1 | FY2025 | 2026H1 |
|---|---|---|---|---|
| 整体毛利率 | 56.3% | 50.0%（推算） | 41.0% | **26.4%** |
| 云端（API）毛利率 | 3.3% | **-0.4%** | 18.9% | **24.6%** |

**推算方法与验证**（置信度：高）：
- 2026H1 云端毛利 = 8.25 × 24.6% = 2.03 亿；总毛利 2.52 亿；差额 0.49 亿 ÷ 本地化收入 1.287 亿 = **38.1%**。
- 用同一方法回算 2025H1：总毛利 2.52/2.637 = 0.956 亿；云端毛利 ≈ 0；0.956 ÷ 1.618 = **59.1%**，与招股书披露的 59.1% **完全吻合** → 方法有效。

**这张表说明的三件事：**
1. 高毛利的那条线（企业级）**毛利率在两年内从 66.0% 塌到约 38.1%**，同时收入绝对额萎缩。
2. 低毛利的那条线（API）确实从 -0.4% 转正到 24.6%，但仍不足以覆盖任何固定成本。
3. **整体毛利率是被结构性摊薄的**：26.4% 的公司毛利率，对应 21.31 亿的研发开支——毛利 2.52 亿只能覆盖研发的 **11.8%**。

### 1.4 "Infra"不是一条业务线，是一个成本中心

- 已知事实：收购中科加禾（AI Infra/编译器，源自中科院计算所编译实验室，数亿元），2026-07-21 完成，当日股价 +36.89%。

**段永平会问的问题**：Infra 这一块，**谁付钱？** 目前答案是——没有外部人付钱，是智谱自己付钱，指望通过降低推理成本回收。这不是"第四条业务线"，是"第一条业务线的成本项"。把它当业务线讲，是叙事，不是生意。

### 2.3 我的判断：方向是主动的，速度和形态是被迫的

**核心论证（本报告的独立发现，置信度：中高）：**

> **一个"主动放弃"的业务，典型形态是"量缩 + 毛利率升"**——因为主动放弃意味着只挑高毛利的项目做，把低毛利的推掉。
> **智谱本地化业务的实际形态是"量缩 + 毛利率同步崩塌"**（收入 1.62→1.29 亿，毛利率 59.1%→约 38.1%）。
> **量价齐跌，是失去议价能力的形态，不是主动挑选的形态。**

三个补充校验：
1. **占比不是分母塌出来的**。反事实测算：若本地化维持 2025H1 的 1.62 亿，API 占比仍有 83.6%（vs 实际 86.5%）。所以"86.5%"这个数字本身主要由 API 的分子暴增驱动，**这一部分是真实的、主动的**。
2. **但绝对额的萎缩是真萎缩**。-54.6% 是同比绝对下滑，不是占比稀释。
3. **两件事可以同时成立**：管理层确实在 2025 年 12 月就定了 API 优先的方向（A1 是最硬的证据）；同时，本地化这门生意在 2026 年上半年确实**被市场打崩了价**（B1+B2 是最硬的证据）。**管理层的"主动"，是在一个正在崩的市场上主动加速离场，而不是在一个健康的市场上主动切换。**

**★评分：战略转型的主动性与执行力 ★3**（方向判断正确且事前公开，值 ★4；但被迫成分显著、且转出的是高毛利业务转入的是低毛利业务，扣 1 星）

## 3. 飞轮是否成立：逐环节验证

待验证的飞轮：**调用量↑ → 单位成本↓ → 价格↓ → 调用量↑**

### 3.1 逐环验证表

### 3.2 结论：这不是飞轮，是一次策略掉头

**2026 年智谱的实际曲线是：**

```
Q1  调用量↑ → 单位成本↓ → 价格【↑83%】 → 调用量仍↑400%   ← 这是"卖方限量"曲线，不是飞轮
Q3  推出 Flash → 匿名免费 → 登顶 → 认领 → 五折 → 夜间免费  ← 这是"补贴买量"曲线，也不是飞轮
```

- 飞轮的定义是**同一个机制自我强化**。智谱在半年内换了两套完全相反的定价机制，这是**战略切换**，不是飞轮转动。
- **最关键的反证在毛利率上**：如果"单位成本 −80%"与"价格 +83%"同时为真，云端毛利率理论上应逼近 80%+。**实际只有 24.6%。**
  - 数学检验（置信度：高）：设年初价 P、成本 C 且毛利率约 0（2025H1 云端 GM = −0.4%，即 C≈P）。若 6 月价格 1.83P、成本 0.2P，则 GM 应为 (1.83−0.2)/1.83 ≈ **89%**。实际 24.6%。
  - **唯一能解释这个缺口的是：实际成交价（realized price）远低于挂牌价。** 订阅制封顶、积分制折算、限时五折、匿名免费公测、夜间免费、Coding Plan 1.5 倍额度活动——这些把 list price 的涨幅系统性地还了回去。
- **"每投入 1 元算力对应 API 收入 +14 倍"是从极低基数起跳的**：2025H1 云端收入仅 0.291 亿，任何分子放大都会产生惊人倍数。这个指标信息量低。

**★评分：飞轮成立度 ★2**（"量"这一环真实且强劲；"价→量"与"成本→毛利"两环在财报上均未验证）

**反面证据：**
- **最强的反证是智谱自己的行为**：2026 年 8 月拿到 OpenRouter 榜首靠的是把模型伪装成匿名代号 `stealth/ox-alpha` 免费投放。**如果"智谱"这两个字有品牌溢价，不需要匿名。** 拿量靠的是"免费 + 跑分"，不是名字。
- 品牌位次随榜单剧烈波动：6/17 GLM-5.2 登开源榜第一 → **一个月后 Kimi K3 多项评测领先 GLM-5.2，尤其代码生成**（[新浪科技](https://finance.sina.com.cn/tech/roll/2026-07-31/doc-iniksnxe9327396.shtml)）。
- 市值半年内从 1.3 万亿港元跌至约 4000 亿港元（一度蒸发约七成），说明"第一股"的稀缺性溢价随同业陆续 IPO 快速瓦解。
- API 的采购决策发生在**路由层**（OpenRouter、企业网关），路由层按价格/延迟/通过率选模型，品牌不进入决策函数。

**结论：智谱有"榜单品牌"和"资本品牌"，没有"认知品牌"。** 榜单品牌的保质期 = 下一次别人发模型的时间。**★2**

### 4.2 转换成本 —— ★1

**支持证据：**
- 企业级本地化部署确有沉没成本：私有数据增量训练（如华泰金融叠加 40–50G 金融语料 + 上万条指令集微调）、一体机硬件、合规审计流程。
- 订阅侧有工作流粘性：GLM Coding Plan（积分制、每 5 小时/每周限额）+ ZCode 客户端（用户破 100 万）+ Subagents/Remote Control/闲时任务等功能。
- **一条真实的技术性锁定**：GLM 在 ZCode 中缓存命中率 >98%，使 Coding Plan 有效 token 量提升约 30%。换到别家模型会立刻失去这层缓存红利——这是我在本次研究中找到的**唯一一条有量化支撑的转换成本**。

**反面证据（压倒性）：**
1. **API 层迁移成本趋近于零。** 钛媒体的表述直接："不同于 Oracle 等传统软件的锁定效应，API 迁移工程成本趋近于零。"OpenAI 兼容协议已成事实标准，改一行 base_url 即可换供应商。
2. **最大的一批客户本身就是路由器。** 字节/阿里/腾讯/百度/美团/快手接入 GLM，是把 GLM 放进自家多模型池。它们切换模型是**配置项**，不是项目。而"前十用户日均调用量 +98 倍"意味着收入正在**向这批最容易切换的客户集中**。
3. **智谱亲手修好了退出通道。** GLM-5.2（7530 亿参数）与 GLM-5.3-Flash（320B-A18B）以 **MIT 协议**开源权重，商用、修改、再分发不设附加条件。客户想走，连 API 都不用调，直接下权重自部署。
4. **有转换成本的业务正在死，没有转换成本的业务正在长**：企业级通用大模型 −54.6% 且毛利率崩至约 38%；API +2735.7% 且毛利率仅 24.6%。**收入结构正在朝"零转换成本"的方向单向迁移。**
5. **智谱自己承认了这个问题**：2026-08-28 发布的旗舰 GLM-5.3 权重**放弃 MIT，改用自定义 glm-5.3 许可**，对年收入超 100 亿美元的服务商增加安全审查条款——而两天前发布的 GLM-5.3-Flash 仍是标准 MIT。**同一家公司七天内对两个模型给出相反的许可决策，是"开源与商业化冲突"被制度化承认的行为证据。**（[The New Stack](https://thenewstack.io/zai-glm-weights-license/)）

**回答任务中的指定问题——"开源模型有没有转换成本？"**
> **有，但方向是反的。** 开源降低的是**进入**成本（免费试用、无需预付、本地部署规避数据外传），同时也降低了**退出**成本（权重在手，随时自建）。对模型厂商而言，开源是获客工具，不是锁定工具。真正的锁定必须建在权重之外——工具链（ZCode）、缓存层、订阅计费关系、企业数据资产。智谱在这三处都有布局，但**都还太薄，且都未在财报中单列验证**。

**结论：★1**

---

### 4.3 网络效应 —— ★1

**支持证据：**
- 开发者生态：MaaS 平台 740 万+ 企业与开发者；ZCode 100 万用户；预置 50+ Skills；MCP 能力接入。
- 被主流 IDE / Agent 框架集成（TRAE、Qoder、CodeBuddy、CatPaw、Cline、OpenCode 等），形成"默认可选项"的分发网络。
- 理论上的数据飞轮：调用数据回流用于后训练。

**反面证据：**
- **LLM API 不存在用户间网络效应**：开发者 A 用得多，不会让开发者 B 用起来更好。这与社交、支付、交易所有本质区别。
- **开源把生态外溢给全行业**：MIT 权重意味着任何人可微调、量化、蒸馏并占有产出的 checkpoint。"生态"建在别人也能免费拿走的资产上。
- **数据飞轮缺乏证据**：智谱**未披露**任何"调用数据回流改进模型"的量化证据；企业客户数据合规限制、开源自部署路径都会切断回流。**数据不足，不能计入护城河。**
- **OpenRouter 榜单每周洗牌本身就是"无网络效应"的直接证据**：2026-07-20~26 周榜前五为 MiMo-V2.5（10.5T）、DeepSeek V4 Flash、腾讯 HY3、**智谱 GLM-5.2（3.29T，第 4）**、DeepSeek V4 Pro；8 月下旬 GLM-5.3-Flash 登顶；9/5 又回落第 2。**有网络效应的市场不会这样。**

**结论：★1**

---

### 4.4 规模效应 —— ★2

**支持证据：**
- 单位 token 推理成本较年初 −80%（官方口径）；10 万级国产芯片规模化部署；每投入 1 元算力对应 API 收入 +14 倍。
- 收购中科加禾（中科院计算所编译实验室背景，团队参与过龙芯/神威/寒武纪/昇腾编译器研发）补齐异构算力编译栈；1GW 级国产算力数据中心部分投运；运营多个万卡集群。
- GLM-5.3-Flash 架构层降本：320B 总参/18B 激活，首个稀疏注意力 + 线性注意力混合的前沿开源模型，注意力计算量 −3.01 倍、KV 缓存 −4.44 倍。
- ZCode 内缓存命中率 >98%。

**反面证据：**
1. **规模效应没有在报表上兑现**：COGS +636% vs 收入 +400%；云端毛利率仅 24.6%；整体毛利率反而从 50.0% 降到 26.4%。
2. **规模在中国 AI 这行不是独占资源，是行业公共品**：DeepSeek、腾讯、小米、MiniMax 同期都在大幅降本。**DeepSeek V4 Flash 在 OpenRouter 第三方托管的价格约为 GLM-5.3-Flash 的一半**（$0.068/$0.168 vs $0.14/$0.49），且 DeepSeek 已启用分时定价，闲时价再打对折。
3. **智谱在规模维度上是劣势方，不是优势方**：30 天 token 口径 17.1T vs DeepSeek V4 Flash 49.9T、腾讯 Hy3 32.8T。**规模效应属于规模最大的那家，不属于第二三名。**
4. **重资产化会把规模效应变成双刃剑**：智算中心回本周期普遍 5–8 年；若集群负载不及预期，折旧将持续拖累。而智谱当前 capex 仅 3.9 亿且主要是买楼——**规模承诺与资本投入之间存在明显不匹配，其算力更可能来自外部采购/长期服务协议（表外），此项无法证实，数据不足。**

**结论：工程能力是真的，规模优势是假的。★2**

### 4.5 技术壁垒 —— ★2

**支持证据：**
- 清华 KEG 技术转化，GLM 系列自研基座，非蒸馏路线的连续迭代能力（GLM-5 → 5.2 → 5.3，同基座后训练迭代）。
- GLM-5.3（7430 亿参数）在 CyberGym 达 **84.5%**，高于 GLM-5.2（77.2%）、Mythos 5（83.8%）、GPT-5.6 Sol（83.6%）。
- GLM-5.3-Flash 的混合注意力架构是**结构性创新**，不是参数堆砌。
- **最有含金量的一条**：GLM-5.3-Flash 发布前的匿名公测期流量**全部由国产芯片承载**。在国产算力上把一个前沿模型跑到 OpenRouter 全球第一，是一项极少数团队能做到的系统工程。

**反面证据：**
1. **领先窗口以"周"计，不以"年"计**（有时间戳的连续证据链）：
   - 2026-06-17 GLM-5.2 开源，被称"第二个 DeepSeek 时刻"，登开源榜第一
   - 2026-07 月之暗面 Kimi K3 发布，**多项评测领先 GLM-5.2**
   - 2026-07-26 OpenRouter 周榜：智谱仅列第 4
   - 2026-08-14 GLM-5.3 发布，重回领先
   - 2026-09-05 30 天 token 榜：智谱第 2
   → **6–8 周一次排序重排。**钛媒体的判断："技术护城河的保质期，往往比初创公司制定一轮战略规划的时间还要短。"
2. **智谱自己把技术差距的半衰期压到接近零**：MIT 开源权重 = 竞品可直接微调/量化/蒸馏。
3. **公司已经在纠偏**：GLM-5.3 旗舰改自定义许可、加入 100 亿美元营收门槛的安全审查条款。这是**承认开源侵蚀了壁垒**。
4. 开发者社区对 GLM-5.3 存在"工业级规模蒸馏""刷榜"的议论（**未证实，仅作记录，不作为判断依据**）。
5. 研发投入的绝对量在全球尺度上不占优：2026H1 研发 21.31 亿元（约 3 亿美元），与全球第一梯队相差一个数量级以上。

**分层结论：**

| 层次 | 壁垒评分 | 理由 |
|---|---|---|
| 模型能力层 | ★1 | 半衰期 6–8 周，且自己开源 |
| 训练/推理工程层 | ★3 | 混合注意力架构、缓存命中率、后训练 pipeline，有 know-how 沉淀 |
| 国产算力全栈层 | ★3 | 中科加禾编译栈 + 10 万级国产芯片调优，复制需要 12–24 个月且需要芯片厂配合 |
| **加权综合**（按收入贡献加权，收入 86.5% 来自模型能力层） | **★2** | 壁垒最厚的层，恰恰不是赚钱的层 |

**回答任务中的指定问题——"模型能力领先能维持几个月？"**
> **实证答案：约 1–2 个月。** 证据是 2026 年 6–9 月的四次排序重排。这不是推测，是可数的事件序列。任何以"当前模型领先"为基础的估值，其有效期不应超过一个季度。

**结论：★2**

### 5.3 正面回答任务指定问题

> **"如果 DeepSeek 便宜一半、Qwen 生态更大、Kimi 长程更强，客户为什么留下？"**

**诚实的回答是：目前留下的理由，全部是产品级的，没有一条是结构级的。**

- 开发者留下的理由 = ZCode 工作流 + 缓存红利 + 订阅额度活动（1.5 倍额度、夜间免费、五折）。**这三条里有两条是促销**，促销停了理由就没了（五折已于 9/9 结束）。
- 企业留下的理由 = 信创合规 + 上市公司资质 + 已有微调资产。**这三条是真的**，但对应的收入只有 1.29 亿/半年（13.5%），且毛利率正在崩。
- **最尖锐的事实**：智谱最大的客户群体（字节/阿里/腾讯/百度/美团/快手）**同时是它最强的潜在竞争对手**。张鹏对此的原话是"大厂一定会自研，但不一定在所有场景中都能做到有足够的竞争力"——这句话承认了自研必然发生，只是赌场景覆盖不全。

**结论：智谱为客户创造了真实价值（把前沿能力的价格打到 1/40，把它跑在国产芯片上），但这个价值不排他。★2**

## 6. 段永平"好生意"四标准

### 6.1 差异化 —— ★2

**有**：Coding/Agent 场景的专注度、全国产算力栈、上市公司身份、MIT 开源的开发者亲和度。
**但**：这是**当期差异化**（this quarter's differentiation），不是**结构差异化**。段永平讲的差异化是"消费者心里那个不一样"（茅台的酒、苹果的体验），是买家**主观上不接受替代品**。API 的买家是路由器，路由器不讲主观。

### 6.2 定价权 —— ★2（本节为任务指定重点，已专项查证）

**"2026Q1 API 定价提升 83% 且调用量增 400%"——查证结果：**

| 项目 | 查证结论 |
|---|---|
| 出处 | 张鹏在 **2026-04-01 FY2025 业绩说明会**上的表述，多家媒体一致引用（[财联社](https://www.cls.cn/detail/2331456)、[东方财富](https://finance.eastmoney.com/a/202604013691387031.html)、[时代周报](https://time-weekly.com/post/328519)、[证券时报](https://www.stcn.com/article/detail/3718524.html)） |
| 属实性 | **表述属实**（管理层口径确凿，多源一致） |
| 口径 | "API 调用定价提升 83%"、"调用量增长 400%"、"市场依然供不应求" |
| 可交叉验证的调价动作 | 2/12 Coding Plan 涨 30% 起、海外版 30–60%、**API 调用价 +67%~100%**；3 月旗舰 API +20%；4/8 GLM 系列 +10% |
| ⚠️ **算术存疑** | 三次调价复合为 1.3×1.2×1.1 = **+71.6%**，且 4/8 那次已属 Q2。"83%"的具体计算口径公司**未披露** |

**支持"这是定价权"的证据：**
- 提价后调用量不降反升（+400%），这是教科书式的定价权表现。
- 摩根大通口径："智谱今年以来 API 价格上涨一倍且销量保持增长，而 MiniMax 对 M3 降价向 DeepSeek 价格区间靠拢"——**同行降价、它涨价，且都在增长**，横向对比确实占优。
- 张鹏："**谁掌握了智能上界，谁就掌握了定价权**"；"高质量 Token 是稀缺资源"。

**支持"这是特定窗口产物"的证据（更强）：**

1. **窗口条件明确且已消失。** 涨价发生在 2026 年春节前后 OpenClaw/Agent 应用引爆需求、**叠加算力供给瓶颈**的时点。张鹏自己承认"**最近确实存在算力供给的约束和瓶颈**"，并说"**瓶颈在算力，不在客户**"。
   > **在供给受限时提价，是配给（rationing），不是定价权。** 定价权的定义是买方有替代品却仍愿付更高价；配给是买方没得买。这两件事在财报上长得一样，在生意本质上完全相反。

2. **毛利率是终极裁判，它给出了否定答案。** 提价 83% + 降本 80% 的组合下，云端毛利率只有 **24.6%**，且总 COGS 增速（+636%）远超收入增速（+400%）。**真有定价权，钱应该落在毛利率上。它没有。**

3. **7/31 的"涨价"含大量口径变更。** Coding Plan Pro 从 ¥149 涨到 ¥538（+261%），但同时从"无周限额"改为"**积分制 + 每 5 小时限额 + 每周限额**"。这是把一个此前亏本的不限量套餐**收回来**，不是纯粹的提价。老用户 V1 版仍按 ¥49/¥149/¥469 执行——**说明公司自己也知道新价对老客户提不动。**

4. **最有力的反证是公司 Q3 的行为，它自己推翻了 Q1 的叙事：**
   - 8/20：GLM-5.3-Flash 以匿名代号 `stealth/ox-alpha` **全免费**投放 OpenRouter/OpenCode/Cline/Nous Research
   - 8/26：智谱认领并开源；定价打到 $0.14/$0.49，官方称"Opus 4.8 的 1/40"
   - 8/31 前：Coding Plan 1.5 倍额度活动
   - 9/3–9/20：**夜间免费**（每日 23:00–次日 09:00 通过 ZCode 使用免额度）
   - 至 9/9 24:00：**五折促销**
   > **一家真有定价权的公司，不需要在半年内把自己的旗舰新品免费送出去两轮。**

5. **精品高价路线的机会成本已经显性化。** 钛媒体统计：4 月时 GLM 在 OpenRouter 约 2.7 万亿 token/月，而 MiniMax 达 6.9 万亿（约 2.6 倍）；文章判断智谱"系统性地错失了这一轮由普适 Agent 驱动的增量红利"。**智谱在 8 月推出低价 Flash，本身就是对这个批评的承认与修正。**

**判断：**
> **智谱在 2026Q1 展示的是"稀缺窗口下的提价能力"，不是"结构性定价权"。**
> 判据很简单——**定价权应该是单向棘轮**（提上去就下不来，如茅台、如可口可乐）。智谱在 6 个月内完成了"涨 83%"到"免费 + 五折 + 夜间免费"的完整往返。**能往返的，不是定价权，是价格策略。**
> ★2（承认它在特定窗口确实提价成功了，比同业强，给 ★2 不给 ★1）

### 6.3 可持续竞争优势 —— ★1

五维护城河加权后无一达 ★3。更关键的是**方向性问题**：收入正在从"有壁垒的地方"（企业级、私有化、微调资产）流向"没壁垒的地方"（API、路由层、开源权重）。**这不是护城河变浅，这是主动把水放到没有护城河的那一侧。**

### 6.4 能否看懂 10 年后 —— ★1

段永平的核心是"看得懂"。对智谱，**看不懂**，而且是三个层面的看不懂：

| 层面 | 12 个月内发生的反转 |
|---|---|
| **收入结构** | 本地化 84.8% → API 86.5%（一年内主客易位） |
| **价格策略** | Q1 涨 83% → Q3 免费 + 五折 + 夜间免费 |
| **开源策略** | GLM-5.2 MIT → GLM-5.3 自定义许可（**七天内对两个模型给出相反决策**） |
| **能力排序** | 6–8 周重排一次（GLM-5.2 → Kimi K3 → GLM-5.3 → ?） |

以上任何一条，都足以让"10 年后"的推演失去意义。四条同时成立时，**任何十年期现金流折现都是在给一个尚未成型的商业模式编故事**。

**这不是对智谱的批评，是对这门生意所处阶段的描述。**

### 8.2 三句话结论

1. **智谱是一家很强的技术公司，但目前不是一门好生意。** GLM-5.3-Flash 的混合注意力架构、把前沿模型跑在 10 万级国产芯片上、单任务成本打到 4.5 美分——这些都是硬本事，中国能做到的团队不超过三家。但"技术强"和"生意好"是两件事，段永平从不混淆这两件事。

2. **最致命的结构性问题不是亏损，是收入正在向没有护城河的一侧单向迁移。**
   - 有转换成本、有毛利的业务：**−54.6%，毛利率 59.1% → 约 38.1%**
   - 零转换成本、薄毛利的业务：**+2735.7%，毛利率 24.6%**
   - 最大的客户群（字节/阿里/腾讯/百度/美团/快手）同时是最强的潜在竞争对手，且它们的采购发生在**路由层**——那里没有品牌、没有网络效应、没有转换成本，只有价格和跑分。

3. **定价权的问题已有明确答案：那是窗口，不是权力。** 判据是"单向棘轮"检验——真正的定价权提上去就下不来。智谱在 6 个月内走完了"涨 83% → 匿名免费 → 五折 → 夜间免费"的完整往返。**能往返的是价格策略，不是定价权。**

### 8.3 段永平框架下的落点

段永平的"不为清单"里有两条，智谱**同时命中**：

> **"看不懂的不做"** —— 收入结构、价格策略、开源策略、能力排序，四条主线在 12 个月内全部反转过一次。
> **"生意模式不清晰的不做"** —— 稳态毛利率是多少？稳态获客成本是多少？订阅收入占比多少？**这三个问题在 2026-09-10 这个时点，公司自己都还没有答案。**

**这不构成"看空"，构成"看不懂"。** 段永平的处理方式是明确的：看不懂就不买，不管它涨多少。

**但也必须公平地记录另一面**：
- 张鹏在 2025 年 12 月**事前**公开了"API 占比提到 50%"的目标，2026H1 做到 86.5%——**这是一次可验证的、超额兑现的管理层承诺**，含金量高于任何事后叙事。
- 云端毛利率从 −0.4% 转正到 +24.6%，是从"卖一单亏一单"到"卖一单赚一点"的**质变**，方向正确。
- 全国产算力栈是这家公司**唯一一条对手在 12–24 个月内难以复制**的资产，但它今天贡献 0 元收入。

**如果 12–18 个月后能看到以下三件事同时发生，商业模式评级应上调至 ★3–★4：**
1. 云端毛利率在**没有促销**的季度里稳定在 40%+
2. 订阅收入（Coding Plan/ZCode）**单独披露**，且占比超过 30%
3. 企业级业务**毛利率止跌回升**（哪怕收入继续降）——证明"主动收缩"而非"被迫退出"

**在这三件事发生之前，这是一门看不懂的生意。**

> 智谱在"做对的事情"上（All-in API + Coding/Agent + 国产算力栈）判断可能是对的。
