# 中国移动（0941.HK / 600941.SH）研究目录

> 首轮研究：2026-10-14，/investment-team 四大师并行框架。基准价 H 股 HK$80.45（2026-10-13 收盘）。

## 核心结论（一句话）

好公司、合理价格、无安全边际、生意边际变差。本金永久损失概率极低（零有息负债风险、金融资产占市值 41%），但定价权正在流失（增值税 6%→9% 无法转嫁）、主业营运利润 -13.6%、2025 年分红超过自由现金流、派息率 75% 接近天花板。**持有者可持有收息，不追买；稳健资金 ≤HK$65–68 分批，保守资金 ≤HK$55；A 股溢价 43–45%，回避。**

## 三个最重要的非共识发现

1. **扣租赁付款后的 FCF 2025 年仅覆盖现金分红 41%**（五年 0.89x）。分红正在部分消耗 6,520 亿元金融资产存量，不是"现金牛自然溢出"。
2. **增值税 6%→9% 是检验定价权最干净的自然实验，结果是失败的**：税负全由股东承担，单位流量收入 -23%。
3. **应收 +31.7% vs 营收 +0.9% 的同一年，公司下调了政企坏账计提率**（少提约 25.9 亿元），2025H2 信用减值净转回约 43.7 亿元。
