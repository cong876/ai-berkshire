## 〇、一句话结论

**利润是真钱，现金流被算力预付款打穿，安全边际在价格上变厚、在资产负债表上变薄。** 核心业务 Q3 剔除预付款后经营现金流约 886 亿、为净利润的 136%，利润质量本身无造假或调节痕迹；但单季 1,374 亿（两季累计）算力预付款 + 814 亿资本开支，让腾讯从"净现金千亿的现金牛"变成"净债务 137 亿的重资本投入者"。现价 372.8 港元 = 非国际准则 TTM 10.8 倍，历史低位；但严格口径 TTM 自由现金流收益率只有 0.3%，PE 的便宜要打折看。红线 3 **计数 1/2**，Q4 再负概率估计约 70%。350 港元买单**保留**，但要接受"成交后大概率伴随红线 3 触发"的设计代价。

**判断（观点）**：剔除预付款后 OCF/净利润 136%，与腾讯历史上 OCF 长期高于净利润的特征一致（递延收入、应付款、折旧摊销加回）——**核心生意的利润是真钱**。

**但另一方面，公司口径"FCF +169 亿"过于宽容**，理由三条：
1. **预付款不会退回，只会转化为资本开支或运营成本**。若预付的是服务器/GPU 设备，交付时转入物业设备（不再二次付现）——那么"剔除预付款"等于把一笔已付的资本开支从 FCF 里永久拿掉；若预付的是算力租赁服务（本季"技术基础设施运营成本（不含折旧）"199.91 亿，同比 +131.8%，附注 3），则它本质是运营成本，放在经营现金流里正是正确分类。**无论哪种，剔除都只适合做"核心经营造血能力"的分析，不能当股东可分配现金。** 预付款的性质（设备 vs 租赁服务）**待电话会验证**。
2. **资本开支付款 651 亿 < 权责口径资本开支 814.33 亿**，差额约 163 亿挂在应付账款里：应付账款由年初 1,211.27 亿升至 1,991.76 亿（+64.4%），31–60 天账龄桶从 84.47 亿跳到 270.68 亿。这是供应商融资，下季要付现。
3. **算力周期内"一次性"连续发生**：Q2 预付 514、Q3 预付 860，没有收敛迹象。

### 2.4 维护性 vs 扩张性资本开支（估计）

公司不披露拆分。**估计方法**：以折旧作为维护性资本开支代理。Q3 物业设备及投资物业折旧 119.95 亿 + 使用权资产折旧 17.06 亿 = **137.01 亿**（EBITDA 调节表 p.12），同比 +55.6%（去年同期 88.08 亿）。

| 项目（Q3，估计） | 金额 | 说明 |
|---|---|---|
| 权责口径资本开支 | 814.33 | 公告 |
| 维护性资本开支（≈折旧，估计） | 约 137 | 代理变量 |
| 扩张性资本开支（估计） | 约 677 | 差额，**83% 为扩张** |
| 另：算力预付款（未计入资本开支） | 860 | 推算 |

**所有者盈余（Owner Earnings，估计）** = 剔除预付款 OCF 886 − 维护性资本开支 137 − 媒体内容 46 − 租赁 20 ≈ **683 亿/季**，年化 ≈ 2,732 亿，对应市值收益率约 **9.4%**（估计）。

```
== (26+860-137.01-46-20)             结果: 682.99
== 682.99*4/28997.2*100              结果: 9.42
```

**判断（观点）**：如果把扩张性投入视为"可选择停下来的增长投资"，腾讯每季仍在产生约 680 亿所有者盈余，与非国际准则利润（665 亿）基本相符——这是"真钱"的最强证据。
**但另一方面**：管理层 Q2 电话会说"今明两年一次性"，而 Q3 预付 + 资本开支合计约 1,674 亿/季（814 + 860），比 Q2（528 + 514 = 1,042）又上了一个台阶。如果 AI 投入成为互联网平台的"维护性"支出（不投就失去竞争力），那么维护性资本开支被严重低估，所有者盈余应大幅下调。这是本报告最大的不确定性。

### 3.1 折旧的滞后压力（估计）

资产端"待折旧弹药"：物业设备及器材 2,425.00 亿（年初 1,499.05 亿，+61.8%）+ 在建工程 230.03 亿（年初 96.70 亿）+ 非流动预付款 1,629.01 亿（大部分为算力，假设大比例最终形成资产）。

**估计**：若在建工程与预付款中约 1,500 亿在未来 4 个季度转入物业设备、按 5 年直线折旧，年化新增折旧约 300 亿、季度约 75 亿，即季度折旧由 137 亿升向 **200 亿以上**（估计）。这相当于当前季度非国际准则经营盈利（680.73 亿）的约 10%。**这笔成本的绝大部分还没进损益表。**

**但另一方面**：若预付款中相当部分是算力租赁服务（运营成本而非资产），它不会变成折旧，而是直接进入"技术基础设施运营成本"——对利润的压力同样存在，只是科目不同；同时云收入 +35%（公告 p.6）说明部分算力对外出租有收入对冲。

### 3.2 利润质量总信号灯

**🟡（核心利润 🟢 真钱；现金转化与未来折旧 🔴）**
没有任何证据显示利润被会计手法美化：不资本化研发、SBC 不膨胀、应收不积压、即期税大增。问题不在"假"，而在"被投入吃掉"——现金流是被企业主动选择的资本开支消耗，而非被经营恶化消耗。
