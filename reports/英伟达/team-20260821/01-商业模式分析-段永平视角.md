**A级研究声明**

资料多 ≠ 确定性高。英伟达是全球被定价最充分的公司之一，默认输出极易写成「CUDA + 全栈 + 一年一代」。本底稿的工作不是证明英伟达「很好」，而是检验四件事：

1. **CUDA 护城河是不是已经被 ASIC / 自研芯片从推理侧凿开？** 训练锁得住，不等于整张账单锁得住。
2. **客户是不是已经少到「几个 CIO 决定季度」？** 直接客户 21%+17%+16%，超大规模约一半数据中心。
3. **这门生意还简单吗？** 单季 $186 亿非流通股权投资、客户租赁担保、循环交易，还算不算「卖铲子」？
4. **定价权是对终端用户的，还是对缺货的超大规模买家的？** 缺货结束那天，75% 毛利率还在不在。

## 1. 商业模式本质：向谁收什么钱

一句话：**卖的不是显卡，是「能把十万张加速器织成一台计算机」的系统 + 把开发者锁在上面的软件税。** 钱主要来自超大规模云和少数 AI 云/主权买家的资本开支，不是来自 2 亿个游戏玩家。

收费对象三层：

| 层 | 买家 | Q1 证据 | 简单程度 |
|----|------|---------|----------|
| 1. 超大规模 | 公有云 + 最大消费互联网（Hyperscale） | DC 的约 **50%** | 简单：几张支票 |
| 2. AI 云 / 企业 / 主权 | CoreWeave 类、工业、政府 | ACIE 约 **50% of DC** | 半简单：分散，但融资常走英伟达生态 |
| 3. 边缘 | 游戏、工作站、汽车、机器人 | **$64 亿 / 7.8%** | 简单，但已不是利润引擎 |

飞轮（公司叙事，需检验）：GPU 性能 → CUDA 生态 → 更多开发者 → 更多库 → 更高转换成本 → 下一代（Blackwell → Rubin）溢价。Q1 事实支持「Blackwell 300 已成出货主力、互联（NVLink / Spectrum-X / InfiniBand）同比 +199%」——系统级绑定在加强。

**但另一方面：** 飞轮的燃料是买家的 capex，不是终端用户的订阅。capex 可以停。游戏/PC 那层曾经也「飞轮很稳」，2022 年证明它会停。

> 段永平：「商业模式要简单。」今天的英伟达，卖铲子那一层仍简单；用资产负债表去给买家盖厂、入股、担保租赁，已经不简单。

## 2. 护城河逐项验证（A级反面检验）

### 2.1 转换成本 / CUDA：训练仍硬，推理在漏

**事实：** CUDA 仍是训练和多数可租用推理的默认栈。公司 Q1 强调 Dynamo 1.0 把 Blackwell 上的推理吞吐最多提升 7 倍——这是**在自家硅上**加深软件，不是证明别人搬不走。

**反面检验：** 超大规模自研芯片瞄准的是**单位 token 成本和功耗**，不是峰值训练 FLOPS。公开可核对的方向：

- Google TPU（含 Ironwood）已是内部训练+推理的成熟路径，减少的是 Google **自己的**英伟达账单，不是可对外出租的 GPU 云。
- AWS Trainium / Inferentia、微软 Maia、Meta MTIA 都是**封闭产能**：你租不到，但它们从英伟达的 hyperscaler 内部推理份额里挖。
- New Street 等卖方有「推理份额 2028 年掉到 20–30%」的预测——**这是预测，不是事实**。本底稿只记：推理工作负载更静态、内核可手写一次，CUDA 的「二十年库」在这里折扣最大。

观点：CUDA 没有塌。塌的是「整张 AI 算力账单 = CUDA」这个等式。训练侧仍接近收费桥；推理侧越来越像「最好的桥之一」。NVLink Fusion（允许超大规模把自研 ASIC 接到英伟达互联）是双刃剑：短期锁定系统，长期承认客户会自研。

### 2.2 规模效应 / 一年一代

Blackwell 已占数据中心收入多数；Rubin 公司口径「FY2027 下半年量产出货」，宣传相对 Blackwell 最多 10x 降低 token 成本。AWS / Google / Microsoft / Oracle 被点名为首批 Vera Rubin 实例。一年一代把竞争对手的软件栈永远放在「追赶上一代」。

**但另一方面：** 一年一代也把**自己的**上一代变成库存风险。FY2026 Q1 已为 H20 计提 **$45 亿**。产品切换本身就是毛利率波动源（FY2026 全年毛利率 71.1%，低于 FY2025 的 75.0%，公司归因 Hopper HGX → Blackwell 机柜 + H20）。

### 2.3 网络效应

开发者网络仍在。真正新增的网络在**机柜内部**：NVLink 把 GPU 织成一台机器，Spectrum-X / InfiniBand 把机柜织成集群。Q1 networking **$148 亿、同比 +199%**，增速远高于 compute。这是系统级转换成本，比单卡 CUDA 更难复制。

**但另一方面：** 超大规模自研芯片同样在自建互联。Google 的 TPU pod、AWS 的 Trainium 集群不需要英伟达的交换机。网络效应在「多租户 GPU 云 + 企业」强，在「四家巨头内部」弱。

### 2.4 品牌 / 定价权

缺货时定价权是五星：Q1 GAAP 毛利率 **74.9%**，指引维持。这不是消费品牌溢价，是**产能配给权**。段氏定价权问的是：客户不买会怎样？对微软/谷歌/亚马逊/Meta，不买的替代是延后训练、或把推理迁到自研芯片——痛，但不是「没有 Windows 开不了工」。

### 2.5 规模 / 成本壁垒

台积电 CoWoS、HBM、液冷机柜是共同瓶颈，英伟达因其订单体量拿到优先产能。这是规模壁垒，也是**单点供应链风险**（见 04）。

## 3. 客户结构：集中度在恶化，不是在分散

公司爱讲「hyperscale 仍约 50%，另一半来自多元化」。50% 对 50% 听起来健康。10-Q 的**直接客户**数字更硬：

| 时点 | 披露 | 加总 |
|------|------|------|
| Q1 FY27 | 三个直接客户 **21%、17%、16%** 的总营收 | **54%** |
| Q1 FY26 | 两个直接客户 16%、14% | 30% |
| FY2026 全年 | 一个 22%、另一个 14% | 36% |
| FY2025 全年 | 一个 12%、两个各 11% | 34% |

直接客户是 ODM / 系统集成商 / CSP，**不是**微软的名字；终端需求仍高度重叠在 MSFT / GOOG / AMZN / Meta / Oracle 及少数 neocloud。10-Q 还写：估计「一家 AI 研究与部署公司」通过向客户买云，贡献了**有意义的**收入——市场通常把这句话读成 OpenAI 路径，**公司未点名，此处不点名当事实**。

应收账款：三个直接客户占 AR **30%、18%、16%**（2026-04-26）。集中度在表内，不是在卖方 PPT 里。

**但另一方面：** ACIE 同比 +74%、环比 +31%，主权/企业不是零。CFO 明确「No shipments of Data Center Hopper products to China」，对比去年同期中国 Hopper **$46 亿**——多元化的一部分，是从被管制市场被动切走的。

## 4. 这门生意还「简单」吗？循环交易是反护城河

10-K（FY2026）自己写的三类「生态投资」：

1. 向私营公司和基础设施基金投了 **$175 亿**，其中含「直接或通过 CSP 购买我们产品的模型公司」，多数非流通、可能永不盈利。
2. 持有公开股权，市值波动进利润表。
3. 向早期公司提供土地/电力/厂房担保 **$35 亿**。

Q1 FY2027 把油门再踩一档：现金流量表「购买非流通证券」**$185.8 亿**（去年同期 $6.5 亿）；非流通证券余额 $223 亿 → **$434 亿**。公开股权 $129 亿 → **$302 亿**。Q1 股权浮盈进利润 **$159 亿**。

这还是不是卖铲子？铲子公司的客户应该用**自己的**钱买铲子。当卖铲人开始给买铲人出资、担保租金、再把对方股价记进 EPS，段永平会说：看不懂。仓库旧文《看懂英伟达》把这个问题叫「思科之问」——本底稿不覆盖旧文，只确认 **2026 年 4–8 月报表把这个问题写得更大了**。

**但另一方面：** 经营现金流 Q1 仍有 **$503 亿**，FCF **$486 亿**。循环投资没有抽干经营机器，它在**改写利润表的可信度**和**客户的真实购买力**。

## 5. 段氏「好生意」标准打分

| 标准 | 判断 | 星 |
|------|------|:--:|
| 能看懂 | 卖加速计算系统能看懂；生态投资、担保、浮盈看不懂 | ★★★ |
| 差异化 | 训练+系统级互联仍明显；推理 ASIC 正在复制「够用」 | ★★★★ |
| 定价权 | 缺货时极强；一旦供给/自研芯片跟上，未验证 | ★★★★ |
| 可持续竞争优势 | CUDA+NVLink 仍深，但客户与监管都在凿 | ★★★★ |
| 用户价值 | 对训练实验室：缩短工期。对 CFO：capex 账单 | ★★★★ |

**本维度总评：★★★★**

不是五星，因为五星要求「简单、能看懂、十年后还在收同样的税」。英伟达今天收的是**资本开支税**，税基被四个客户和出口管制同时改写；公司又用自己的资产负债表去维持税基。好生意的材料还在，已经不是 2016 年那种「游戏卡 + CUDA」的简单好生意。

> 段永平：「最重要的是企业的核心竞争力有没有变化。」CUDA 没死；变的是客户有没有动力绕开它、以及英伟达自己还是不是那个只靠卖货赚钱的公司。

**反面论据（必须保留）：** Q1 经营利润率 65.6%、毛利率 74.9%、数据中心同比 +92%，任何「生意已经坏了」的说法都被当季报表打脸。指引 $910 亿说明至少管理层认为下一季需求没有断。本底稿质疑的是**可持续性与可理解性**，不是本季的出货。
