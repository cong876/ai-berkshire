## 6. 业务与财务风险

### 6.1 Runway 与烧钱速度

**先澄清一个常被误读的数字**：2025 年末股东权益 **-81.11 亿**、流动负债净额 88.35 亿，是**上市前口径**——优先股/可转换金融工具在上市前按负债列账，IPO 时转为权益。这不是真实的资不抵债。**风险评估师的职责是澄清而非放大这个数字。**

**真实的现金画像（截至 2026-06-30，部分为推算）**

| 项目 | 数值 |
|---|---|
| 2025 年末现金及等价物 | 22.59 亿人民币 |
| 2025 年末借贷总额 | 6.895 亿（2024 年末 1.37 亿，净增 5.52 亿） |
| 2025 年末未动用银行融资额度 | 52.36 亿 |
| IPO 净额 48.96 亿港元，至 6/30 已用 45.88 亿，余 3.08 亿港元 | 使用率 **93.7%** |
| 2026H1 实际消耗速度 | ≈ **7 亿人民币/月** |
| 配售净额（7/13 到账） | 313.75 亿港元 ≈ **287 亿人民币** |
| 管理层计划消耗速度（2027 年底前用完） | ≈ **16 亿人民币/月** |

**Runway 敏感性（自 2026-07 起算）**

| 情形 | 月消耗 | Runway | 耗尽时点 |
|---|---|---|---|
| 维持 2026H1 速度 | 7 亿 | 约 41 个月 | 2029 年底 |
| 中间情形 | 10 亿 | 约 29 个月 | 2028 年底 |
| **管理层自述计划** | **16 亿** | **约 18 个月** | **2027 年底** |

> **关键发现：管理层自己给出的用款计划，隐含 runway 只有约 18 个月。** 这不是分析师的悲观假设，是配售公告里的原话。市场普遍用"配售后现金充裕"来安抚自己，但公司自己说的是"2027 年底前全部动用"。
>
> 2027-01-08 解禁日时，按计划速度已用掉约 96 亿，账上仍剩约 190 亿——**所以解禁日的风险是价格风险，不是流动性风险。真正的融资考验在 2027 年底。**

### 6.2 若再融资窗口关闭会怎样

**结论：不会立即破产，但会立即摧毁投资逻辑。**

三层缓冲：①约 287 亿配售资金 ②科创板 150 亿（政策支持力度强，11 天完成辅导验收）③2025 年末未动用银行额度 52.36 亿 + 国资股东背景。

但砍支出的路径是自毁式的：研发 21.31 亿/半年中相当部分是训练算力 → 砍算力 → 模型迭代从 2 个月一版拉长 → 被 Kimi/DeepSeek/阿里追平 → API 量价齐升叙事终结 → 估值坍塌 → 再融资更不可能。

**这是一个正反馈陷阱。李录框架下最危险的公司类型，就是"必须持续融资才能维持竞争力"的公司——因为它把生存权交给了资本市场的情绪。**

### 6.3 模型迭代失速风险

**护城河的宽度 = 从模型发布到被追平的时间。目前这个时间是"几个月"。**

- 智谱迭代节奏：GLM-5（2 月）→ 5.2（6/15，MIT 开源）→ 5.3（8/14）→ 5.3-Flash（8/26 开源）
- 追赶者：Kimi K3（7 月中，2.8 万亿参数）、DeepSeek（6 月融资 510 亿、估值近 4000 亿）
- **智谱自己在中报说："单点榜单领先很快会被追平"**

已知短板：GLM-5.2 在非官方 LLM Benchmark Code V3 评测列第三，推理速度较慢、指令遵循不稳定；成本侧 Grok 4.5 在 GDPval-AA v2 中每任务成本 0.49 美元，**低于** GLM-5.2。

**失速的触发条件不需要"落后"，只需要"不再明显领先"**——定价权完全建立在"能力领先"这个前提上。

### 6.4 市场结构风险

- 现价 822.5，较 6/22 高点 -72.4%；配售方（1588）浮亏 **48.2%**
- 9 月卖空占成交金额加权均值 **14.3%**（8 月 5.0%），峰值 9/4 达 **27.28%**
- 牛熊证 10 只牛证 vs 1 只熊证，收回价密集在 780–880，9/10 已触发多只
- 港股通持股 2,710 万股，9 月净买入接近零但在暴跌日净买入
- **配售后自由流通盘约 8%（7 月为 3.9%）** ← 与行情软件"流通股 2.411 亿股"口径冲突，见最终报告"未解决数据冲突"

**风险学解读**：27% 的卖空占比 + 牛证收回价密集在现价上方 = 一个已经高度拥挤的空头交易叠加一个正在被强制平仓的多头结构。在极小的自由流通池里，两股力量都会放大波动。**任何在此价位的仓位决策，必须先接受"未来数月股价与基本面的相关性可能很低"这个前提。**

**评分｜财务安全性：★★★**

## 7. 李录式长期确定性拷问：10 年后智谱还在吗？

李录只问一个问题：**十年后这门生意还在不在、还赚不赚钱、还是不是这家公司在赚。** 三个"是"才叫确定性。

### 7.1 十年后的四种形态（概率为主观判断，非数据推导）

| 情形 | 概率 | 形态 | 前提条件 | 李录会怎么看 |
|---|---|---|---|---|
| **A. 中国的 Anthropic** | 40% | 高端基座 + API 定价权 + 主权模型出海，毛利率 50%+ | 模型能力持续第一梯队；市场愿为高端 Token 付溢价；地缘风险不升级 | 好生意，但需要连续 10 年不失手——这是"持续优秀"，不是"确定性" |
| **B. 国家级 AI 基础设施** | 30% | 国资深度参与，收入巨大但 ROIC 平庸 | 模型层商品化 + 政策托底 | **活着但不赚钱。李录不投这种。** |
| **C. 转型为应用/Agent 公司** | 20% | 模型退为内部能力，价值捕获转向垂直场景 | 模型层被商品化，主动转型成功 | 估值锚彻底改变，今天买入的逻辑全部作废 |
| **D. 被并购或消亡** | 10% | 技术路线掉队 / 融资窗口关闭 / 地缘冲击 | — | 本金永久损失 |

> **只有情形 A（40%）符合"十年后仍是一门好生意且仍由这家公司赚"。**
> **一门有 40% 概率达标的生意，在李录框架下叫"太难了"，不叫"机会"。**
> 这不是对智谱的否定——是对"这个价格上的智谱"的否定。60% 的情形里，今天的投资逻辑不成立。

### 7.2 最可能颠覆其商业模式的力量：模型层被商品化

**这个进程不是假设，它正在发生，而且智谱自己就是推手之一：**

| 商品化证据 | 具体事实 |
|---|---|
| 开源成为默认 | GLM-5.2 采用 **MIT 协议**开源；GLM-5.3 于 8/28 开放权重；GLM-5.3-Flash 于 8/26 开源 |
| 价格战 | 2026 上半年中国实验室**六次**下调 API 价格，其中**三次为永久性降价** |
| 价格锚崩塌 | DeepSeek V4-Pro 输出 0.87 美元/百万 token，**比 GPT-5.5 便宜约 34 倍**；Kimi K2.6 缓存命中价 0.07 美元 |
| 能力收敛 | GLM-5.3 编码与 Agent 能力"接近 Claude Fable 5"；Kimi K3"与最强闭源系统不相上下" |
| 追赶周期缩短 | 智谱自认"单点榜单领先很快会被追平" |

**必须呈现的反证（本节最重要的部分）**
- **2026Q1 智谱 API 涨价 83%，调用量增长 400%。** 商品没有定价权，涨价 83% 会掉客户。这是"模型不是商品"的直接实证反驳。
- API 毛利率从 -0.4% 转正至 **24.6%**；MaaS 毛利率 3.3% → 18.9% → 24.6%
- 海外 GLM Coding Plan 以 Claude 约 1/7 的价格获得 15 万付费开发者——这是**性价比套利**，不是商品化
- 8 月出现分化：DeepSeek V4 Pro 开启峰谷定价，输出最高 27 元/百万 tokens、**部分涨幅达 12 倍**

**诚实的结论：模型层正在部分商品化（低端已经是，高端还不是），而智谱的整个估值建立在"高端不会商品化"这一个赌注上。**

**如果高端也商品化，数学上会发生什么**

| 变量 | 现状 | 商品化后 |
|---|---|---|
| API 毛利率 | 24.6%（爬坡中） | 向云基础设施收敛：**15–25% 封顶** |
| 研发/收入比 | **223%** | 要盈利需降至 **<30%** |
| 达成路径 | — | 收入涨约 **7 倍**，或研发砍约 **70%** |
| 砍研发的后果 | — | **退出第一梯队 → 失去定价权 → 收入不涨 → 循环** |

> **这是一个没有中间解的结构。** 要么收入呈数量级跃升，要么模式重构。
> 商品化情形下价值转移到：①**芯片层**（英伟达/昇腾）②**应用与分发层**（谁拥有用户）③**数据与场景所有者**。模型公司变成"AI 界的中国移动"——收入巨大、资本开支巨大、**ROIC 平庸**。

**智谱的对冲策略与致命弱点**：向下做 Infra（1GW 数据中心 + 中科加禾 + 自研芯片评估）对手是**华为**；向上做主权模型/政企部署对手是**阿里云、字节**。**同时向上下游延伸，意味着同时面对两个资源多一个量级、且有云业务现金流可以无限补贴的对手。智谱没有第二条现金流。**

> 智谱今天的护城河宽度 = "上一次模型发布到下一次被追平"的时间——目前是**几个月**。
> 李录要的护城河是**十年**。
> 这两个数字差了一个数量级，而估值是按后者定价的。

**评分｜长期确定性（10 年）：★★**（所有维度中最低）

## 10. 总体结论

**这是一家优秀的公司，配上一个极差的风险收益结构。这两句话不矛盾。**

**必须承认的优点（不能因为看空就抹掉）**
- 被实体清单封锁后，用 15 个月完成 GLM-5 全程昇腾训练 + 8 大国产算力平台适配。这是硬工程成果。
- 商业化不是故事：API 收入同比 +27 倍、占比 86.5%、毛利率由负转正至 24.6%、每 1 元算力对应收入提升 14 倍。
- 管理层从不承诺盈利时间表，且在中报里主动说"单点榜单领先很快会被追平"。**在一个人人吹泡沫的行业里，这是罕见的克制。**
- 一半员工持股（451/938 人）——利益一致性机制同业最强之一。

**但李录框架下，这些都不足以构成"可投"**
1. **护城河宽度与估值久期严重错配。** 护城河是"几个月"，估值是按"十年"定价的。
2. **管理层的资本胃口远超其自我描述。** IPO 半年烧完 93.7%、随即以近 7 倍规模再融资、A 股还要 150 亿——**这不是一次性事件，这是模式。**
3. **信息环境不支持定价。** 期末现金、经营现金流、资本承诺、海外收入占比——**四个决定风险量化的数字，中报全部没有。**
4. **可观察窗口只有 8 个月。** 李录不会在一家上市 8 个月的公司上重仓，无论它多优秀。

**风险框架输出（非投资建议）**
- 现价 822.5 仍是 IPO 价的 **7.08 倍**——"跌了 72%"不等于"便宜"，只等于"离高点远"
- 27% 的卖空占比 + 牛证收回价密集触发 = 未来数月股价与基本面的相关性可能很低
- **R3（金融制裁）是唯一不可恢复的风险。不可恢复的风险不能用概率折现，只能用仓位上限控制。**

## 11. 最可能杀死这笔投资的 3 件事

### 第 1 件：2027-01-08 的约 40% 老股解禁，撞上极小的自由流通盘
**日期已经确定，剩 4 个月。** 451 名持股员工 + 君联/启明/中科创星 + 清华系股东，约 39.99% 的筹码同时解锁。参照系是商汤：流通盘不足 5%，大额解禁后**单日暴跌 46.77%**。
叠加效应：若届时股价仍低于 1588 配售价、科创板 150 亿尚未落地、314 亿已消耗近三分之一——公司将在最差的价格被迫选择"再融资"或"砍研发"，而砍研发就是自毁。

### 第 2 件：制裁升级至金融/证券层面（SDN 或同类禁投清单）
概率不高（10–15%/2 年），但**它是唯一能在几周内使股权价值大部分归零的风险**。AA26-251A 已提供官方事实基础，且智谱在六家被点名公司中处于最不利叙事位置——**被指控行为的时间窗口最新（截至 2026 年年中），而它早在 2025 年 1 月就已在实体清单上。**
触发链条：国际机构强制清仓 → 恒生综指剔除 → **港股通资格丧失** → 极小流通盘承接不住 → 流动性螺旋。若与 2027-01-08 解禁重叠，无解。
