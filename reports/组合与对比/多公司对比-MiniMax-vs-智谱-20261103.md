## 8. 共同的行业判断（两份报告共用）

1. **IDC 2026H1**：中国 MaaS 收入 106.3 亿元（+889%），火山 45.1% + 阿里 25.2% = 70.3%（上年同期 58.5%），双寡头更强。
2. **单位 Token 收入没有崩塌**：+86%（含视频结构效应），信通院均价 +97.9%——"价格战结束、成本战开始"；但 Token 量远低于预测，"量弱价强"。
3. **海外小模型档价格倒挂**：Haiku 5.5 / GPT-6 Luna $0.10/$0.50 低于 M3.1 Flash $0.15/$0.60；AA v5 开源与闭源差距 3→12 分。
4. **48 号公告（10/16 征求意见稿，11/15 截止）**：API/App/SaaS/端侧明文豁免；已开源技术不管；新开源与海外授权需登记、自动许可；"AI 辅助漏洞挖掘"列限制类；"2 万亿参数门槛"仅二手，不采信。
5. **模型层利润集中到大厂与 DeepSeek**（DeepSeek API 毛利率 82.9%，单源）；独立公司毛利率仍 17.9%–26.4%。
6. **稀缺性溢价到期日 ≈ 2027Q1**：月之暗面（ARR >10 亿美元）港股上市；DeepSeek 2027 科创板；可灵、阶跃排队。
7. **11/3 两家同日 −8%**：四组均未找到公司级事件；恒科上午 +0.96%、午后 AI 链跳水，与隔夜纳指科技股尾盘跳水同构；判为板块 beta，"未检索到"不等于"确认没有"。
