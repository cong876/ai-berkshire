## 信息丰富度评级：A级（信息充裕）

微软上市超过 40 年，SEC 披露完整，卖方覆盖过饱和。资料多会写成「云+Office 护城河、Nadella 会打仗、Copilot 渗透」。本轮强制做**反面检验**：Copilot 3000 万席位有没有 ARR；Azure +43% 有多少是产能释放；GAAP $17.95 里有多少浮盈；6 月旧稿「估值已压缩到 22x」还在不在。

**AI研究局限性声明**：(1) Azure 绝对值公司未单列，「全年超 $1000 亿」是口头口径，含 GitHub 云等；(2) Copilot 无 attach / ARR / 净保留；(3) 云份额 Synergy / Gartner / 三家 IR 分母不同，禁止合成一张市占率表；(4) OpenAI 关联收入 $241 亿仅 10-K 单源；(5) Anthropic $32 亿税前收益未进公司 Non-GAAP 调整，可持续 EPS 含估计。A 级资料降低的是数据缺口，不降低 token 经济与 OpenAI 治理的不确定性。

本报告不覆盖、不取代 `微软-research-20260623.md`（当时股价 $367.34、市值 $2.73 万亿、TTM PE 约 22x）。不构成投资建议。

## 1. 一句话结论

> 办公税仍在付账单：FY2026 经营利润 $1552 亿、利润率 46.8%，PBP 贡献约 54%。Azure 全年口头超 $1000 亿、Q4 +43%，但份额同比持平 20%，高增被管理层归因于产能释放。可持续 EPS **$16.93**、PE **28.4x**——6 月「22x」窗口已关。公司 FCF 仍有 $670 亿，却连降两年。**经营质量配得上核心资产讨论，当前价格配不上「被错杀」三个字。**

## 4. 各维度分析摘要

### 4.1 商业模式 & 护城河（段永平视角）★★★★

1. **一句话**：三层税。第一层向 CIO 收身份+办公年费（简单、利润率 60%）；第二层卖云计算和 GPU 水电；第三层 Copilot/OpenAI，看不太懂。利润还在第一层。
2. **3000 万 Copilot 席位没有 ARR / attach / 净保留。** 相对约 4.5 亿商业席位，渗透估计 6–7%。目录价毛估可过百亿美元 ARR，折扣后可能腰斩。公司已改成 seat+consumption，等于承认纯席位加价不是终点。
3. **Azure +43% 被 Hood 归因于产能释放 + GitHub 6 月用量计价。** 「需求超过供给」是多季背景，不是本季需求上台阶。把 +43% 当成纯 IaaS 需求，是在偷换分母（口径含 GitHub 云、Nuance 等）。
4. **OpenAI 是资产也是反护城河。** 关联收入 $241 亿（占营收 7.3%）、应收 $60 亿。Q2 曾披露 RPO 约 45% 来自 OpenAI；Q4 只说剔 OpenAI 仍 +25%。治理与 token 单位经济：看不懂，不假装懂。
5. **轻资产正在改写成电厂。** PP&E 一年 +53% 至 $3131 亿；Q4 capex+租赁约 $410 亿。还不是航空公司，已经不是 2019 年的微软。

**但另一方面**：PBP 经营利润率 60%，转换成本在身份地产上仍是五星。2011 年也被说「Windows 已死」，Nadella 做成了更轻的订阅。这次方向相反：把订阅改成电厂。

### 4.2 财务 & 估值（巴菲特视角）★★★

1. **浮盈约 6% 净利，不是「大半是纸面」。** GAAP EPS $17.95 = OpenAI $0.67 + 公司 Non-GAAP $17.28；Non-GAAP **仍含** Anthropic 税前 $32 亿（约 $0.35）。可持续 **$16.93**。CNBC「OpenAI $34 亿」不是 10-K 独立行。
2. **营业利润机没有被注水。** OI $1552 亿、+21%、利润率 46.8%；OCF 是 GAAP 净利的 1.37 倍（浮盈在现金流里被加回）。
3. **FCF 没抽干，但油门在松。** 公司 FCF $670 亿（−6.5%），连续第二年下降。扣新签融资租赁后经济 FCF **$424 亿**，yield 1.19%。尚未起租租赁 **$3291 亿**。Hood「FY2027 仍转正」是指引；同时把数据中心寿命改 25 年、部分租赁改经营租赁——账面 FCF 的会计弹性在变大。
4. **22x 不成立。** $481.15 / $16.93 = **28.42x**；P/FCF 53.5x。盈利收益率 3.52%，股息率 0.76%。
5. **三情景（基数 $16.93，3 年）**：乐观 **$834.5（+73%）** / 中性 **$495.7（+3%）** / 悲观 **$270.9（−44%）**。现价约等于中性。22x 可持续 EPS 约 **$372**。

> 巴菲特：「价格是你付出的，价值是你得到的。」$481 是价签；股东得到的是经营利润和自由现金，不是 OpenAI 再融资抬高的账面价值。

### 4.3 行业 & 竞争（芒格视角）★★★★

1. **Azure 没有继续吃 AWS。** Synergy Q2 2026：AWS 28%、微软 **20% 同比持平**、Google 15%（+2pt）。AWS 掉的 2 个点被 Google 捡走。公司增速与份额迁徙不是同一件事。
2. **没有可审计的统一云市占率表。** Synergy 含 IaaS+PaaS+托管私有云；Gartner 最新官方 IaaS 仍是 2024 年表；Azure 口径含 GitHub 云。禁止三套尺子加总。
3. **意图入口是 ChatGPT（9 亿周活）；收银机是 Copilot 席位税（3000 万，渗透约 6.5%）。** 办公席位 +6%、美元 +16%，没有被抽走。被抽走的是开发者「最常用工具」：JetBrains 5–7 月 Claude Code 39% vs Copilot 21%。Bing 4.47% vs Google 91.31%。
4. **过路费还在，修路也很重。** 生产力毛利率 82%；智能云毛利率 62.2%→58.0%。Q4 capex 约三分之二是短寿命 GPU/CPU。2026 年 4 月 OpenAI 排他已取消。
5. **Lollapalooza 对份额叙事为负，对过路费尚未同向。** Google 云、开源模型、开发者工具、电力约束四力同向压缩「Azure 独食」故事；办公税仍在运转。

### 4.4 风险 & 管理层（李录视角）★★★

1. **最致命单一风险：业主盈余被短寿命 GPU 与 OpenAI 承诺锁死。** 现金 capex $1160 亿（占营收 35%），约三分之二必须重置。Q1 FY2027 单季指引 **超过 500 亿美元**。Hood 给的是信心，不是回收年数。
2. **治理红旗：无。** 一股一票，独董 11/12。黄旗在 OpenAI 关联方（收入 $241 亿、应收 $60 亿）和「能换人、不能停火」。
3. **Nadella 云与订阅的能力圈已证明；AGI 开支与 OpenAI 董事会政治不在圈内。** 2026-04 已经让过一次独占权。Anthropic 是产品对冲，不是治理对冲。
4. **TCI / Hohn Q2 清仓**；Ackman 加至约 **621 万股 / $23.2 亿**。聪明人的分歧本身是风险信号。
5. **监管是慢性税。** Teams 已在 EEA 拆套餐；Azure 被初步指定 DMA 守门人。罚款付得起，架构改装才贵。

> 李录会问：你是否真的拥有那 670 亿 FCF？十年后人们是否仍为打开 Excel 付费？Nadella 有没有把 OpenAI 当成能力圈外的东西来风控？公开证据分别指向：拥有但正在被征用、不确定、正在补课但无法控制对方董事会。

## 5. 投资论点（Bull vs Bear）

### 🟢 看多逻辑

1. **办公税没裂。** PBP 经营利润率 60%，贡献约 54% 经营利润；商业席位仍在涨。
2. **经营利润率 46.8%、OI $1552 亿**，全球最好的利润池之一，浮盈在线下。
3. **Azure 全年跨过 $1000 亿、Q4 +43%**，RPO 剔 OpenAI 仍 +25%，需求不是零。
4. **公司 FCF 仍有 $670 亿**，分红+回购 $487 亿，还在向股东返还现金。
5. **治理干净**：一股一票，无双层股权；内部人无法用金股锁死错误。
6. **若 GPU 利用率兑现、Copilot attach 从 6% 做到高双位数**，乐观情景 $835，28x 可以被增长消化。
7. **身份+合规转换成本**仍是 CIO 侧最硬的锁，Google Workspace 尚未在财富 500 打穿。

### 🔴 看空逻辑

1. **中性情景仅 +3%。** 现价约等于「10% 增长 × 22x」，没有传统安全边际。
2. **6 月 22x 窗口已关。** 股价两月 +31%，可持续盈利几乎没涨。
3. **FCF 连降两年**，经济 FCF yield 1.2%；未起租租赁 $3291 亿还没开始折旧。
4. **Copilot 席位没有美元验证**；ChatGPT 是意图入口，开发者工具在流向 Claude Code。
5. **Azure 份额同比持平**，增量被 Google 拿走；+43% 含供给与计价噪音。
6. **OpenAI 四重身份**（股东/客户/IP/竞品），排他已取消；RPO 曾高度集中。
7. **公众股东否决不了军备预算。** 能换 CEO，不能停 capex。

## 7. 最终投资建议

### 7.1 定性判断

| 维度 | 判断 | 评级 |
|------|------|:----:|
| 生意质量 | 一流办公税 + 正在变重的云军备 | **A-** |
| 管理层 | 会开云机器；AGI 开支缺乏回收年数 | **A-** |
| 估值 | 可持续 28x，中性打平 | **C+** |
| 时机 | 6 月压缩窗口已过；FCF 拐点未到 | **C+** |

### 7.2 分层操作建议

价格锚：现价 **$481.15**；工具三情景 **$834.5 / $495.7 / $270.9**。22x 可持续 EPS 约 **$372**。

| 投资者类型 | 建议 | 参考价格区间 | 说明 |
|-----------|------|-------------|------|
| **激进型** | 已有仓可保留为核心资产，**现价不主动加满** | 回踩 **$420–450** 再加；靠近 **$372**（约 22x）才接近「有垫」 | 赌的是 GPU 利用率 + Copilot 用量，不是 3000 万席位海报 |
| **稳健型** | **观望** | 等待其一：(1) 公司 FCF 同比转正且 Q1 capex 不再「>$500 亿」这种加速度；(2) 可持续 PE 压回 **22x 附近（约 $372）** | 需要看见 Copilot 的美元（ARR/attach）或 Azure ex-OpenAI 份额不再被 Google 独食 |
| **保守型** | **回避新开仓** | 除非靠近悲观带 **$270–320**，或经济 FCF yield 回到 3% 以上 | 李录框架下，28x 买一项自己停不了火的 GPU 重置，安全边际不够 |

以上是研究区间，不是预测。下一季 capex 指引、RPO ex-OpenAI、租赁重分类都会改写倍数。6 月旧稿若按「22x 中等仓位」持有，现价对应的是**估值扩张而非基本面跳跃**，不宜把涨幅理解成论文被验证。

### 7.3 关键催化剂

**加仓 / 论点转正**
1. 单季公司 FCF 同比转正，且 FY2027 capex 指引不再上修加速度
2. 公司首次披露 Copilot ARR 或 attach，且显著高于 6–7% 回推
3. Synergy 份额连续两季回升，或 Azure 增速在产能释放后仍能维持 35%+
4. 10-K 关联方收入占比下降、ex-OpenAI RPO 仍双位数，同时回购加速
5. DMA/FTC 无拆解身份与云互锁的同意令

**减仓 / 回避**
1. 公司 FCF 转负，或经济口径（扣新签租赁）持续低于分红回购
2. Copilot 席位涨、365 美元增速掉到低于提价——货架席位回流
3. OpenAI 训练/API 可见迁云，关联收入与应收同时下降
4. GPU 供给缓解后 Azure 增速回落到与 20% 份额匹配的市场增速之下，capex 却因长单降不下来
5. TCI 路径被更多长线机构复制（入口迁移交易拥挤）

## 8. 总结

四位分析师打在同一根钉子上：**第一层办公税还在出利润，市场定价的是第二层云军备已经打赢——而份额、FCF 和 Copilot 美元都还没把「打赢」写进报表。**

段永平看到 60% 利润率的 CIO 税，但拒绝把 3000 万席位写成 attach 成功，也拒绝假装懂 token 经济。巴菲特看到 46.8% 经营利润率，但拒绝用 $17.95 和 26.8x，更拒绝把 6 月 22x 当成 8 月的事实。芒格看到办公美元仍 +16%，但拒绝「Azure 在吃 AWS」——吃 AWS 的是 Google。李录看到一股一票和 Nadella 会开云，但拒绝在 $1160 亿短寿命 capex 面前把业主盈余当成已经安全的股东现金。

市场在 GAAP 26.8x 上讲「合理的伟大公司」，在 P/FCF 54x 上讲「capex 是暂时的」。本报告的结论靠近后者的风险、前者的半真半假：**按经营利润，这仍是一流公司；按股东能主张的自由现金和当前倍数，这是一家已经离开安全垫的核心资产。**

**最值得跟踪的三个变量**
1. **公司 FCF 与短寿命资产占比**——业主盈余何时回来；
2. **Copilot 的美元（ARR/attach），不是席位海报**——办公税有没有升级成功；
3. **Azure 份额（Synergy）与 RPO ex-OpenAI**——增长是市场的还是一个客户的。

**一句话总结**：一流生意，二流当前现金回报，估值已离开 6 月的压缩窗口。可以持有质量，不宜在这个价格上把「22x 被错杀」当新开仓理由。
