### 1.2 三层税的本轮更新

| 层 | 收税对象 | 上轮计价 | **本轮变化** | 判定 |
|----|----------|----------|--------------|------|
| 第一层：知识工作税 | CIO | M365 席位 + E5/E7 + Copilot $30 附加 | **席位价不降，上面再叠一块计量表**：Cowork / Code / Autopilot / 前沿模型按 Copilot Credits 计费（$0.01/credit，预购最多 8 折）。公司举例：5 个 Opus 5 长时 Cowork 任务 ≈ **$43** 额外费用，叠在 $30 席位上 | 🟢 收费面变宽（未经财务验证） |
| 第二层：算力税 | CIO/开发者/前沿实验室 | Azure 消费 + 长约 | 无新数；Hood 重复「需求健康、供给约束」；Maia 300 主攻**自有推理成本** | 🟡 |
| 第三层：开发者工作流税 | 工程师/企业 DevOps | GitHub 席位 → 6 月起用量计价 | GitHub Copilot 加入 MAI-Code-1.1-Flash、Gemini 3.8 Flash、Grok 4.6，以及多模型路由 HydraFusion（[GitHub Changelog](https://github.blog/changelog/2026-10-01-github-copilot-in-vs-code-september-2026-releases/)） | 🟡 多模型化坐实 |

**一句话生意定义（更新）：** 微软向企业 CIO 收「身份+办公+合规」的年费，向所有人卖算力，并在 2026 年 9 月起把 AI 从「按人收」改成「按人收底座 + 按用量收深度」。

**事实 vs 观点：**
- 事实：USL 列价 $30 不变；UBB 必须先有 USL；企业租户 UBB 默认关闭，需管理员建立支出策略（[Futurum](https://futurumgroup.com/insights/microsoft-splits-the-copilot-pricing-model-into-everyday-and-advanced-ai/)；Microsoft Learn）。
- 观点：这是 8-21 底稿「per-seat-plus-consumption」从电话会措辞变成产品与价目表。上轮担心「3000 万席位是最后一次加价」——微软的回答是**不再加席位价，改加计量表**。这在结构上比「再涨 $3」更可持续，因为它把收费锚到用量而不是人数。

**但另一方面：**
1. Credits 计量的是**投入（算力/模型/时长）而非产出**。Futurum 原评：财务能给 UBB 设上限，但**无法预测**一个 agent 任务的成本。CIO 面对不可预测账单的本能是「审批+限额」，这会抑制用量——与微软「不想让客户配给日常 AI」的叙事自相矛盾。
2. UBB 企业端**默认关闭**。默认关闭的计量表，第一年收入很可能很小。没有任何一手数字显示 credits 收入规模。
3. 席位价「不变」也可以读成「不敢涨」：ChatGPT Enterprise / Claude 的企业版是现实比价对象（微软自己在发布中用 Copilot vs Claude vs ChatGPT 的 40 条 prompt 对比做营销——Futurum 指出这是厂商自建模型、按列价、不含折扣）。

本维评分 **生意本质清晰度：★★★★**（持平。计价方式更透明了，但新计量表的规模仍是黑箱）。

## 2. 飞轮：M365 → Copilot → Azure → 模型层，最弱的一环仍是「美元」  🟡持平

```
M365 席位（4.5 亿+，第三方分母）
   → Copilot 席位（>3000 万，7-29 披露，本轮无更新）
      → 新：Cowork / Code / Autopilot 消耗 Copilot Credits（9-25 起，Q4 CY2026 推开）
         → Azure 推理负载（M365 Copilot 吞吐、GitHub 用量）
            → 推理硬件：Maia 200（在产）→ Maia 300（2027 多 GW，自用主平台）
               → 模型层：OpenAI GPT-5.6 + Anthropic Sonnet 5 同时在 USL 里；MAI 自研；前沿模型走 UBB
```

### 2.1 各环节本轮体检

| 环节 | 上轮状态 | 本轮证据 | 变化 |
|------|----------|----------|------|
| M365 席位 | +6% YoY，靠 SMB/一线 | 无新数 | 🟡 |
| Copilot 席位 | >3000 万，无 ARR/attach | Hood 9-9 未给新数；9-25 发布未给新数 | 🟡（仍不可验证） |
| Copilot 变现 | 「席位+用量」仅口头 | **价目表落地**：credits $0.01、USL/UBB 边界、FinOps 工具、Graph API 管控支出 | 🟢 机制有了，美元没有 |
| Azure 消费 | +43%，归因产能释放 | Hood 9-9：效率当季变现、dock-to-live −50%；Q1 指引 +45% | 🟡（10-28 验证） |
| 推理成本 | Maia 200 宣称每美元性能 +30% | Maia 200：内置 AI 功能（Teams/Copilot/Cowork）每瓦 token 比领先 GPU 高至 **1.7 倍**；Maia 300：每 MW token **+40%**（预期值） | 🟢（厂商口径，未独立验证） |
| 模型层 | OpenAI 独家叙事贬值 | USL 同时包含 OpenAI 与 Anthropic 模型；GitHub 加入 Gemini/Grok；多模型路由产品化 | 🟢 对冲；🔴 模型差异化进一步归零 |

**最弱一环（观点）：** 仍是「Copilot 席位/credits → 美元」这一段。上轮的缺口（ARR、attach、净保留、实际 ASP）**一个都没补上**。9-25 的股价 +3.66% 奖励的是产品叙事，不是收入证据。

**飞轮里新增的一个齿轮——成本端：** 上轮把飞轮的轴承定义为 capex。Maia 300 的意义是把「同一个 MW 的电换更多 token」，即每单位 capex 的产出。若 +40% 兑现，固定价 USL 下「用户用得越多、微软越亏」的问题（Hood 9-9 自己承认重度使用会推高固定价许可的成本）会被部分对冲。这是本轮飞轮最实质的改善——但它是**2027 年才部署的预期值**。

**但另一方面：** Maia **只自用、不出租**（与 AWS Trainium、Google TPU 对外出租/出售不同；Google Cloud Q2 已开始确认 TPU 系统销售收入）。这意味着 Maia 只降低微软自有产品的成本，**不形成 Azure 对外的差异化供给**。对外客户买的仍是 Nvidia GPU，Azure 在这一块与 AWS/Google/Oracle/neocloud 同质化。

本维评分 **飞轮：★★★★**（持平：旧飞轮五星；新飞轮机制补齐、成本端有望改善，但仍缺美元证据）。

| 转换成本（Copilot） | ★★ | ★★ | 🟢 方向改善、星级不变 | Autopilot 有独立身份与工作区；Agent 365 统一管支出与模型权限——**但无留存数据** |

### 3.1 品牌 ★★★★ 🟡

事实：9-03 Xbox 宣布云游戏按月限时（[Xbox Wire](https://news.xbox.com/en-us/2026/09/03/xbox-cloud-gaming-changes/)）；同期媒体记录第三次 Xbox 硬件涨价与裁员（[Aftermath](https://aftermath.site/microsoft-xbox-game-pass-cloud-gaming-time-limits/)，二手）。

观点：消费品牌的定价权检验是「涨价后用户留不留」。Xbox 的做法是在 FY2026 收入 −7% 的基础上**收缩权益**，这是对付费意愿弱的回应，不是品牌溢价的体现。企业端品牌无反证。

但另一方面：公司称限时只影响约 4% 订户——如果属实，是精准砍掉重度云游戏的高成本用户，属于成本纪律而非品牌失血。

### 3.2 转换成本：Copilot 从「插件」往「员工」走  🟢方向

9-25 发布的 **Autopilot** 是「拥有自己身份和工作区的常驻 agent」（[Microsoft Blog](https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/)）。Agent 365 的成本管理从 Cowork 扩展到 Code 与 Managed Runtime，10 月接入 Copilot Studio agent；管理员可按组控制模型族、用 Graph API 批量设支出策略。

观点：这是把 Copilot 往第一层五星地产（Entra 身份 + Graph + Purview）上焊。agent 一旦有了 Entra 身份、审计日志和预算策略，撤掉它的成本接近撤掉一个系统账户体系——**方向上**在把 Copilot 从 ★★ 推向 ★★★。

但另一方面（为什么本轮不升星）：
1. 没有一手留存、续约、净美元保留数据；
2. USL 里同时塞了 OpenAI 与 Anthropic 的模型、前沿模型走 UBB——**锁定在 harness，不在模型**，而 harness 的竞品（Google Workspace + Gemini Enterprise：Pichai 称近 90% Fortune 100 在用 Gemini Enterprise，[Yahoo 转述 Alphabet Q2](https://finance.yahoo.com/markets/stocks/articles/alphabet-q2-2026-earnings-revenue-203058727.html)）也在做同样的事；
3. Autopilot / Code / Cowork 处于 Frontier 预览或「未来几周」可用，**还没有规模化使用**。

### 3.3 规模 ★★★★ 🟡 —— 规模在变成「人人都有」

| 指标 | 微软 | Google Cloud | 来源 |
|------|------|--------------|------|
| 最近季增速 | Azure +43%（Q2 CY） | **+82%**，$248 亿 | 微软新闻稿；Alphabet EX-99.1 |
| 积压订单 | 商业 RPO $6,780 亿（ex-OpenAI +25%） | Cloud backlog **$5,140 亿** | 同上 |
| 云经营利润率 | IC 分部 41% | 35.6% | 同上 |

### 4.3 判断

**资产侧 🟢：** OpenAI 净收入 $500 亿、增速 77%、企业 +107%——作为被投方和分成来源，它比 8-21 时更值钱。微软同时拿分成（有上限）、拿股权（估值上行）、拿 Azure 负载（主云）。

**反护城河侧 🔴：**
1. **信用集中**：OpenAI 未来五年预计烧 $2,780 亿，而它对 Azure 的承诺约 $2,810 亿（Q2 口径）。Azure 积压订单的四成左右，兑现能力取决于一家**仍在巨额亏损、需持续外部融资**的公司。10-08 当天 MSFT −1.35%、甲骨文更大跌幅，说明市场把微软当作 OpenAI 信用的代理变量。
2. **非独家 + 多云**：OpenAI 已可在 AWS 提供全部服务；微软反过来把 Anthropic Sonnet 5 塞进自家 USL。双方都在**主动降低对彼此的依赖**。上轮「正在贬值的独家叙事」——**已证实，且贬值已写进合同**。
3. **分成封顶**：上限金额不披露。按段氏纪律：分成的上限、期限、结算节奏看不到，就**不能**把 OpenAI 增长线性折算成微软收入。

**但另一方面：** 去独家化对微软也是**解放**：微软不必再为 OpenAI 的 AGI 进度、模型路线背书，可以把 Copilot 做成多模型 harness（9-25 已做到）。如果 harness 才是护城河（上轮核心判断），那么 OpenAI 关系的松绑在**商业模式上是中性偏正**的，只在**资产负债表/RPO 信用上是负**的。

OpenAI 关系单独评分：**资产 ★★★ / 反护城河风险 ★★★★**（持平；两侧同时放大，相互抵消）。

## 11. 与 Meta 对照（商业模式维度）

> 只用已掌握的数据：微软取 FY2026 10-K/EX-99.1；Meta 取本项目 8-21 轮 Meta 商业模式底稿所引 Q2 2026 EX-99.1 / 10-Q（`reports/Meta/team-20260821/01-商业模式分析-段永平视角.md`）。**未对 Meta 做新研究**，Meta 10-14 轮由另一组 Agent 负责。

### 11.1 两头现金牛

| 维度 | 微软：办公税（PBP） | Meta：广告税 |
|------|---------------------|--------------|
| 收费对象 | CIO（按席位，年度合同） | 广告主（按竞价，实时） |
| 收入集中度 | PBP 占营收 42.2%；另有 IC 41.5%、MPC 16.3% | 广告占营收 **97.6%**（Q2 2026：$593.6/$608.0 亿） |
| 现金牛利润率 | PBP 分部经营利润率 ~60%（FY26） | 公司经营利润率 Q2 **31%**（上年 43%）；毛利率 81.4% |
| 最近量价 | 商业 M365 席位 +6%，收入增长靠 ARPU（E5/E7/Copilot） | 展示 +14%、单价 +12%（Q2）；DAP 36.0 亿 +3% |
| AI 对现金牛的**直接作用** | 尚未被美元证明（Copilot 无 ARR） | **已被美元证明**：单价 +12% 管理层归因含广告效果提升 |
| AI 对现金牛的**替代风险** | ① AI 减少知识工作者 → **席位数**下降（按人收费天然暴露）；② ChatGPT/Claude 抢「员工意图」 | ① 用户时间流向 AI 助手；② agent 代购绕过信息流；③ 推荐视频可被 TikTok/YouTube 替代 |
| 对替代风险的**结构性回应** | 9-25 起把 AI 从「按人」改「按人 + 按用量」，Autopilot 给 agent 发身份——**让 agent 本身成为可计费的「席位」** | 广告系统本就按效果计价，AI 提升效果即提升价格 |

### 11.2 两座电厂

| 维度 | 微软 | Meta |
|------|------|------|
| capex 强度 | 现金 capex / 收入 **35.0%**（FY26：$1,160/$3,318 亿） | 指引中枢 $1,375 亿 / TTM 收入 $2,282.5 亿 ≈ **60.2%**（**估计**，口径为全年指引对 TTM 收入） |
| 电卖给谁 | **外部客户 + 自用**：商业 RPO $6,780 亿（ex-OpenAI +25%） | **基本自用**：算力回报只能经由广告或尚未商业化的模型/agent |
| FCF | FY26 **$670 亿**（−6.5%） | Q2 **$7.84 亿**（上年 $85.5 亿）；H1 $131.7 亿 |
| 资本回报方式 | FY26 回购+分红 $487 亿 | H1 回购 0，发债 $249 亿 |
| 「烧钱税」 | Xbox 体量在缩但仍盈利（亏损未单列） | Reality Labs 年亏约 **$190 亿**，H1 −$86.5 亿 |
| 最大客户/对手集中 | OpenAI：关联收入 $241 亿、RPO 曾占 45% | 无单一大客户（广告主分散） |

### 11.3 结论：谁的现金牛更不受 AI 冲击？

**数据显示的结论分两层，方向相反：**

1. **现金牛对 AI 的「受益确定性」：Meta 更高。** Meta 的广告单价 +12%、展示 +14% 是 AI 推荐/投放提升效果的**已发生**的美元证据；微软的 Copilot 至今没有一个收入数字。若问「AI 有没有已经让现金牛变得更好」，证据站在 Meta 一边。
2. **现金牛对 AI 的「替代抗性」与电厂的「可变现性」：微软更高。** 微软的第一层税挂在身份/合规/文件这类「关门最痛」的基础设施上，且收入来源分散（三分部各占 16%–42%）；Meta 97.6% 收入来自单一广告税，用户注意力一旦被 AI 助手分流，没有第二条腿。更关键的是，微软的电厂**有外部买家**（RPO $6,780 亿），Meta 的电厂只能靠自身广告与尚未商业化的项目回本——因此 Meta 的 capex 强度（~60%）和 FCF 压缩（Q2 仅 $7.84 亿）都更极端。

**但另一方面：**
- 微软的「按人收费」恰恰是 AI 替代劳动力时**最直接暴露**的计价方式——AI 越成功、企业知识工作者越少，席位基数越受压。9-25 的 credits 计量表是对这一风险的回应，但尚无美元证据。Meta 按效果计价，没有这个结构性矛盾。
- 微软外部买电客户中最大的一家（OpenAI）本身就是 AI 冲击的来源之一，且五年预计烧钱 $2,780 亿——「有外部买家」这条优势带着显著的信用折扣。

观点（标注）：**今天的 AI 让 Meta 的现金牛更赚钱、让 Meta 的电厂更难回本；让微软的电厂更容易卖电、却让微软的现金牛面临计价方式的长期挑战。** 两家都在用旧税养新电厂，微软的旧税更难被替代，Meta 的旧税更直接受益——没有哪一家在两个维度上同时占优。

## 13. 段永平式点评

> 「好的商业模式，就是能持续赚钱、不需要太多再投入。」

微软这两个月做对了一件事：没有为了数字去涨 $30 的席位价，而是把「日常用的」和「重度用的」分开收钱。这是把事情做对——用户用得少的不多收，用得多的多付，CIO 能管住预算。段永平会喜欢这种计价的诚实。

但这门生意的前半句——「不需要太多再投入」——在继续失效。自研芯片要多 GW 部署，CFO 说可以借钱，最大的客户五年要烧掉两千多亿美元，而微软积压订单的四成左右系在它身上。办公税还在稳稳地付账单，只是账单越来越大。

上一轮说「这门生意一半看得懂、一半看不懂」。这一轮，看不懂的那一半多了一份价目表，但还是没有一张收入表。10 月 28 日之前，不改分。

> 「看不懂的东西不碰，看懂了也不着急。」——本维只给生意打分，不给价格打分。$543.45 对应的估值是否合理，交巴菲特视角处理。
