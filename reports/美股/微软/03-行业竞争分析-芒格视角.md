## 〇、先给结论：三个反共识判断

1. **在 Synergy 这套唯一能按季度追踪的份额尺子上，Azure 没有继续吃 AWS。吃 AWS 的是 Google。** Q2 2026：AWS 28%、Microsoft 20%、Google 15%（Synergy 官网 2026-07-30）。同比：AWS 30%→28%（-2pt），Microsoft **20%→20%（持平）**，Google 13%→15%（+2pt）。环比：Microsoft 从 Q1 的 21% 掉回 20%。公司增速是另一套故事——Azure +43%、AWS +37%、Google Cloud +82%——**增速差不等于份额迁徙**，因为分母、产品包和硬件转售都不一样。**没有可审计的统一市占率表。**

2. **ChatGPT 是消费级意图入口；Copilot 是企业席位税。两者不是同一张票。** OpenAI 最近一次一手披露：ChatGPT **9 亿周活**、付费订阅 **5000 万**（2026-02-27 / 3 月融资稿，此后未更新）。微软一手：Microsoft 365 Copilot **超过 3000 万付费席位**（FY26 Q4），对照商业席位「超过 4.5 亿」（FY26 Q2）+ 席位同比 +6%，渗透率大约 **6.5%–6.7%**（回推，公司未公布 Q4 席位绝对数）。搜索战场更清楚：StatCounter 2026-07 全球 Google **91.31%**、Bing **4.47%**。开发者战场已经换人：JetBrains 2026 年 5–7 月调查，Claude Code 工作场景采用 **39%**，GitHub Copilot **21%**（一年前 29%）。**办公套件的席位没有被抽走；开发者的「最常用工具」正在被抽走。**

3. **AI 军备把增量租金的很大一块交给了英伟达和电力，但微软的过路费柜台还在运转。** FY2026 购建固定资产现金 **1159.5 亿美元**（10-K 现金流量表），同比 +80%；自由现金流回推 **669.9 亿美元**，低于 FY2025 的 **716.1 亿美元**。Q4 capex **410 亿美元**，约三分之二是短寿命 GPU/CPU。NVIDIA 数据中心 Q1 FY2027 **752 亿美元**、毛利率约 75%。与此同时，生产力分部毛利率仍 **82.1%**，智能云经营利润率仍 **41.3%**。微软同时在收费（席位、Azure 消耗、OpenAI 收入分成至 2030）和修路（电力、机柜、芯片库存）。**2026 年 4 月修订后，修路的独占权已经没了。**

> 芒格：「如果你只盯着市占率数字，你会以为什么都没变。激励和入口路径已经变了。」

## 一、行业规模与增长 ★★★★☆

> 芒格会先问：这个市场变大，是因为企业多买了软件，还是同样的工作负载被 Synergy、Gartner 和三家 IR 用三把尺子量了三遍？云、办公、搜索、生成式 AI **必须分口径**，不能加总成一个「微软 TAM」。

### 1.1 云基础设施：三套尺子，三套故事

| 口径 | 最新数 | 同比 | 来源 | 独立验证 |
|------|--------|------|------|----------|

| 其中公共 IaaS+PaaS | — | +47% | 同上 | 是 |
| GenAI 专项云服务 | — | +165% | 同上 | 部分（Synergy 自有定义） |

| Gartner 2025 / 2026 IaaS | **未检索到官方更新表** | — | — | ⚠️ 截至 2026-08-21 |

**口径陷阱（必须写进团队备忘）**：

- Synergy 分母含 IaaS + PaaS + 托管私有云；Gartner 这张表只含公共 IaaS。AWS 在 Gartner 2024 是 **37.7%**，在 Synergy Q2 2026 是 **28%**。差的不是一年份，是分母。
- 微软公司口径「Azure and other cloud services」含 GitHub 云、Nuance 医疗云、虚拟桌面等，**不是纯 IaaS**。10-K 明文把这些打进同一增长指标。
- Alphabet「Google Cloud」含 GCP **和** Google Workspace，Q2 2026 还首次确认 TPU 系统销售收入。把 247.7 亿美元当「云基础设施」会高估 Google 的 IaaS/PaaS。
- AWS 分部相对最干净，但仍含芯片（Trainium 等）和 AI 服务。Jassy：AI 与芯片业务各自年化超过 **250 亿美元**。
- Synergy 自己把 OpenAI、CoreWeave、Anthropic 列为「云提供商」。OpenAI 既是微软的客户，又出现在 Synergy 的供给名单里。

**因此：本报告拒绝输出一张「统一云市占率表」。下面三张表必须分开读。**

## 二、竞争格局：按战场拆，不要一个「最大对手」★★★★☆

行业不是「微软 vs AWS」。它是六条生意叠在同一块 MSFT 招牌上，对手不同、激励不同、输赢的定义也不同。

| 战场 | 卖的是什么 | 2026 中谁在进 | 谁在出 / 被抽 |
|------|-----------|---------------|---------------|
| 云基础设施 | 机柜、GPU 小时、企业契约 | Google（份额）、Oracle/新云（增速） | AWS（份额缓慢漏）、Azure（份额持平） |
| 生产力套件 | 席位税 + Copilot 附加税 | 微软（席位+6%、美元+16%） | Google Workspace（企业席位无一手数）；Notion 在笔记/Agent，不在 Excel |
| 模型 / 入口 | 对话次数、企业 Agent | ChatGPT（消费意图）、Gemini（搜索内嵌） | Copilot 消费端不是同一量级 |
| 开发者 | 仓库网络 + 编码代理 | Claude Code（采用率）、Codex（增速） | Copilot「最常用工具」份额下降 |
| 广告 / 搜索 | 点击与意图 | Google 仍吃 91%；Amazon 零售媒体 | Bing 在 4% 上爬 0.5pt |
| 芯片 | 训练/推理硅 | NVIDIA（75% 毛利率） | 微软是买方；Maia 是对冲，不是替代 |

### 2.1 没有「一个最大对手」

把 AWS 写成微软的最大对手，是 2018 年的句子。2026 年：

- 云份额的增量对手是 **Google Cloud**（Synergy +2pt，公司增速 +82%）。
- 云利润率的参照系仍是 **AWS**（39% vs 智能云 41%，但 AWS 分母更纯）。
- 办公套件的长期替代威胁是 **Google Workspace + Gemini 捆绑**，不是 Notion。
- 模型层的对手和伙伴是同一个人：**OpenAI**。
- 开发者心智的对手是 **Anthropic Claude Code**，不是 AWS。
- 搜索的对手从来都是 **Google**，2026 年没有新证据显示这一点变了。
- 资本开支的议价对手是 **NVIDIA** 和电网。

## 三、核心竞争者威胁评估 ★★★★☆

### 3.1 云基础设施：AWS —— 份额在漏，利润机器没坏

| 项目 | 数据 | 来源 |
|------|------|------|
| Q2 收入 / 增速 | 422.3 亿，+37% | Amazon IR |
| 年化 run-rate | **1690 亿美元** | Jassy |
| 经营利润 | 166 亿，利润率 39.3% | `16.6/42.232` |
| Synergy 份额 | 28%，同比 -2pt | Synergy / CRN |
| 2026 capex 指引 | Jassy：**2200 亿美元**（全年） | CNBC 引电话会 |

AWS 的激励很清楚：用 18 个季度最快的增速证明「底座最大的人也能再加速」，同时用自研芯片（芯片业务年化超 250 亿）降低对 NVIDIA 的单点依赖。Jassy 的公开逻辑是：24% 增速乘在 1420 亿年化上，和更高百分比乘在更小基数上，不是一回事——这句话在 Q2 +37% 之后仍然适用。

**反面**：Synergy 份额从 2021 年的 32%+ 掉到 28%，不是四舍五入。Google 的美元增量已经追上。若电力和 GPU 供给继续偏向前沿模型客户，AWS 的「企业长尾」优势会重新变成它的护城河；若训练大单继续流向 TPU / OCI / 新云，AWS 会继续漏点。

**威胁评级：★★★★☆**（利润和绝对额仍是标尺；份额叙事已经输给 Google）

### 3.2 云基础设施：Google Cloud —— 2026 年真正在吃份额的人

| 项目 | 数据 | 来源 |
|------|------|------|
| Q2 收入 / 增速 | 247.7 亿，**+82%** | Alphabet 新闻稿 |
| 经营利润 / 利润率 | 88 亿 / 35.5%（上年同期 20.7%） | 电话会 |
| Backlog | **5140 亿美元** | Pichai / 10-Q |
| Synergy 份额 | **15%**，同比 +2pt，环比 +1pt | Synergy |
| 口径杂质 | 含 Workspace；Q2 首次确认 TPU 系统销售 | 电话会 |

Google 的激励变了：Cloud 不再是「证明自己也能做企业」的赔钱广告，而是利润率和 backlog 同时膨胀的增长引擎。TPU 销售把 Google 部分变成了「卖铲人」——这会抬高收入、混淆基础设施份额。电话会说「即使剔除 TPU 系统销售，增速仍显著加速」，但没有给出剔除后的数字。

**反面**：5140 亿 backlog 里有多少是电力兑现不了的大单、有多少是 TPU 硬件、有多少是 Workspace 续约，公开文件拆不开。Alphabet 公司层面自由现金流在 2026 年已被媒体和自身 capex 指引压到紧张（本报告不替代财务角色的 FCF 审计）。

**威胁评级：★★★★★**（对 Azure **份额**而言，这是 2026 年最大的云对手）

### 3.3 云基础设施：Oracle —— 小基数、高增速、负 FCF

| 项目 | 数据 | 来源 |
|------|------|------|
| FY26 IaaS | **181 亿美元**，+77% | Oracle PR 2026-06-10 |
| Q4 IaaS | **58 亿美元**，+93% | 同上 |
| FY26 自由现金流 | **-237 亿美元** | 同稿 |
| Synergy 份额 | Q1 2026 **4%**（CRN）；Q3 2025 约 3% | 第三方转述 |
| GPU 利用率 | 管理层称 **97.5%** | Constellation 引电话会 |

Oracle 的激励是用 IaaS 增速和 AI 大单重估整家公司。它在「训练集群 / 客户自带资本、Oracle 负责设计运维」这条缝里抢微软和 AWS 来不及交付的容量。Synergy 把 Oracle 和新云（CoreWeave、Crusoe、Nebius）放在同一句「增速最高的第二梯队」里。

**反面**：-237 亿 FCF 说明 Oracle 自己也在给英伟达和电力修路，而且修得比微软更痛。4% 份额不是第三名。把 OCI 写成「云格局改写者」需要 backlog 变成收入，而不是新闻稿变成份额。

**威胁评级：★★★☆☆**（对前沿训练容量是真威胁；对微软 4.5 亿办公席位几乎不是）

### 3.4 生产力：Google Workspace —— 企业席位的影子对手

Alphabet **不披露** Workspace 付费席位数。能核对的是：Google Cloud 分部含 Workspace；Gemini 被捆进 Workspace；6sense 一类「域名份额」常给出 Workspace 领先、微软落后——那是把教育和个人 Gmail 算进去的分母。

微软能核对的是：商业席位 +6%、商业产品+云 1020 亿美元、Copilot 从 1500 万涨到 3000 万只用了两个季度。Fortune 级客户名单（AstraZeneca、Boeing、P&G、Wells Fargo 等单户 ≥6 万席）是公司点名，不是第三方估计。

**观点（标为观点）**：Workspace 在中小企业和教育有真实存在感；在受监管的大型企业，转换成本仍然站在微软一边——Outlook/Excel/Teams/Entra 的图，不是 Docs 的图。威胁是 Gemini **零增量或低增量捆绑**改变采购心理，不是明天替换 4.5 亿席。

**威胁评级：★★★☆☆**

### 3.5 生产力：Notion / Apple —— 不要写成「办公套件挑战者」

- Notion：Sacra 估 2026-07 ARR **8.65 亿美元**。对照 M365 商业 1020 亿美元，大约是 **0.8%**。Notion 自己已收缩「重建 Office」叙事，转向跨 SaaS 的 Agent。它抢的是 Confluence / 知识库预算，不是 Excel。
- Apple iWork：免费默认应用，企业协议几乎不存在。它降低的是消费者「为什么要付 Microsoft 365 个人版」的意愿，对商业云 1020 亿美元是边角。

**威胁评级：★★☆☆☆**（Notion） / ★★☆☆☆（Apple，仅消费端）

### 3.6 模型 / 入口：OpenAI —— 既是伙伴，也是 2026 年最大的合同风险

必须按时间拆条款，不能把 2023 年的「独家」沿用到今天。

| 时点 | 公开条款 | 来源 |
|------|----------|------|
| 2025-10-28 | 微软持 OpenAI Group PBC 约 **27%**（约 1350 亿美元估值口径）；OpenAI 承诺增量采购 **2500 亿美元** Azure；微软放弃 compute ROFR；IP 延至 2032；AGI 需独立专家组核实 | Microsoft 官方博客 |
| 2026-04-27 | **取消排他**：OpenAI 可在任何云上服务全部产品；微软仍是「主要云伙伴」，产品「一般先在 Azure 上线」——除非微软做不到或选择不做；微软 IP **非独家**至 2032；微软**不再向 OpenAI 支付**收入分成；OpenAI 向微软的分成维持原比例（CNBC 消息源称 **20%**）、设总上限、至 **2030**、与 AGI 脱钩 | OpenAI 公告；CNBC 2026-04-27 |

激励变了。OpenAI 的激励是多云、IPO 路径、自己当云客户也当云供给（Synergy 已把它列入提供商）。微软的激励是锁定 2500 亿承诺和 20% 分成，同时用 MAI / Anthropic 股权（Q4 确认 Anthropic 投资收益 32 亿美元）降低单模型依赖。

**反面**：2500 亿是多年消耗承诺，不是一年收入。Q4 电话会：商业 RPO **6780 亿美元**，+84%；**环比 RPO 增量全部来自前沿模型公司以外的客户**；剔除 OpenAI 后 RPO +25%。全年云收入「近 90% 来自前沿模型公司以外」。这些句子是微软在主动降低「Azure = OpenAI 一家」的定价。它们也证明：市场担心的正是这件事。

**威胁评级：★★★★★**（合同对手 + 入口对手 + 云客户，三位一体）

### 3.7 模型 / 入口：Google Gemini / 开源

Gemini 的主战场是搜索内嵌和 Workspace，不是「再做一个 ChatGPT」。开源模型（Llama 等）的主战场是企业可私有化部署和开发者本地 Agent。微软的对策写在电话会里：Foundry 上架 **超过 11,000** 个模型（OpenAI、Anthropic、Mistral、xAI、自研 MAI）。这是货架策略，不是押注单一前沿。

开源对 Azure 训练收入是替代；对 Copilot 席位税是互补——企业仍要把 Agent 挂在身份、邮件和文件图上。替代是否发生，看的是 GitHub / VS Code 是否还是默认外壳，而不是模型权重印着谁的名字。

**威胁评级：★★★☆☆**（Gemini 对搜索） / ★★★☆☆（开源对训练消耗）

### 3.8 开发者：GitHub vs Cursor / Claude Code —— 仓库还在，代理已经换人

| 指标 | GitHub Copilot | Cursor | Claude Code | 来源 |
|------|----------------|--------|-------------|------|
| 公司一手用户 | Q4：**5000 万用户**；GitHub 平台 **2.25 亿用户** | 不披露 | 不披露 | Nadella Q4 |
| 付费订阅（旧数） | FY26 Q2：**470 万**，+75% YoY | 第三方「100 万+」 | 第三方区间 | 微软 Q2；博客二手 |
| JetBrains 工作采用 Jan 2026 | **29%** | 18% | 18% | AI Pulse（>1 万开发者） |
| JetBrains 工作采用 May–Jul 2026 | **21%** | **12%** | **39%** | Developer Ecosystem 2026（>1.5 万） |
| 「最常用工具」 | — | — | **31%**（转化率约 80%） | 同上 |
| 满意度（旧波次） | most-loved 9% | 19% | 46%；CSAT 91% | AI Pulse 2026-01 |

**口径必须分开**：微软的「5000 万用户」不是 JetBrains 的「工作采用率」，也不是 470 万付费订阅。JetBrains 是抽样调查，有地区加权，不是普查；但它是目前唯一按同一问卷追踪 2025–2026 的公开序列。

反问题 2 在开发者这条线上的答案：**GitHub 作为仓库网络没有被抽走（2.25 亿用户、Fortune 500 超 90%、三分之一 PR 有 Agent）。GitHub Copilot 作为「开发者最常用的 AI 工具」正在被抽走。** Q4 电话会承认 6 月改成按用量计费后消耗好于预期——这是在用价格模型追回已经被 Claude Code / Codex 抢走的心智。

Cursor 的 ARR 故事（第三方 20–40 亿美元）与 JetBrains 采用率下行（18%→12%）冲突。本报告把 Cursor 标为「收入口径与采用口径对不上」，不把它写成已经取代 GitHub 的平台。

**威胁评级：★★★★☆**（对 Copilot 产品） / ★★☆☆☆（对 GitHub 仓库网络）

### 3.9 广告 / 搜索：Google —— 对手从未变

FY26 微软搜索广告 151.8 亿美元；Google 搜索单季 632.7 亿美元。StatCounter 全球 91.31% vs 4.47%。ChatGPT 9 亿周活是并行入口，但 Similarweb 一类研究在 Google 报告里显示与 Google 用户高度重合——意图查询仍大量落回 SERP。

微软搜索的真实功能是：给 Edge / Windows 默认值变现，不是挑战 Google。Q4 指引搜索广告 ex-TAC 增速降至中个位数（第三方合作影响）。这不是「AI 搜索崛起」的句子，是联盟流量的句子。

**威胁评级：★★★★★**（对搜索） / ★☆☆☆☆（对办公和 Azure）

### 3.10 芯片：NVIDIA —— 供应商议价，不是产品对手

| 项目 | 数据 | 来源 |
|------|------|------|
| 数据中心收入 | Q1 FY27 **752 亿美元**，+92% | NVIDIA IR |
| Hyperscale | 约 **379 亿美元** | 新分部 |
| 毛利率 | GAAP 指引约 **74.9%** | 指引 |
| Q2 FY27 | **尚未发布**（预告 2026-08-26） | Hudson Labs / 公司日程 |
| 微软 Q4 capex 中短寿命资产 | 约三分之二（约 **275 亿美元**） | Hood；`41*0.67` |

Nadella 在 Bg2 Pod 的原话大意：问题不是芯片供给，是没有通电的机柜（warm shells）把已到货的 GPU 插上。DCD、CFO Q1 电话会交叉印证。微软的对冲是 Maia 200（自称单位美元性能 +30%）和 Cobalt CPU。对冲降低的是边际，不是 NVIDIA 对训练集群的定价权。

**威胁评级：★★★★☆**（对 capex 和毛利率）——供应商议价，不是抢客户

## 四、细分赛道格局 ★★★★☆

### 4.1 办公：席位没被抽走，渗透率刚开始

3000 万 Copilot / 4.5–4.64 亿商业席位 ≈ **6.5%–6.7%**。这意味着超过 90% 的付费席位还没交 Copilot 税。反面同样成立：从 1500 万到 3000 万发生在两个季度，其中 Q4 是财年结束、大单集中的季度——办公室 365 评论（office365itpros）提醒过这一点，不能把「两个季度翻倍」外推成线性。

ChatGPT 5000 万付费 vs Copilot 3000 万席位：ChatGPT 含大量 20 美元消费者；Copilot 是 30 美元/用户/月的企业附加（标价，成交价有折扣）。**谁是意图入口？消费者问问题，去 ChatGPT；雇员在 Outlook 里改纪要，被收 Copilot 税。** 入口是 ChatGPT；收银机在微软图里。

### 4.2 搜索：并行层，不是替代层

Bing 4.47% 对 Google 91.31%。Copilot.com / Windows 键唤起的对话，StatCounter 不算搜索份额。把「AI 聊天」加进搜索分母，Google 和微软的份额都会被稀释——稀释的是点击，不是微软突然变成搜索第二。微软搜索广告一年 152 亿美元，Google 搜索一个季度 633 亿美元。

### 4.3 开发者：平台一层、代理一层

GitHub 赢的是默认仓库和 PR。Agent 层 2026 年 5–7 月的赢家是 Claude Code。微软的反击是：把 MAI、OpenAI、Anthropic 都塞进 Copilot，并改成用量计费。这是货架 + 计价，不是重新赢得「最爱」。

### 4.4 云：容量比份额更紧

Q4：客户需求继续超过可用容量；指引 Q1 FY27 Azure 约 **+45%** 恒定汇率。RPO 6780 亿。约束从「有没有 NVIDIA」变成「有没有电和壳」。谁先通电，谁先把 backlog 变成收入——这是 Google、Oracle、新云和微软的同一场比赛，不是定价权比赛。

## 五、行业趋势 ★★★★☆

### 5.1 技术：模型层多云，应用层仍要身份和图

2026 年 4 月条款之后，「GPT 只能在 Azure 上训练和调用」不再是行业结构。行业结构变成：前沿模型在哪都能跑；企业 Agent 仍要挂在邮件、文件、工单和 Entra 上。微软押注后半句。前半句已经被 OpenAI、Amazon Bedrock、Google 同时验证。

### 5.2 监管：欧盟要把云塞进 DMA，美国还在取证

| 辖区 | 状态（截至 2026-08-21） | 来源 |
|------|-------------------------|------|
| 欧盟 DMA | 2026-06-25 **初步认定** AWS 与 Azure 为守门人（即使未达数量门槛）；理由含锁定、转换成本、AI 成为采购决定因素 | 欧委会；DCD / Bratby Law |
| 英国 CMA | 对同一两家走**自愿承诺**，与欧盟分道 | Bratby Law |
| 美国 FTC | 2024-11 起 CID；2026 年扩大到至少六家对手，问捆绑、许可、互操作、Entra ID、Copilot | The Verge / CIO |
| 日本 FTC | 微软称配合调查 | The Verge 引公司 |

初步认定不是终局。若欧盟确认，义务在六个月内生效，罚则可达全球营业额 10%。这是对「用 Office/身份把工作负载锁在 Azure」这套激励的直接攻击。反面：CMA 说明发达市场可以得出相反程序结论；云市场 2026 年增速 43%，委员会自己也承认定量门槛没达到。

### 5.3 电力与数据中心：约束从芯片换成瓦特

IEA：数据中心用电 2025 年 485 TWh，2030 年 950 TWh。Nadella：芯片在库存里插不进去。Hood：即使 Q4 多交付了容量，约束至少持续到 2026 年。变压器交货周期被行业媒体写成以年为单位。微软的行为（租赁机柜、自建、核电/燃气双边）是对激励的理性反应：谁先有瓦特，谁先确认收入。

### 5.4 新进入者：新云是训练缝，不是办公缝

Synergy 点名 CoreWeave、OpenAI、Crusoe、Nebius、Nscale。它们吃的是 GPU 小时。它们不签发 Entra 令牌，也不替换 Excel。对 Azure 训练收入是真竞争；对 3000 万 Copilot 席位几乎无关。

## 六、产业链与价值分配 ★★★☆☆

> 芒格会问：增量一美元的云账单，最后停在谁的口袋？

```
上游：电力 / 天然气 / 核电 → 变压器 / 液冷 → NVIDIA / 存储 / 定制硅
中游：超大规模云（AWS / Azure / GCP / OCI）+ 新云
下游：模型实验室（OpenAI / Anthropic / Google / xAI）→ 企业套件与 Agent → 广告与搜索
```

| 环节 | 商业模式 | 可观察利润信号 | 2026 年租金方向 |
|------|----------|----------------|-----------------|
| NVIDIA | 卖铲 | 数据中心毛利率 ~75%；单季 752 亿 | **吸入** |
| 电力与电网 | 卖瓦特 / 并网排队 | IEA 485→950 TWh；warm shell 短缺 | **吸入**（量），价格因辖区而异 |
| 超大规模云 | 卖小时 + 卖契约 | Azure 智能云毛利率 58.0%（上年 62.2%）；AWS 经营利润率 39% | **被挤压但仍厚** |
| 模型实验室 | 卖订阅 / API | OpenAI 一手收入已数月未更新；分成给微软至 2030 | 不确定 |
| 企业套件 | 卖席位税 | PBP 毛利率 **82.1%**，经营利润率 **59.9%** | **仍是最肥的过路费** |

FY2026 智能云：收入 +30%，销售成本 +44%（578.8 / 401.7 亿 = **1.44 倍**）。毛利率从 62.2% 压到 58.0%。这就是「修路」在报表上的形状。同一年生产力分部经营利润 **838.8 亿美元**，利润率近 60%——过路费柜台还在。

Q4 自由现金流 196 亿美元（经营现金流 554 亿 − 购建 358 亿）。FY26 自由现金流回推 670 亿，低于上年 716 亿。净利润 1337 亿美元在涨，现金被机柜和 GPU 截走。Hood 把日历年 2026 capex 从约 1900 亿（含约 250 亿元件涨价）因租赁重分类调到约 **1750 亿美元**——投资意图没变，会计口径变了。

**微软是收过路费还是给别人修路？** 两边都是。对 4.5 亿席位和 Copilot 附加税，它在收费。对 Q4 410 亿 capex 里约 275 亿短寿命硅，它在给 NVIDIA 和存储厂修路。对 OpenAI，它同时是房东（2500 亿承诺）、股东（约 27%）和分成收款人（至 2030）——4 月之后不再是独家房东。

## 七、芒格模型：逆向、激励、Lollapalooza

### 7.1 逆向：聪明人为什么不信「微软最稳」

反过来问：2026 年已经发生、但共识句还没改写的事实是什么？

| 共识句 | 反向事实 | 置信度 |
|--------|----------|--------|
| Azure 继续吃 AWS | Synergy 份额 20%→20%，环比 21%→20%；被吃的是 AWS→Google | 高（第三方序列） |
| Copilot 锁死办公入口 | 渗透 6.5%；消费意图在 ChatGPT 9 亿周活 | 高（单位不同，必须拆） |
| GitHub 赢了 AI 编程 | JetBrains：Copilot 工作采用 29%→21%，Claude Code 18%→39% | 中高（调查，非普查） |
| OpenAI 是微软护城河 | 2026-04 排他取消；IP 非独家；可上任何云 | 高（双方公告） |
| 软件利润免疫 capex | 智能云毛利率 -4.2pt；FCF 670 vs 716 亿 | 高（10-K） |
| Bing 借 AI 翻身 | 4.47% vs 91.31%；搜索广告一年 < Google 搜索一季 | 高 |

还在的东西（观点须标为观点）：办公图与身份的转换成本、Azure 混合云与企业销售机器、GitHub 仓库默认、Windows/Edge 分发、2500 亿 Azure 承诺的下限、20% 分成至 2030。**不是护城河的东西**：独家模型、Synergy 份额上升、搜索挑战者叙事、Copilot 等于 ChatGPT。

### 7.2 激励：谁拿钱，谁就会怎么做

| 主体 | 旧激励 | 新激励（2025–2026） | 可预期行为 |
|------|--------|---------------------|------------|
| 企业 CIO | 把工作负载迁到「三家之一」 | AI 容量短缺 + DMA/FTC 问捆绑 | 多云；把训练丢给有电的人；办公仍续微软 |
| OpenAI | Azure 独家换资本 | 多云 + 分成上限 + 自建供给 | 把溢出训练给 AWS/OCI/自建；Azure 仍拿优先上架 |
| 开发者 | 公司发 Copilot 席位 | 个人用 Claude Code / Codex 更快 | 双工具；采购 Copilot，真爱 Claude |
| NVIDIA | 卖完 H100 | 卖 Blackwell / 收 75% 毛利 | 继续对超大规模客户保持定价权 |
| 微软财务 | 用份额故事证明投资 | 用 RPO「非前沿客户」和 90% 非实验室云收入证明质量 | 主动淡化 OpenAI 集中度 |
| 监管 | 管应用商店和搜索 | 把云和身份捆绑写成守门人问题 | 欧盟先行，美国取证 |

「告诉我激励，我就告诉你结果」：JetBrains 的采用率逆转，是开发者激励（谁能把多文件任务做完）压过了采购激励（谁在 EA 协议里）的结果。Synergy 份额持平，是微软把稀缺瓦特优先给高价 Azure 消耗、而 Google 用 TPU + 激进交付去抢增量的结果——这是观点，但与「需求超过供给」的公司原话相容。

### 7.3 Lollapalooza：三股力有没有同向？

**对「Azure 吃份额」叙事：已经同向，而且方向是负的。**

1. Synergy 份额同比持平、环比掉点；
2. Google 美元增量追上 AWS，TPU 出货混淆分母；
3. OpenAI 排他取消，最大训练客户获得合法外溢权。

三力都指向：2026 年云故事的主角是「容量与 Google」，不是「微软继续夺取第二名以上的位置」。

**对「软件过路费」：尚未同向摧毁。**

PBP 毛利率 82%、经营利润 839 亿、Copilot 3000 万席、商业席位仍 +6%。要把过路费也打穿，还需要第四力——监管拆捆绑，或开发者 Agent 绕过 Office 图直接写进仓库与浏览器。第四力在调查和调查里，不在 FY26 的利润里。

**对行业利润池：同向指向上游。**

短寿命硅占 Q4 capex 三分之二、NVIDIA 单季数据中心 752 亿、IEA 用电翻倍、微软 FCF 下滑。租金从「卖软件许可证」部分迁到「卖 GPU 小时和瓦特」。微软两边都有位子，但 2026 年新增的位子更像房东和施工队，不像 2016 年那种纯软件收租人。

## 十、给 Team Lead 的五条发现

1. **先把「云市占率」从模型里拿掉，改成三列并列、禁止加总。** Synergy Q2 2026：AWS 28% / MSFT 20% / Google 15%，市场 1434 亿美元。Gartner 最新官方 IaaS 仍是 2024：37.7% / 23.9% / 9.0%。公司口径：Azure FY26 >1000 亿 +41%、AWS 单季 422 亿 +37%、Google Cloud 248 亿 +82%（含 Workspace 与 TPU 销售）。三套分母不能合成一张表。财务角色应用 Azure 增速、智能云毛利率、RPO 剔前沿客户，而不是「份额第二」。

2. **Azure 没有继续吃 AWS；吃 AWS 的是 Google。** Synergy 同比：Microsoft 20→20，AWS 30→28，Google 13→15。环比 Microsoft 21→20。公司增速 Azure 快于 AWS（43% vs 37%），但美元增量上 Google Cloud 已与 AWS 打平（+111.4 亿 vs +113.6 亿，`calc` 偏差 2.15 亿）。「增速更快 = 在吃份额」在分母膨胀 43% 的市场里不成立。

3. **意图入口是 ChatGPT；收银机是 Copilot 席位税。不要比较 9 亿周活和 3000 万席位谁赢。** 前者是 2026-02 一手、单位是周活；后者是 FY26 Q4 一手、单位是企业付费席位，渗透约 6.5%。搜索更极端：Bing 4.47% vs Google 91.31%，微软全年搜索广告 152 亿 vs Google 单季搜索 633 亿。办公席位 +6%、美元 +16%，**没有被抽走**。被抽走的是开发者「最常用 AI 工具」：JetBrains 5–7 月 Claude Code 39% vs Copilot 21%。

4. **OpenAI 条款已经从护城河改成有期限的分成 + 非独家 IP + 可外溢的 2500 亿承诺。** 2025-10-28 放弃 ROFR；2026-04-27 放弃排他、微软停止向 OpenAI 付分成、OpenAI→微软分成设帽至 2030。Q4 管理层用「环比 RPO 增量全部来自非前沿客户」「云收入近 90% 非实验室」来对冲市场对集中度的定价。综合报告应把 OpenAI 同时标为客户、股东、分成对手和入口竞争者，而不是护城河。

5. **Lollapalooza 对份额叙事已经同向为负；对过路费还没有。** 份额持平 + Google 抢点 + 排他结束，三力拆掉「微软最稳的云故事」。反面必须写进综合报告：PBP 经营利润 839 亿、利润率 60%；智能云经营利润 570 亿、利润率 41%；Copilot 两个季度从 1500 万到 3000 万。真正的第四力是监管拆 Entra/Office 捆绑，或 Agent 绕过 Office 图。FY26 这第四力还在 CID 和 DMA 初步认定里，不在利润表里。Capex 侧：购建 1160 亿、FCF 670 亿（低于上年 716 亿）、Q4 约 275 亿短寿命硅——增量租金的上游归属可以核对，不必靠比喻。
