## 一句话结论

**Connectivity（Starlink）赚的是真钱，而且越来越多；公司整体的 GAAP 利润一半不是经营所得，现金被 SI 的资本开支整体吞掉。** Q3 净利润 4,404 中约 49% 来自利息收入以外的非经营项和税收[中]；9M 自由现金流 −34,972[高]，剔除客户预付和融资购置设备后的"经济 FCF"约 −42,443[中]。本文内在价值区间 **每股 50–80 美元（中枢约 65）**，现价 134.72 比中枢高约 92%，**没有安全边际**。主动买入价 ≤ 50，持有上限 80，都比 thesis 第 5 节严（thesis：买入 ≤ 65、持有带 60–85）。

IPO 前可赎回优先股 38,752 列在夹层，股东权益只有 2,573；IPO 和转股后跳到 176,768。任何跨越 2026Q2 的 ROE 都无意义。

| 公司 ROIC（再剔商誉与无形） | 12.4% | 中 | |

**纠正一个旧口径**：10-Q MD&A 说递延收入增加主要来自 **Space 与 Connectivity 客户预付**，不是 SI 客户。上轮季报"约三分之一来自 SI 客户预付"的说法应改为"来自政府与企业的发射/通信预付"。这类预付对应 62,959 积压订单，质量比算力预付高。

维护性 vs 扩张性（估计）：D&A 年化约 146 亿，可视为维护性上限；其余约 80% 为扩张性。Connectivity 自己的 capex 只占 9M 的 8.8%，**它完全养得活自己**。

### 3.3 FCF 与"经济 FCF"

- 9M FCF = 13,097 − 48,069 = **−34,972** [高]；Q3 单季 −9,962 [中]
- 经济 FCF（剔除递延收入、加上融资购置、扣返利）= **−42,443** [中]
- FY2023–9M'26 累计 FCF = **−54,206** [高]

**会计陷阱预警（发现）**：Apollo 约 400 亿 GPU 融资租赁（8-K，2027H1 起租）走的是**租赁资产，不进"购置 PP&E"一行**；租金中的本金（每季 1/20）进融资活动。Valor 失败回租同理。**结果是 2027 年报告的 capex 可能下降、FCF"改善"，而经济实质上的设备投入并没有减少。** 巴菲特口径的所有者盈余必须用"capex + 融资租赁本金 + 失败回租本金"。

### 3.4 现金跑道

| 项目 | 金额 | 置信度 |
|---|---:|---|
| Q3 末现金 + 有价证券 | 89,855 | 高 |
| Q4 capex 指引 | 35,000–40,000 | 转述 |
| YE2026 现金估计（乐观/中性/悲观） | 72,470 / 61,970 / 49,643 | 低 |
| 2027 刚性现金需求（不可撤销承诺 25,569 + 债务到期 2,425 + 频谱现金 8,500 + 信贷付款 828） | 37,322 | 中 |
| Apollo 满额后年租金（本金 8,000 + 利息约 2,700） | 约 10,700/年 | 低 |
| 2027E 中性 Adj. EBITDA / OCF | 85,760 / 72,896 | 低 |
| 2027 资金缺口（capex 1,500 亿 / 2,500 亿） | 77,104 / 177,104 | 低 |
| 管理层"+10 GW"若按 300 亿/GW 自建 | 约 300,000 | 低 |

**解读**：短期（12 个月）不存在流动性危机——10-Q 自称现金与 50 亿循环额度足以覆盖未来 12 个月，债务 2031 年前无大额到期。但 2027 年的扩张计划在任何合理假设下都需要 **770–1,770 亿外部融资**（债务、租赁或增发）。

**FCF 何时转正（情景，估计）**：
- 乐观（25%）：2028 下半年。条件：Anthropic 续约、单瓦定价不降、2028 capex 主动降档。Oracle 在 10/28 投资者日给的同类时点是 FY28 下半年，可作参照。
- 中性（50%）：2029 年。2027–28 继续以租赁和债务扩张，FCF 持续为负。
- 悲观（25%）：靠自身无法转正。Anthropic 2027 终止，SI 收入断崖，capex 被迫砍，但 Valor/Apollo 租金是刚性的。

**但另一方面**：管理层随时可以停下扩张。D&A 年化约 146 亿，而 Q3 年化 Adj. EBITDA 352 亿，只做维护性投资的话公司马上就能产生正 FCF。负 FCF 是选择，不是被迫——前提是 SI 的增量回报确实高于资金成本。

**发现 1：债券市场比股票市场冷静。** 10-Q 披露 SpaceX 票据公允价值 22,932，只有账面的 **92.3%**[高]。发行四个月跌约 8%，含利率上行和信用利差走阔两种因素，10-Q 未拆分。股价约等于 IPO 价 135，相当于持平；债券持有人则已经要求更高的收益率。

**发现 2：失败回租的实质。** CTC 把 GPU 卖给 Valor 再租回，因为租约实质是融资租赁，会计上不承认出售，资产留在表内、负债记为债务。实质就是**以 GPU 为抵押、年化约 10.9% 的关联方贷款**，利率比同期投资级票据高约 5 个百分点。按约 129 亿余额计，每年多付约 6.5 亿利息[低]。

### 4.2 商誉

商誉 48,423，占权益 27.4%；含无形资产占 31.0%。SI 分部 47,908，其中 Cursor 36,646（对价 42,474，可辨认净资产只有 5,828）。Cursor 全季收入约 1,147，年化约 46 亿[中]。按 GAAP 对价算 9.3 倍收入，按隐含 600 亿算 13.1 倍。
- **减值风险（短期低）**：减值测试看报告单元公允价值，SPCX 市值远高于账面，2026–27 年触发概率低。
- **但另一方面**：Cursor 的最大竞争对手之一（Claude Code）属于 SpaceX 的第一大客户 Anthropic。若 Cursor 增速失速且 SPCX 股价大跌，减值会在同一时间到来。

### 4.3 Spectrum 交易

名义对价 196 亿 = **111 亿股票（固定 261.8 百万股 × 42.40）+ 最多 85 亿承接 EchoStar 债务**；另有信贷协议利息代付（2026 年 1,241、2027 年 828，若 2028 交割再加 827）[高]。股数是固定的，按现价算股票部分价值约 353 亿，是名义的 3.2 倍；对现有股东的实际成本是 **1.93% 的摊薄 + 约 85 亿现金**。预计 2027-11-30 交割，交割后现金或再融资支付[高]。

### 5.2 股权激励：真实成本

- Q3 SBC 合计 2,363 = 收入的 16.2% = **营业利润的 84.7%**[高]
- Cursor 留任奖励 23,376 分 2.8 年摊销，约 **2,087/季**[中]；Q4 起比 Q3 多约 870
- 未归属业绩股 1,333 百万股（市场/业绩条件未满足），全部归属则摊薄 **9.6%**[高]
- CFO 期权按"每增加 100 亿 Adj. EBITDA"分批归属（S-1）。管理层报酬挂在一个剔除 SBC 与折旧的指标上。

> 巴菲特："如果期权不是薪酬，那是什么？如果薪酬不是费用，那是什么？"——Adj. EBITDA 8,809 与营业利润 2,791 之间差了 6,018，其中 2,363 是 SBC，3,644 是 GPU 与卫星折旧。两者都是真实成本。

### 5.3 估值备抵释放：未来 GAAP EPS 的放大器

10-Q 原话：可预见未来"合理可能"释放美国递延税资产的大部分估值备抵，届时确认**重大一次性所得税收益**[高]。规模未披露。用累计亏损 37,448 × 21% 做粗略上限，约 **78.6 亿**，折每股 0.58[低]。若在某一季确认，该季 GAAP EPS 可能达到约 0.75（正常化单季 0.17 + 0.58）[低]，TTM PE 会瞬间"变便宜"。**这是会计数字，不是现金**；现金税本来就因 NOL 接近零（9M 只付 66）。

### 5.4 利润质量信号灯

| 检验 | 信号 | 依据 |
|---|---|---|
| OCF / 净利润 | 🟢 | 9M OCF 13,097 vs 净亏损 413；OCF / Adj. EBITDA 97% |
| OCF 是否依赖预付 | 🟡 | 递延收入占 37.6%，但来自 Space/Connectivity 合同 |
| 应收 vs 收入 | 🟢 | 同步，DSO 稳定 |
| 非经常性收益占比 | 🔴 | 49% |
| SBC 强度 | 🔴 | 营业利润的 85% |
| 资本化支出 | 🟡 | 资本化利息与 SBC 上升，与在建工程匹配；GPU 折旧年限仍未披露 |
| 客户集中度 | 🔴 | 客户 B 占 SI 收入 66.5%、占外租算力收入 **78.4%**[中] |
| 关联方 | 🔴 | 高息关联方回租 + TBC 重估入利润 |
| FCF | 🔴 | 三年半累计 −542 亿 |

**结论**：没有收入造假的迹象（应收、存货、DSO 干净）；问题出在**利润薄、利润结构不可持续、现金被资本开支吞掉**。

## 7. 总体结论

**财务质量：★★（2/5）**
- 支撑因素：Connectivity 是一门 ROIC 约 40%、Adj. EBITDA − capex 每季 +19.6 亿、9M 增速 57% 的真钱生意；没有收入造假迹象；净现金 510 亿，债务契约宽松。
- 扣分因素：GAAP 净利润约一半来自非经营项；SBC 相当于营业利润的 85%；三年半累计 FCF −542 亿；SI 外租收入 78% 来自一个 90 天可撤销的客户；关联方以约 10.9% 利率提供 129 亿融资；Apollo 租赁会让"报告 FCF"好看于实质。

**安全边际：★（1/5）**
- 现价 134.72 比本文内在价值中枢 65 高约 92%，比概率加权值 78 高约 72%。只有乐观情景（25%）能支撑现价。

**内在价值区间：每股 50–80 美元，中枢约 65。** 买入价 ≤ 50，持有上限 80。现有 12/18 90 沽维持持有到期；**不新开 85 以上行权价的卖沽**，85 沽也只在正股回落到 110 以下、权利金达标时再议。thesis 的买入带建议从 ≤ 65 下调到 ≤ 50，持有带上沿从 85 下调到 80，交 Team Lead 裁定。

**改变结论的条件**：
- 上调：2027 年两个连续季度整体 FCF ≥ 0（扣除租赁本金后）；Anthropic 不可撤销期过后仍续约且客户 B 占比降到 25% 以下；10-K 披露的 GPU 折旧年限 ≤ 5 年且 SI 营业利润率仍 ≥ 20%。
- 下调：Anthropic 发出终止或缩减通知（悲观情景，内在价值约 14–25）；Q4 毛利率低于 55%；新增关联方融资利率超过 10%。
