## 研究框架概览与核心结论（2026-11-02 团队研究）

**核心结论**：SpaceX = 一门五星生意（入轨成本：Falcon + Starlink 是同一条护城河的两个出口）外套一门二星买卖（SI 算力出租）。现价 134.72 等于中性情景 5 年后目标价，市场把 SI 按护城河定价，证据只支持按期权定价。**现价不买；接货上限 80，买入 ≤ 55。** 最近的检验日期：2026-12-18（90 沽到期）、2027-01-15（Anthropic 终止窗口开启）、2027-02（10-K）。详见 [team-20261102/最终报告.md](team-20261102/最终报告.md)；长期追踪见 [SpaceX-thesis.md](SpaceX-thesis.md)。

## 论文基线（2026-10-21 建立；2026-11-02 起由 [SpaceX-thesis.md](SpaceX-thesis.md) 取代，本节仅存档）

SpaceX = 一门五星生意（Starlink）+ 一门五星但增长停滞的生意（发射）+ 一门占一半收入、八成 capex、合同可 90 天撤销的二星生意（SI）。市价按三条护城河定价，证据只支持两条。

**强化条件**：SI 合同续约不降价；GPU 回收期被 10-Q 数据证实；Starship 节奏兑现。
**削弱条件**：Anthropic / Google 2027 年减量或自建；Q4 毛利率回落超过 7 个百分点；关联方债务继续以约 11% 利率扩张。
