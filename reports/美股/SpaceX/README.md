## 论文基线（2026-10-21 建立）

SpaceX = 一门五星生意（Starlink）+ 一门五星但增长停滞的生意（发射）+ 一门占一半收入、八成 capex、合同可 90 天撤销的二星生意（SI）。市价按三条护城河定价，证据只支持两条。

**强化条件**：SI 合同续约不降价；GPU 回收期被 10-Q 数据证实；Starship 节奏兑现。
**削弱条件**：Anthropic / Google 2027 年减量或自建；Q4 毛利率回落超过 7 个百分点；关联方债务继续以约 11% 利率扩张。
