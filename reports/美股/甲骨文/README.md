## 核心结论（2026-11-10 首轮团队研究）

**综合评分 2.25 / 5。现价 119.79 不买正股；当前不卖任何认沽；进入"条件式卖沽"候选池，行权价上限 90。**

- 两门生意一张表：数据库+应用收租生意（值约 55 美元/股）+ 客户约一半为 OpenAI 的 GPU 包工生意（5 年合同 vs 15–19 年租约，RPO 6,640 亿的主体）。
- 内在价值中枢约 110（区间 85–145）；买入带 ≤77、加码 ≤65；持有带 77–90；不接货上限 90。OpenAI 砍单 30–50% 情景：65 / 52–65 / ≤45。
- 剔客户预付款后 FCF：FY26 −283 亿、Q1 FY27 −168 亿；全口径负债与承诺约 3,109 亿 = FY27 估计 EBITDA 5.9 倍；S&P BBB− 距垃圾级一步，5 年 CDS 约 300bp。
- 卖沽四道门槛（行权价 ≤90 / 到期不跨财报 / 买价年化 ≥12% / 锁定后类现金 ≥20% NAV）：11/10 事件窗口与账户两项不过。
