**A级研究声明**

资料多 ≠ 确定性高。IBKR 的默认输出极易写成「全球最低成本券商 + 账户狂增 + 净息差印钞」。本底稿的工作不是证明它「很好」，而是检验四件事：

1. **收费对象是谁？** 佣金向主动交易者收执行税；NII 向客户闲置现金和融资余额收利差——两门生意，不是一门。
2. **低价格是护城河还是自杀协议？** 段永平要的是能提价的差异化，不是永远最便宜。
3. **利率下行会不会把「印钞机」关掉？** 公司自己给了 25bp 敏感度。
4. **公众股东买到的是整家券商，还是 IBG LLC 的 26.5%？**

## 0. 市值与财务快照（供商业判断，估值交给财务分析师）

### 0.1 必须先拆开的股权结构

IBKR **不是**「一家券商 = 一张股票」。

| 实体 | 2026-06-30 | 来源 |
|------|------------|------|
| IBG LLC 会员单位 | **17.014 亿** | EX-99.1 股权表 |
| 其中 IBG, Inc.（上市公司） | **4.507 亿（26.5%）** | 同上 |
| 其中 IBG Holdings LLC（Peterffy 等） | **12.507 亿（73.5%）** | 同上 |
| Class A 流通 | **4.5057 亿** | 10-Q / 424B5 |
| Class B | **400 股** | 10-Q。Holdings 通过 Class B 投票 |

2026-08-20 收盘 **$89.85**（stockanalysis 历史价；exa 日线 $89.85）。StockAnalysis 当前股本 **4.5308 亿**（含 6/30 后单位兑换）× $89.85 = **$407.1 亿**。

**陷阱**：Macrotrends / CNBC 页头市值约 **$1540 亿**，是把 17.01 亿 LLC 单位全部乘股价。那是「若 Holdings 全部换成 Class A」的隐含整体估值，**不是**公众公司市值。本底稿用 **$407 亿**。

### 0.2 收入结构：两台发动机

TTM 至 2026-06-30 净收入（公司季报加总）**$68.63 亿**。Macrotrends $68.63 亿；StockAnalysis 标准化 $68.35 亿（偏差 0.41%）。

|------|-----|---------|--------|--------|
| 净利息收入 NII | **$38.94 亿** | **56.7%** | $35.63 亿 | $31.48 亿 |
| 佣金 | **$24.05 亿** | **35.0%** | $21.49 亿 | $16.97 亿 |
| 其他费用与服务 | $3.24 亿 | 4.7% | $2.91 亿 | $2.80 亿 |
| 其他收入 | $2.40 亿 | 3.5% | $2.02 亿 | $0.60 亿 |

Q2 2026 单季：佣金 $6.73 亿（+30%），NII $10.57 亿（+23%），净收入 $18.96 亿，税前 $14.56 亿，**税前利润率 77%**。归母净利 $3.12 亿（公众 26.5% 那一层）。

**观点**：把 IBKR 写成「佣金券商」已经过时。按美元，它首先是**客户资产负债表上的利差生意**，其次才是交易执行。

## 1. 生意本质：一句话

> 向全球主动交易者、对冲基金和介绍经纪商（IB）提供自动化执行与清算；向其闲置现金和融资余额收净息差；用软件替代人工，把税前利润率做到 70% 以上。

收费对象拆成三层：

| 层 | 客户付什么 | 公司赚什么 |
|----|-----------|-----------|
| 执行 | 每笔可计佣订单约 **$2.56–2.64**（7 月 $2.56；Q2 $2.64） | 佣金 − 交易所/清算费。Q2 交易毛利率约 **83%**（剔市场数据等非交易费用后，电话会） |
| 资产负债表 | 融资利率；闲置现金只拿到低于公司投资收益率的利息 | 融资利差 + 隔离现金再投资利差 + 证券借贷 |
| Lite / 订单流 | 美股/ETF「零佣金」 | 做市商支付。FY2025 PFOF **$5100 万**（10-K 合同收入表），相对 $21.49 亿佣金是零头 |

10-K：无单一客户占 2025 年佣金超过 **2%**。客户在 200+ 国家和地区。目标客户是「要全球接入、要低综合成本、要闲置现金拿市场利率」的人——不是 Schwab 的顾问托管户，也不是 Robinhood 的 $12k 账户。

**但另一方面**：NII 占比过半，意味着这门生意的利润对**利率和客户杠杆**的敏感度，高于对「下一笔股票单」的敏感度。段永平要的「简单」，在佣金层成立，在利差层变成小型银行。

## 2. 飞轮怎么转

1. **低综合成本 + 全球产品**吸引主动交易者和 IB（介绍经纪商把零售单导到 IBKR 清算）。
2. 账户数起来 → 客户权益和闲置现金起来 → **NII 在佣金之外再收一张税**。
3. 融资余额起来（7 月 $1007 亿，+49% YoY）→ 利差再放大。这是飞轮也是风险（见李录底稿）。
4. 软件规模效应：Q2 员工 **3,265** 人，对应 TTM 净收入 $68.6 亿、税前约 $53.6 亿。人工成本 Q2 仅占调整后净收入 **10%**。
5. 介绍经纪商管道：电话会称 pipeline「仍然非常强」。这是 B2B 获客，CAC 低于大众零售广告。

Peterffy 在 Q2 电话会：营销开支增加后，**获客效率（marketing yield）并没有更高，只是同比例多花多得**。账户增速从管理层口头「常态 20%」抬到连续 >30%，靠的是多花钱，不是突然出现新护城河。

**反面**：飞轮的燃料是**市场波动 + 客户加杠杆 + 利率不为零**。三者同时熄火时（2020 年零利率 + 部分年份交易清淡），NII 会掉一截；佣金也会掉。飞轮不是永动机。

## 3. 护城河：逐项验证

| 类型 | 判定 | 证据 | 反面 |
|------|------|------|------|
| **成本优势 / 规模** | **成立，且是主护城河** | 税前利润率 Q2 **77%**，连续 7 个季度 >70%；无长期债务；超额资本 $103 亿 | 利润率高部分来自 NII，不是纯执行垄断。Schwab 有更大托管规模 |
| **转换成本** | **对活跃专业户成立** | 多币种、全球 170+ 市场、API、期权/期货/外汇一套账户；平均账户权益约 **$17 万**（7 月 $9067 亿 / 531.7 万户） | 介绍经纪商可整体迁走；IBKR Lite 用户转换成本接近 Robinhood |
| **网络效应** | **弱** | 证券借贷和内部 ATS 有一点双边，但不是Visa 式网络 | 客户并不因为「别人也在 IBKR」而必须留下 |
| **品牌** | **专业圈强、大众弱** | Barron's 等评测常年靠前；大众心智是 Schwab / Fidelity / Robinhood | 品牌不能支撑提价 |
| **技术壁垒** | **中等、可维持** | 四十年自动化；Q2 上线韩国、隔夜交易同比近 3 倍（1090 万笔 vs 380 万） | 技术可被模仿；AI 交易入口（Connector）也可能把订单导向别处 |
| **定价权** | **不成立（段氏标准）** | 可计佣订单均价 Q2 $2.64，同比几乎持平（$2.65）；公司战略是「尽量少收」 | 这是**低成本生产者**，不是能涨价的特许经营 |

段永平要的「好生意」常常是能对客户提价还不丢量。IBKR 走的是 Costco 路线：用最低综合成本锁住高价值客户，在**利差和规模**上赚钱，而不是在佣金标价上赚钱。

**观点**：成本优势是真的；把它叫成「定价权」是偷换概念。

## 4. 用户价值：为谁创造了什么

| 客户类型 | 独特价值 | 公司如何变现 |
|----------|---------|-------------|
| 个人主动交易者 / 专业交易员 | 全球市场、低融资利率、闲置现金付息 | 佣金 + NII + 融资 |
| 对冲基金 / 自营 | 清算、证券借贷、融资 | 融资与借贷比零售佣金更厚 |
| 介绍经纪商 / 银行 | 把零售后台外包给 IBKR | 规模、NII 共享结构 |
| IBKR Lite 零售 | 美股零佣金 | PFOF，FY2025 仅 $5100 万 |

## 5. 业务矩阵与协同

- **Pro vs Lite**：Pro 付佣金换价格改善；Lite 零佣金走 PFOF。10-K 写明 Lite 的做市商支付记在佣金。PFOF 不是主业。
- **NII 内部结构（Q2 NIM 表）**：隔离现金净利息 $8.09 亿；融资利息 $9.88 亿；付给客户现金 $9.56 亿；证券借贷报表口径仅 $4400 万，但若把现金抵押利息加回，证券借贷净收入约 **$3.43 亿（+37%）**。
- **新产品**：预测市场（Kalshi / CME / ForecastEx）、韩国股票、欧洲加密、OCC 国民信托银行牌照（预批准，管理层称年底可运营，用于共同基金/ETF 直接托管）、IBKR Connector（Claude / ChatGPT / Grok 连账户）。
- **协同**：同一套清算和风控摊到更多产品。预测市场和 agentic trading 是期权，**尚未贡献可审计的收入分列**。

**反面**：信托银行牌照把公司推进 OCC  периметр，合规成本上升；agentic trading 若做成，订单可能被模型层截流，IBKR 变成管道。现在还是演示，不是护城河。

## 6. 段氏「好生意」标准评估

| 标准 | 结论 | 说明 |
|------|------|------|
| 能不能用一句话说清 | ✅ | 全球低成本电子经纪 + 客户现金/融资利差 |
| 差异化 | ⚠️ | 差异化在**全球接入 + 自动化成本**，不在品牌溢价 |
| 定价权 | ❌ | 佣金单价持平；战略是少收费 |
| 可持续竞争优势 | ✅（成本端） | 70%+ 税前利润率连续多个季度；账户 +34% |
| 用户导向 | ✅ | 闲置现金付息、不靠坑客户利差吃到尽（相对部分零售券商） |
| 看不懂的部分 | ⚠️ | 介绍经纪商 AML、融资尾部风险、利率路径 |

> 段永平会问：这门生意十年后还在吗？执行和清算不会消失。会问：你能不能提价？公开证据说**不能、也不打算**。会问：利润从哪来？过半从利差来——那就不是纯「软件券商」，是**轻资本的类银行**。

## 7. 反面检验（本维度强制）

### 7.1 利率下行会不会掐死 NII？

公司口径（Q2 电话会，CFO Paul Brody）：

- 美联储基金利率每变动 **25bp**，年化 NII ±**$8100 万**（起点：2026-06-30 EFFR **3.64%**，余额当时水平）。
- 非美元基准同样 25bp，年化 ±**$3800 万**。
- 「完全利率敏感」的客户余额仅 **$284 亿**（去年同期 $228 亿），不是 $1800 亿贷方余额全部瞬时重定价。
- 投资组合久期 **<30 天**。Q2 平均联邦基金利率同比已降 70bp（−16%），但融资利息仍 +39%、隔离现金利息 +7%——**余额增长盖过了利率下跌**。

FRED：2026-08-19 EFFR **3.63%**；7 月 FOMC 以 9-3 把目标区间维持在 **3.50–3.75%**，三名委员主张加息 25bp。当前宏观路径**不是** 2020 式归零。

100bp 降息粗算：4×$8100 万 = **$3.24 亿**，约占 TTM 税前 $53.56 亿的 **6%**。线性敏感度**打不死**这门生意。

**但另一方面**：25bp 系数是在 3.64% 附近的局部导数。若政策利率掉到接近 0，闲置现金利差会非线性压缩（2020–2021 NII 仅 $11.5 亿 vs FY2025 $35.6 亿）。线性外推不能用到零利率。公司也声明余额增长会放大敏感度——表越大，同样 25bp 的绝对冲击越大。

### 7.2 「低佣金」会被 Schwab / Robinhood 打死吗？

不是同一桌麻将。7 月口径：

| | IBKR | Schwab | Robinhood |
|--|------|--------|-----------|
| 客户资产 | **$9067 亿** | **$13.04 万亿** | **$3550 亿** |
| 账户 | **531.7 万** | 活跃经纪 3994 万 | 入金客户 **2850 万** |
| 户均 | ~$17.1 万 | 经纪户均更高 | ~$1.2 万 |
| 账户 YoY | **+34%** | 经纪账户 +6% | +7% |

Schwab 是顾问 + 托管巨型机器；Robinhood 是美国大众交易 + 加密 + 预测市场。IBKR 吃的是**全球主动交易者和 IB 清算**。Robinhood 往上走、Schwab 往下走都会切边缘，但没有证据显示 IBKR 的核心专业户在批量流失。

### 7.3 监管会不会改写单位经济？

- Lite 的 PFOF 若被禁，FY2025 $5100 万量级，可转回佣金，不是生死线。
- 真正的监管风险在**介绍经纪商全权账户的监控**（2025-12 Nasdaq AWC：外国 IB 全权账户操纵交易的监督缺陷）和多司法辖区牌照。见李录底稿。
- 中国：公司称不在大陆获客；Tiger/Futu 被整后，资产向 IBKR 转入增加。这是顺风，也可能是政策风向标——**不是护城河**。

### 7.4 股权结构让「买公司」打了折

公众股东买到的是 IBG, Inc. 对 LLC 的 **26.5%** 经济权益 + 管理权（IBG, Inc. 是唯一 managing member）。Peterffy 及其关联方通过 Holdings 控制约 **73.5%** 投票与经济。Tax Receivable Agreement：税基抬升节省的 **85%** 付给 Holdings。

段永平买的是「公司」，这里公司的 **3/4 不在股票里**。EPS 已经只反映公众那一层，所以 PE 分子分母是匹配的；但治理上你买不到控制权。

## 8. 本维度评分

| 子项 | 星级 | 一句话 |
|------|:----:|--------|
| 生意可理解性 | ★★★★ | 执行税简单；利差层是小型银行，仍能看懂 |
| 差异化 | ★★★★ | 全球接入 + 自动化成本，不是品牌溢价 |
| 定价权 | ★★ | 佣金不能涨；利差随市场走 |
| 飞轮 | ★★★★ | 账户→现金/融资→NII，当前数据支持 |
| 可持续性 | ★★★★ | 执行需求不会消失；零利率会伤 NII |

**商业模式与护城河：★★★★**

不是五星：定价权不合格，利润过半绑在利率和杠杆上。也不是三星：77% 税前利润率、34% 账户增长、户均 $17 万，说明这不是「便宜但没壁垒」的零售券商。

> 「人家赚的钱摆在那儿了。」Q2 税前 $14.56 亿摆在那儿。问题是其中多少来自 3.64% 的联邦基金利率，多少来自不可逆的成本优势——7 月融资余额环比 −7%、DART 环比 −16%，已经提醒：β 和杠杆会撤。
