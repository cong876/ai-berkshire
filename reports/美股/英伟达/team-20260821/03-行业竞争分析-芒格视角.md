## 1. 行业在卖什么：训练、推理、互联，三张不同的账单

公开事实（公司口径）：

- Q1 数据中心 **$752 亿**，占营收 92%；其中 compute $604 亿（+77%）、networking $148 亿（+199%）。
- Hyperscale 仍约 DC 的一半；ACIE（AI 云/工业/企业/主权）另一半，同比 +74%。
- 黄仁勋公开把 Blackwell + Rubin 的需求窗口说到日历 2027、量级「$1 万亿」——**这是管理层展望，不是订单 backlog 审计数**。本底稿不当确认收入。

观点：行业的增量利润仍在「能把加速器织成一台计算机」的系统，而不在单卡。谁能同时卖硅、交换机、软件和一年一代，谁就收系统税。英伟达是目前唯一把这四件事收到一张发票上的公司。

**但另一方面：** 账单正在裂成两半。训练需要可编程和集体通信（NCCL），CUDA+NVLink 仍是默认。推理需要的是焦耳/token。裂开之后，市占率「AI 加速器 80%+」这种总帽子会掩盖推理侧的流失。

## 2. 竞争格局：对手不是 AMD 一家，是客户自己

### 2.1 超大规模自研（主威胁）

| 玩家 | 芯片 | 公开状态（2026 年中） | 对 NVDA 的含义 |
|------|------|----------------------|----------------|
| Google | TPU（Ironwood / 多代） | 内部训练+推理最成熟 | 直接减少 Google 自用采购；对外出租有限 |
| Amazon | Trainium 3 / Inferentia | re:Invent 路径上的量产芯片 | 内部+AWS 租户可迁；Neuron SDK 仍是摩擦 |
| Microsoft | Maia | 偏内部推理（Copilot / 部分 API） | 最慢的一家；OpenAI 训练仍大量走 NVDA |
| Meta | MTIA | 中周期 | 同时签 CoreWeave / 自建，双轨 |

关键结构：**这四家既是最大买家，也是最大潜在替代者。** Q1 三个直接客户占营收 54%——直接客户是 ODM/CSP 名字，终端高度重叠这四家 + Oracle + 少数 neocloud。

American Compute 等第三方估计：截至 2025 年底约 320 万 Blackwell 封装，十大运营商控制约 67% 集群算力，五家超大规模约 49%。**第三方，非公司披露**，当方向不当时点精确数。

NVLink Fusion：允许客户把自研 ASIC 接到英伟达互联。芒格会说：这是承认「硅可以不是我们的」，用交换机和软件继续收税。短期聪明，长期把「必须买我们的 GPU」改成「可以只买我们的交换机」。

### 2.2 AMD

MI350 / MI325X 是公开市场上唯一接近的通用替代。中国 H200 出口政策把 MI325X 与 H200 并列（同样 25% 费用、同样许可）——说明监管把它们当成**同档商品**。事实：AMD 数据中心 GPU 收入仍比英伟达小一个数量级以上（以各公司最近季报为准，本底稿不合成虚假市占率表）。AMD 的机会在价格敏感推理和「需要第二供应商」的采购政策，不在替换英伟达的旗舰训练集群。

### 2.3 其他（Groq、定制推理 ASIC、中国华为昇腾等）

对可出口市场：专用推理芯片在延迟敏感场景有点状替代，尚未在公司报表里变成可见的收入缺口。对中国市场：TrendForce 等称国内方案在国内数据中心占比快速上升——**第三方**。公司自己的事实是：Q1 **零** 数据中心 Hopper 对华出货（去年同期 $46 亿），Q2 指引 **假设中国 DC compute = 0**。

## 3. Lollapalooza：四股力是否同向？

芒格的问题不是「有没有竞争对手」，而是几股力量会不会**同时**朝一个方向推。

| 力 | 方向 | 已验证？ |
|----|------|----------|
| 1. 客户自研 ASIC（推理优先） | 减少 NVDA 在 hyperscaler **内部**推理的增量 | 方向验证；幅度未在 NVDA 收入里出现拐点 |
| 2. 出口管制 | 切掉中国 DC 增量 | **已验证**：H20 $45 亿拨备、Q1 对华 Hopper=0、H200 许可至 10-Q 日仍无收入 |
| 3. 电力 / 电网 / 机柜落地 | 限制出货速度，不是限制意愿 | 10-K / 10-Q 均列为关键约束；第三方谈弗吉尼亚排队 |
| 4. 融资与循环交易审查 | 压抑 neocloud 杠杆扩张 | 公司自己披露担保 $35 亿、Q1 非流通投资 $186 亿；媒体在问 OpenAI 相关担保是否收缩 |

1+2 已经同向：**最大市场的内部推理被自研切，第二大地理市场被政策切。** 3 是双刃剑（限制供给反而支撑毛利率）。4 若发酵，伤的是 ACIE 里靠杠杆买 GPU 的那一半。

尚未形成「收入已经下降」的 Lollapalooza：Q1 DC +92%、指引 $910 亿。Lollapalooza 现在作用在**远期份额和倍数**，还没作用在当季出货。

**但另一方面：** 同向的还有英伟达自己的力量——一年一代、networking +199%、 Dynamo / CUDA-X 继续加厚软件。Lollapalooza 不是只对空头开放。

## 4. 产业链：利润在谁手里

| 层 | 玩家 | 议价 |
|----|------|------|
| 上游晶圆 / 先进封装 / HBM | TSMC、SK 海力士、三星 | 产能是共同瓶颈；英伟达因体量优先，但**不能无 TSMC** |
| 中游系统设计 | NVDA + Foxconn / Wistron / Quanta 等 | 英伟达收系统溢价；ODM 是直接客户、也是集中度来源 |
| 下游云 | MSFT / GOOG / AMZN / Oracle / Meta / neocloud | 付钱的人，也是自研的人 |
| 更下游模型 | 闭源实验室 + 开源权重 | 10-K：开源模型若跑在对手平台，可能减少对其产品的需求 |

价值分配现状：英伟达毛利率 75%，台积电/HBM 供应商赚制造利润，云厂商把 GPU 折旧转成 token 收入（单位经济**公司未披露**）。开源模型降低的是「必须买最贵那张卡才能跟 SOTA」的理由——10-K 自己写了这条风险。

---

## 5. 产品节奏：Blackwell 现在，Rubin 下半年

- Blackwell / Blackwell Ultra / GB300：Q1 「Blackwell 300 产品放量」驱动 DC。公司称 Blackwell 已占 DC 收入多数。
- Rubin：10-K 写明预计 **FY2027 下半年**开始量产出货；相对 Blackwell 最多 10x 降 token 成本（公司宣传）。GTC 2026 微软宣称点亮首台 Vera Rubin NVL72——**客户公关，不是收入确认**。
- 一年一代把「等到 AMD / ASIC 追上」变成移动靶。也把自身库存做成定时器（H20 已炸过一次）。

## 6. 芒格维度小结

| 问题 | 答案 |
|------|------|
| 这是不是有竞争淘汰的好行业？ | 需求侧是。供给侧正在从「唯一铲子」变成「最好的铲子 + 若干专用铲」 |
| 英伟达会不会被淘汰？ | 训练侧 3–5 年证据不足。推理侧正在被客户自己部分淘汰 |
| 能力圈 | 半导体周期 + 客户 capex 周期，比「软件订阅」更难假装看十年 |
| 本维度 | **★★★★** |

不是五星：五星要求赢家通吃且客户无法自建。英伟达仍是通吃训练和可出租算力的赢家；客户自建已经从 PPT 变成产线。

> 芒格：「告诉我我会死在哪里，我就不去那里。」对英伟达，死法不是「突然出现一个更快的 GPU 公司」，而是**四个最大客户在推理上不再增量采购、同时中国继续为零、同时 neocloud 融资断掉**。三件都已经发生了一部分；还没有同时打满。

**反面论据：** networking 同比三倍、ACIE +74%、微软/谷歌仍在抢 Rubin 首发——说明替代尚未打断订单簿。把「份额叙事结束」写成「需求已经结束」，是在偷换。
