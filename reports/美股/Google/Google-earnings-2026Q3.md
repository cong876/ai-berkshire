## 二、本期最重要的 3 个变化

**1. Cloud 从"第二引擎"变成"第一增量来源"，但增长的一部分是卖硬件。** Cloud 收入 $307 亿、同比翻倍，单季同比增量 $155 亿，是 Search 增量（$68 亿）的 2.3 倍；分部经营利润 $111 亿、利润率 36.2%，一年内从 23.7% 抬上来。积压订单 $5,610 亿（Q2 $5,140 亿，+$470 亿），略高于 55% 将在 24 个月内确认，即约 $3,090 亿，相当于 TTM Cloud 收入（约 $932 亿）的 3.3 倍。但另一方面：新闻稿把分部定义改写为"Google Cloud 的产品收入主要来自 TPU 系统销售"，CFO 承认 TPU 系统销售是"meaningful contributor"，却拒绝给出剔除 TPU 后的增速；其他营业成本 +32% 里含 TPU 硬件成本，存货一年内从 $24 亿涨到 $133 亿。Cloud 36% 的利润率混合了高毛利 GCP 与低毛利硬件，而 Q4 起第三方"桥接算力"放量会带来"利润率逆风"。

**2. Search 减速到 +12%，管理层首次承认 AI Mode 变现偏低。** Search 从 Q2 的 +17% 降到 +12%，环比几乎零增长（$632.7 亿 → $633.5 亿）。管理层给了四个原因（汇率、欧盟取消小额免税打击亚太零售商、世界杯后媒体娱乐回落、AI Mode 变现偏低），并量化了基数效应：Q3 约 3 个百分点，Q4 还有"a couple points"，Q4 汇率逆风更大。换句话说，**Q4 Search 大概率跌到个位数或 10% 边缘**。与此同时公司说查询量增速是五年最高——查询在涨、收入在减速，意味着每次查询的变现在下降。这是 8 月报告"减仓信号 1"（Search 掉到个位数且 CPC 转负）第一次进入视野，尚未触发。

**3. 现金流与资本结构同时转向，减仓信号 3 已触发。** FCF 连续两季为负（−$59 亿、−$91 亿），9 个月 FCF −$48 亿，按 Q4 隐含 capex $63–73B 估算，**2026 全年 FCF 大概率为负（估计 −$100 至 −$280 亿），将是 Alphabet 上市以来首个负 FCF 年份**。同一季度：零回购、首次动用 ATM 增发 $124 亿、新发债 $290 亿、长期债务一年翻近三倍至 $1,251 亿、未来采购承诺 **$9,240 亿** 加租赁承诺 $1,520 亿，2027 capex 仍是"显著增加"且不给数字。扣掉 $904 亿有价权益证券（SpaceX 等）后，真正的流动资金约 $1,747 亿对 $1,251 亿债务，净现金只剩约 $500 亿。8 月报告的减仓信号 3 "FCF 连续多季为负且继续增发" 本季**触发**。

## 六、与投资论文的关系

8 月报告的五句话论文：意图拍卖场仍在 / GAAP 利润不可用 / FCF 被 capex 抽干 / Cloud 是有外部买家的第二引擎 / 最致命风险是入口迁到代理层。

| 论文要素 | Q3 证据 | 状态 |
|---|---|---|
| 搜索护城河未被打穿 | Search +12%，查询量增速五年最高，零售仍是最大贡献；但 AI Mode 变现偏低已被承认，Q4 还要再减 2 pct | **削弱**（从"没有被打穿"变成"变现在被稀释"） |
| GAAP 利润不可用 | 本季反向：浮亏 $87 亿把 EPS 压到 $2.12，可持续 $2.67 +22% | 无影响（结论正确，方向换了） |
| FCF 被 capex 抽干 | −$91 亿，全年转负，2027 再加，$9,240 亿承诺 | **恶化**（已从担忧变成事实） |
| Cloud 有外部买家 | 积压 +$470 亿至 $5,610 亿，TPU 近 100 家客户，Apple / Anthropic / Oracle / Meta（TorchTPU）；利润率 36% | **强化**（但含硬件，Q4 利润率逆风） |
| 入口迁到代理层 | Gemini 应用 10 亿用户，agent 产品企业版先行；无分流数据 | 无变化 |

**8 月报告的触发信号盘点**：

加仓 / 转正（5 条）：(1) 单季 FCF 转正且 2027 capex 不再显著增加 ❌；(2) 付费点击与 CPC 连续两季双正 ⚠️ 等 10-Q；(3) Cloud 剔 TPU 仍高增且利润率 30%+ — 利润率 ✅、剔 TPU 无数字 ⚠️；(4) 重启回购 ❌（反向：ATM）；(5) 广告科技救济无需剥离 ✅（9 月 AdX 不拆）。**1.5 / 5。**

减仓 / 回避（5 条）：(1) Search 个位数且 CPC 转负 ❌（+12%，Q4 逼近）；(2) capex 再上修且积压取消率上升 ❌；(3) **FCF 连续多季为负且继续增发 ✅ 触发**；(4) 上诉法院禁 Apple 默认付款 ❌；(5) 零售预算可见迁出 ❌。**1 / 5 触发。**

**与 10-20 换仓判断的关系**：那份报告把换仓论据押在"Google 的 capex 有外部买家"。Q3 给了正面证据（积压、TPU 客户名单、Cloud 利润翻三倍），也给了反面证据（Google 同样零回购、同样 FCF 为负、而且比 Meta 多了 ATM 增发与 $9,240 亿承诺）。估值差距收窄：Google 可持续 PE 26.6x vs Meta 剔一次性 21.9x，溢价从 50% 缩到 21%。**换仓的结构性理由变强、估值理由仍不成立、时点理由消失**（两家财报都已出）。

## 七、结论：这份财报改变了什么

**1. 超预期 / 符合 / 低于预期？——低于预期。** 收入持平共识（−0.3%），Cloud 超预期 5.5%，但可持续 EPS $2.67 比共识 $3.01 低 11%，经营利润环比零增长、利润率环比掉 2.2 pct，FCF −$91 亿。盘后 −9.6% 定价的是三件事：Search 减速 + AI Mode 变现偏低被承认、2026 全年 FCF 转负、2027 capex 第三次不给数字叠加 $9,240 亿采购承诺。市场没有为 Cloud +103% 付钱，因为管理层拒绝说明其中多少是硬件。

**2. 对投资论文：削弱，未破裂。** 五个要素一强化、两削弱、两不变。生意本身（意图匹配 + 算力租赁）没有出现永久性损伤的证据；受损的是"capex 周期可在 24 个月内回到正 FCF"这个假设——现在连 2027 都不会。综合评分从 3.5 降到 **3.25**：商业模式 ★★★★ 不变，财务 & 估值 ★★★ → **★★**（FCF 转负 + 增发 + 承诺锁定），行业 & 竞争 ★★★★ 不变（Cloud 份额增量继续抢 AWS），风险 & 管理层 ★★★ 不变（坦诚度加分、TPU 不透明减分）。

**3. 下一个催化剂。** (a) 10-Q（预计 11 月初）：付费点击 / CPC、ATM 用途、采购承诺分年到期表——这三个数决定 Q4 前要不要动仓位；(b) 11 月 Gemini 4 Carbon 全面开放与 agent 消费者版；(c) **Q4 电话会（2027 年 1 月末）的 2027 capex 数字**，BofA 财报前估 $3,000 亿，若高于此且仍无 FCF 路径，财务评分再降一星；(d) Cloud Q4 利润率（第三方算力逆风的实际幅度）。

**4. 已持有 2.1%，加 / 持 / 减？——持有，不加，加仓线下移。** 盘后 $291 落进 8 月报告的激进型加仓带 $280–310，但那条线的前提是"赌 Cloud 积压兑现 + 搜索不被掏空"，没有预设减仓信号 3 同时触发。按新基数重算：可持续 EPS $10.95，24x ≈ **$263**，22x ≈ $241，20x ≈ $219；三情景（18%/30x、12%/24x、3%/16x）：乐观 $540（+86%）/ 中性 $369（+27%）/ 悲观 $191（−34%）。中性情景从 8 月的 +4% 变成 +27%，三分之二来自股价 −15%，三分之一来自 EPS 基数上调——这是价格变便宜了，不是生意变好了。

- **现有 2.1% 持有**。生意没坏，估值 26.6x 可持续 PE 对应 +22% 的可持续 EPS 增速，不是卖出价；仓位小，承受得起再跌到悲观带。
- **加仓线从 $280–310 下移到 $250–265**（22–24x 可持续 EPS），且附带条件：10-Q 显示 ATM 用途仅为 SBC 税、付费点击与 CPC 双正。两条都满足，才在 $265 以下把仓位加到 4%；只满足价格不满足条件，不加。
- **减仓触发**：Q4 Search 增速跌破 10% 且 10-Q 显示 CPC 转负（减仓信号 1 正式触发），或 2027 capex 指引 ≥ $3,000 亿且 Q4 仍增发，则把 2.1% 清掉——仓位本来就是观察级别，论文破裂就不留。
- **Meta → Google 换仓**：不执行。两家同一周都触发了"FCF 负 + 零回购"，Google 还多一条增发；换仓是在同一条 AI capex 线上挪位置，10-20 报告的结论没有被推翻，反而被两份财报同时验证了"两家都不在买入区"。
- **组合层面**：GOOG 直接 2.1% + 经 QQQM 间接约 1.3%，有效暴露 3.4%，纳指/AI 一条线 44.9%；本周为 10/27–29 事件禁区，按 QQQM 规则 R1–R8 不因单只股票的盘后波动改动 QQQM 挂单。

> 巴菲特："只有在退潮的时候，你才知道谁在裸泳。" Alphabet 不是裸泳，它是在涨潮期把所有现金和一部分股权都压进了基建。
> 芒格："反过来想，总是反过来想。" 反过来问：如果 Cloud 积压 $5,610 亿是真的、利润率能守住 30%，今天 26.6x 买一个 EPS +22% 的公司便宜吗？——便宜。问题是这个"如果"要到 2027 年 TPU 大规模交付后才能验证，而验证之前，公司已经承诺了 $9,240 亿。
> 李录："投资最重要的是知道自己不知道什么。" 本季不知道的是：TPU 的毛利率、剔 TPU 的 GCP 增速、2027 的 capex 数字。三个都在管理层手里，三个都没给。
